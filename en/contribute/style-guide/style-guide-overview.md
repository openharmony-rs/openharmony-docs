# About This Guide

<!-- md-trans-meta sourceCommit=195053a223f1a2d54d1ded7b0c40b4ed874b59e5 translatedAt=2026-11-17T02:46:33.905Z nl=1 -->

This guide provides requirements and recommendations for the language style, document structure, and content elements of OpenHarmony documentation. It helps maintain a consistent style and enables developers to contribute documentation efficiently.


Before writing OpenHarmony documentation, read this guide and follow the applicable requirements and recommendations.


Also, choose the template that best matches your content from the [OpenHarmony Documentation Templates](../template) and follow its instructions. The templates provide guidance for specific document types and help you write more efficiently.


This guide is updated regularly. Suggestions for improvement are welcome.


> **NOTE**
> This guide distinguishes between [Rule] and [Recommendation]:
> 
> - [Rule] indicates a mandatory requirement.
> 
> - [Recommendation] indicates optional guidance.
