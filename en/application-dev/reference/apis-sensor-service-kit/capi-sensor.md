## Overview

Provides APIs for using common sensor features, including the accelerometer, gyroscope, and light sensor. You can use unified APIs to obtain sensor information and subscribe to or unsubscribe from sensor data, simplifying the app development process and reducing development costs.<br>**Use scenarios**: pedometer, motion tracking, automatic screen brightness adjustment, and game control.
