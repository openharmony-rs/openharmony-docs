# Rect

Rectangle in a plane.

@typedef Rect

**Since:** 12

**System capability:** SystemCapability.ArkUi.Graphics3D

## height

```TypeScript
height: number
```

Rectangle height, in scene units of the world coordinate system (such as cm, m, km, etc.). The valid value range is greater than 0.

**Type:** number

**Since:** 12

