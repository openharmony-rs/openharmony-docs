# PlaneGeometry

@extends GeometryDefinition

**Inheritance/Implementation:** PlaneGeometry extends [GeometryDefinition](arkts-arkgraphics3d-scenetypes-geometrydefinition-c.md)

## size

```TypeScript
get size(): Vec2
```

Width and height of the plane, indicating the size of the plane. The unit is the scene unit of the world coordinate system (such as cm, m, km, etc.).
