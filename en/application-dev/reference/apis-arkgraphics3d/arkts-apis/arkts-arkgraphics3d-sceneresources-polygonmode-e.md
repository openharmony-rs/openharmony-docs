# PolygonMode

Enumerates the polygon drawing mode.

@enum { int }

**Since:** 23

**System capability:** SystemCapability.ArkUi.Graphics3D

## FILL

```TypeScript
FILL = 0
```

Draws each face of the polygon.

**Since:** 23

**System capability:** SystemCapability.ArkUi.Graphics3D

## LINE

```TypeScript
LINE = 1
```

Draws only the wireframe of the polygon.

**Since:** 23

**System capability:** SystemCapability.ArkUi.Graphics3D

## POINT

```TypeScript
POINT = 2
```

Draws only the vertices of the polygon.

**Since:** 23

**System capability:** SystemCapability.ArkUi.Graphics3D
