# MaterialType

```TypeScript
export enum MaterialType
```

Enumerates the material types in a scene. The material type defines how materials in a scene are rendered.

@enum { int }

**Since:** 12

## UNLIT_SHADOW_ALPHA

```TypeScript
UNLIT_SHADOW_ALPHA = 100
```

Draws only shadows. When the Blend property of the material is enabled, the material is blended with the background to simulate a transparent material effect.

**Since:** 23

**Model restriction:** This API can be used only in the stage model.
