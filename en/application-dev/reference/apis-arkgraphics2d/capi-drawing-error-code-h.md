## Function Description

### OH_Drawing_ErrorCodeGet()

```c
OH_Drawing_ErrorCode OH_Drawing_ErrorCodeGet()
```

**Description**

Obtains the most recent error code of this module.<br>When an API that does not return an error code fails, the error code of this module is set to the corresponding error number. It is not reset to OH_DRAWING_SUCCESS after a successful execution. You can reset the error code by calling [OH_Drawing_ErrorCodeReset](#oh_drawing_errorcodereset).

**System capability**: SystemCapability.Graphic.Graphic2D.NativeDrawing

**Since**: 12

**Return value**

| Type| Description|
| -- | -- |
| [OH_Drawing_ErrorCode](#oh_drawing_errorcode) | Returns the most recent error code of this module. The error code returned by this function is not modified after the function runs successfully. |

### OH_Drawing_ErrorCodeReset()

```c
void OH_Drawing_ErrorCodeReset(void)
```

**Description**

Resets the error code of this module to OH_DRAWING_SUCCESS.<br>The error code of this module obtained through [OH_Drawing_ErrorCodeGet](#oh_drawing_errorcodeget) is set to the corresponding error number when an API that does not return an error code fails, but it is not reset to OH_DRAWING_SUCCESS after a successful execution.<br>Calling this API resets the error code to OH_DRAWING_SUCCESS, preventing interference between multiple APIs and facilitating debugging by developers.

**System capability**: SystemCapability.Graphic.Graphic2D.NativeDrawing

**Since**: 18
