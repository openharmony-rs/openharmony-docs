## Function Description

### OH_Drawing_GetRunStringIndices()

```c
OH_Drawing_Array* OH_Drawing_GetRunStringIndices(OH_Drawing_Run* run, int64_t start, int64_t length)
```

**Description**

Obtains an array of character indices of glyphs within a specified range of a run, where the indices are offsets relative to the entire paragraph.

**System capability**: SystemCapability.Graphic.Graphic2D.NativeDrawing

**Since**: 18

**Parameters**

| Name| Description|
| -- | -- |
| [OH_Drawing_Run](capi-drawing-oh-drawing-run.md)* run | Pointer to an [OH_Drawing_Run](capi-drawing-oh-drawing-run.md) object.|
| int64_t start | Start position specified within the rendering unit. The value range is [0, glyphCount-1], where glyphCount is the glyph count of the rendering unit. The method returns a null pointer when passing a negative number or a value that exceeds the glyph count of the rendering unit. |
| int64_t length | Length specified within the rendering unit. When length is 0, the method obtains the character index array of all characters in the rendering unit. When length is less than 0, the method returns a null pointer. When start+length exceeds the actual range of the rendering unit, the method obtains valid data up to the end of the rendering unit. |

**Returns**

| Type| Description|
| -- | -- |
| [OH_Drawing_Array](capi-drawing-oh-drawing-array.md)* | Returns the character index array of the glyph. Call [OH_Drawing_DestroyRunStringIndices](capi-drawing-text-run-h.md#oh_drawing_destroyrunstringindices) to release this pointer when the object is no longer needed.|

| float* descent | Pointer to the distance from the lowest character in the rendering unit to the baseline, in px. |
