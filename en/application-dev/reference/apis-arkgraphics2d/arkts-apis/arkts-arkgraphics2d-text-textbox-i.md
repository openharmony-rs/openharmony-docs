# TextBox

Rectangular area of the text, indicating the rectangular space occupied by the text during layout.

**Since:** 12

**System capability:** SystemCapability.Graphics.Drawing

## Modules to Import

```TypeScript
import { text } from '@kit.ArkGraphics2D';
```
