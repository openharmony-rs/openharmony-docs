# FontMetricsFlags

```TypeScript
enum FontMetricsFlags
```

Enumerates the font measurement flags, which is used to specify whether a field in the [FontMetrics](arkts-arkgraphics2d-drawing-fontmetrics-i.md) struct is valid.

**Since:** 12

<!--Device-drawing-enum FontMetricsFlags--><!--Device-drawing-enum FontMetricsFlags-End-->

**System capability:** SystemCapability.Graphics.Drawing

## UNDERLINE_THICKNESS_VALID

```TypeScript
UNDERLINE_THICKNESS_VALID = 1 << 0
```

The **underlineThickness** field is valid.

**Since:** 12

**Atomic service API (ArkTS-Dyn only) :** This API can be used in atomic services since version 22.
