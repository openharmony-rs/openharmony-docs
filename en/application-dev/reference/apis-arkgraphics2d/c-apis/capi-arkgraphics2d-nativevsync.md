# NativeVsync

## Overview

This module provides the capabilities for obtaining the system vertical synchronization (VSync) callback, allowing you to synchronize your application's drawing frame rate with the system's frame rate.

**System capability**: SystemCapability.Graphic.Graphic2D.NativeVsync

**Since**: 9
