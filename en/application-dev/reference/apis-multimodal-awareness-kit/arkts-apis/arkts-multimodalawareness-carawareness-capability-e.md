## REALTIME_WEATHER

```TypeScript
REALTIME_WEATHER = 'RealTimeWeather'
```

Real-time weather capability, which supports recognizing the weather conditions of the environment where the car is currently located.

**Since:** 26.0.1

**Model restriction:** This API can be used only in the stage model.
