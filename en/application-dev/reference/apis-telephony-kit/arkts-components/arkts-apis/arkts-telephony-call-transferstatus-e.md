# TransferStatus

Enumerates call transfer states.

**Since:** 26.0.0

**System capability:** SystemCapability.Telephony.CallManager

## TRANSFER_DISABLE

```TypeScript
TRANSFER_DISABLE = 0
```

Call transfer disabled.

**Since:** 26.0.0

**System capability:** SystemCapability.Telephony.CallManager

## TRANSFER_ENABLE

```TypeScript
TRANSFER_ENABLE = 1
```

Call transfer enabled.

**Since:** 26.0.0

**System capability:** SystemCapability.Telephony.CallManager
