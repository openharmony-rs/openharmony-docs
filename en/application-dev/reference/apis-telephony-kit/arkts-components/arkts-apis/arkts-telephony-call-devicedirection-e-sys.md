# DeviceDirection (System API)

Enumerates device directions in a video call.

**Since:** 11

**System capability:** SystemCapability.Telephony.CallManager

**System API:** This is a system API.

## DEVICE_DIRECTION_0

```TypeScript
DEVICE_DIRECTION_0 = 0
```

0-degree direction.

**Since:** 11

**System capability:** SystemCapability.Telephony.CallManager

**System API:** This is a system API.
