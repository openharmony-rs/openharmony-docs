# NetworkSearchResult (System API)

Obtains the network search results.

**Since:** 6

**System capability:** SystemCapability.Telephony.CoreService

**System API:** This is a system API.

```TypeScript
import { radio } from '@kit.TelephonyKit';
```

**Since:** 6

**System capability:** SystemCapability.Telephony.CoreService

**System API:** This is a system API.
