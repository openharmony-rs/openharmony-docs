# ShortMessageClass

Enumerates SMS message types.

**Since:** 6

**System capability:** SystemCapability.Telephony.SmsMms

## UNKNOWN

```TypeScript
UNKNOWN = 0
```

Unknown type.

**Since:** 6

**System capability:** SystemCapability.Telephony.SmsMms

## INSTANT_MESSAGE

```TypeScript
INSTANT_MESSAGE = 1
```

Instant message, which is displayed immediately after being received.

**Since:** 6

**System capability:** SystemCapability.Telephony.SmsMms

## OPTIONAL_MESSAGE

```TypeScript
OPTIONAL_MESSAGE = 2
```

Message stored in the device or SIM card.

**Since:** 6

**System capability:** SystemCapability.Telephony.SmsMms

## SIM_MESSAGE

```TypeScript
SIM_MESSAGE = 3
```

Message containing SIM card information, which is to be stored in the SIM card.

**Since:** 6

**System capability:** SystemCapability.Telephony.SmsMms

## FORWARD_MESSAGE

```TypeScript
FORWARD_MESSAGE = 4
```

Message to be forwarded to another device.

**Since:** 6

**System capability:** SystemCapability.Telephony.SmsMms
