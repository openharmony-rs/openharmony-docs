## Overview

Defines a struct for the background deserialization result transferred together with **JSVM_COMPILE_BACKGROUND_DESERIALIZE_RESULT**.

**Use scenario**: Used to transfer and store the background deserialization result data in the JSVM background compilation scenario.

**Features**: A lightweight type definition, used together with **JSVM_COMPILE_BACKGROUND_DESERIALIZE_RESULT**.
