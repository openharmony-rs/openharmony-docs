## Overview

Defines a JavaScript CPU profiler.

**Use scenario**: Analyzes the CPU usage of a JavaScript app or module, locates performance hotspots and bottlenecks, and optimizes the execution efficiency of JavaScript code.

**Features**: Provides detailed CPU time profiling data, supports function-level performance statistics, and can generate performance profiling reports.
