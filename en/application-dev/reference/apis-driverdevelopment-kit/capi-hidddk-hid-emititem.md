## Overview

Represents the HID event information struct, which contains the event type, event encoding, and event value, and is used to describe the events reported by an input device. In driver development scenarios, this struct is used to transmit and identify events generated by various HID devices.

**Since**: 11

**Related module**: [HidDdk](capi-hidddk.md)

**Header file:** [hid_ddk_types.h](capi-hid-ddk-types-h.md)

## Summary

### Member Variables

| Name| Description|
| -- | -- |
| uint16_t type | HID event type, used to identify the event category, such as key presses and movements. Refer to the HID protocol specification for the value range. |
| uint16_t code | HID event code, used to identify a specific HID event. Refer to the HID protocol specification for the value range. |
| uint32_t value | HID event value, indicating the parameter or state of the event. The specific meaning depends on the event type and code. For example, for a key event, it indicates the key state; for a movement event, it indicates the movement distance. |
