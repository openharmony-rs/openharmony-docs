## Overview

Provides the enum and struct definitions in HID DDK, supports developers in defining and operating HID devices during driver development, applies to scenarios involving interaction with input devices such as mouse, keyboard, and touchscreen, and provides complete definitions of device features, event types, key value encodings, and coordinate axes, helping developers quickly implement driver development for HID devices.

**File to include**: <hid/hid_ddk_types.h>

**Library**: libhid.z.so

**System capability**: SystemCapability.Driver.HID.Extension

**Since**: 11

**Related module**: [HidDdk](capi-hidddk.md)
