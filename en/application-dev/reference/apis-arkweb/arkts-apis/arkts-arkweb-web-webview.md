# @ohos.web.webview

This module provides the capability to manage web modules.

@namespace webview

**Since:** 9

**System capability:** SystemCapability.Web.Webview.Core

## Modules to Import

```TypeScript
import { webview } from '@kit.ArkWeb';
```
