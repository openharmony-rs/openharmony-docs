# ConsoleMessageSource

Enumerates the log sources of the console messages.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## XML

```TypeScript
XML = 0
```

Logs are generated by the XML/HTML parser of the web page, for example, HTML syntax errors, XML format exceptions, and parsing warnings caused by unclosed HTML tags.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## JAVASCRIPT

```TypeScript
JAVASCRIPT = 1
```

Logs are generated when an exception occurs during JavaScript execution, such as a JavaScript syntax error or runtime exception.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## NETWORK

```TypeScript
NETWORK = 2
```

Logs are generated when web page resources (such as JS, CSS, and images) fail to be loaded and error code 404 is returned.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## CONSOLE_API

```TypeScript
CONSOLE_API = 3
```

Logs are generated when web pages call W3C console APIs, such as **console.warn** and **console.error**.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## STORAGE

```TypeScript
STORAGE = 4
```

Logs are generated when exceptions (such as storage quota exceeding and operation exceptions) occur on storage- related modules (LocalStorage, SessionStorage, IndexedDB and Cookie).

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## RENDERING

```TypeScript
RENDERING = 5
```

Logs are generated when exceptions (such as invalid CSS styles, layout exceptions, and rendering performance warnings) occur on the rendering engine (such as Blink).

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## SECURITY

```TypeScript
SECURITY = 6
```

Logs are generated when web page security policies are violated, HTTPS certificate errors occur, and mixed content (HTTP resources are loaded on HTTPS pages) occurs.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## OTHER

```TypeScript
OTHER = 7
```

Logs are generated by other sources, such as web extension plugins.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## DEPRECATION

```TypeScript
DEPRECATION = 8
```

Logs are generated when an expired syntax, such as **slider-vertical**, is used.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## WORKER

```TypeScript
WORKER = 9
```

Logs are generated when service worker errors occur, for example, service worker navigation preload requests are interrupted before being completed.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## VIOLATION

```TypeScript
VIOLATION = 10
```

Logs are generated when a rule is violated, for example, the execution of a piece of JavaScript code takes more than 50 ms.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## INTERVENTION

```TypeScript
INTERVENTION = 11
```

Logs are generated when the web page detects code behaviors that may compromise user experience, security, or performance. The web page proactively intervenes, blocks or modifies the behavior, and notifies you of the behavior through a message containing **kIntervention**. For example, the **DispatchBeforeUnload** event is triggered on a web page without user interaction.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core

## RECOMMENDATION

```TypeScript
RECOMMENDATION = 12
```

Logs are generated when code behaviors that do not comply with web security best practices are detected and improvement suggestions are provided. For example, when the page uses APIs (such as **innerHTML** and **eval()**) that may have XSS risks and does not comply with the Trusted Types security specifications.

**Since:** 23

**System capability:** SystemCapability.Web.Webview.Core
