# BlankScreenReason

```TypeScript
declare enum BlankScreenReason
```

Enumerates the reasons for blank screen attribution, identifying the root cause of the blank screen issue across the network layer, resource layer, rendering and JavaScript layer, kernel and process layer, and container layer.

**Since:** 26.0.1
