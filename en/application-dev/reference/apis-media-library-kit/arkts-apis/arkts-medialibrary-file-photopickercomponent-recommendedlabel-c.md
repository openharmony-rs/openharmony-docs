# RecommendedLabel

```TypeScript
export declare class RecommendedLabel
```

Indicates the recommendation label clicked by the user on the search page. A recommendation label is either a pure text label (only `text` is provided) or a smart entity label (`smartEntity` is provided). The two cases are mutually exclusive.

**Since:** 26.1.0
