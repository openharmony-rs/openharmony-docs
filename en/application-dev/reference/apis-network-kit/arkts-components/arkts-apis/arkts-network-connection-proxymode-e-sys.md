# ProxyMode (System API)

Enumerates the proxy modes. This API uses a promise to return the result.

**Since:** 20

**System capability:** SystemCapability.Communication.NetManager.Core

**System API:** This is a system API.

## PROXY_MODE_OFF

```TypeScript
PROXY_MODE_OFF = 0
```

Proxy disabled.

**Since:** 20

**System capability:** SystemCapability.Communication.NetManager.Core

**System API:** This is a system API.

## PROXY_MODE_AUTO

```TypeScript
PROXY_MODE_AUTO = 1
```

Auto mode.

**Since:** 20

**System capability:** SystemCapability.Communication.NetManager.Core

**System API:** This is a system API.
