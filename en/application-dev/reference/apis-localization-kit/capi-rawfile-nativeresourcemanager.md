## Overview

Represents a ResourceManager object at the native layer. NativeResourceManager encapsulates the native implementation of the JavaScript ResourceManager and can be obtained through the [OH_ResourceManager_InitNativeResourceManager](capi-raw-file-manager-h.md#oh_resourcemanager_initnativeresourcemanager) function.
