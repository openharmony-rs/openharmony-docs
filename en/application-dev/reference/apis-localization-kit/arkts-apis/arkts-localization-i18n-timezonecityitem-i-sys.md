# TimeZoneCityItem (System API)

Represents a time zone and city combination item.

**Since:** 10

**System capability:** SystemCapability.Global.I18n

**System API:** This is a system API.

## Modules to Import

```TypeScript
import { i18n } from '@kit.LocalizationKit';
```

```TypeScript

```

**Since:** 10

**System capability:** SystemCapability.Global.I18n

**System API:** This is a system API.
