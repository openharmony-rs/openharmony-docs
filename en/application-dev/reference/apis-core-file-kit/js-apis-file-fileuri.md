fileuri inherits from [URI](../apis-arkts/js-apis-uri.md).

This module provides the capability of obtaining the Uniform Resource Identifier (URI) of a file based on the file path, and supports conversion between URIs and application sandbox paths. With the file URI, you can use the APIs provided by [@ohos.file.fs](js-apis-file-fs.md) to perform operations such as open, read, and write, thereby implementing file sharing.

> **NOTE**
>
> The initial APIs of this module are supported since API version 9. Newly added APIs will be marked with a superscript to indicate their earliest API version.

## Modules to Import

```ts
import { fileUri } from '@kit.CoreFileKit';
```

Before using this module, you need to obtain the application sandbox path of the file. The following is an example:

  ```ts
  import { UIAbility } from '@kit.AbilityKit';
  import { window } from '@kit.ArkUI';

  export default class EntryAbility extends UIAbility {
    onWindowStageCreate(windowStage: window.WindowStage) {
      let context = this.context;
      let pathDir = context.filesDir;
    }
  }
  ```

### Attributes

**System capability**: SystemCapability.FileManagement.AppFileService

| Name| Type| Read-Only| Optional| Description|
| -------- | --------| --- |-------- |----------------|
| path<sup>10+</sup> | string | No | No | Converts a URI into a sandbox path. 1. During URI-to-path conversion, percent-encoded characters in the URI are decoded and concatenated in place. ### constructor<sup>10+</sup>

constructor(uriOrPath: string)

constructor is the constructor of FileUri. When a path is passed in, the application sandbox path can be obtained through the application context, for example, context.filesDir.

**Atomic service API**: This API can be used in atomic services since API version 15.

**System capability**: SystemCapability.FileManagement.AppFileService

**Parameters**

| Name| Type| Mandatory| Description|
| -------- | -------- | -------- |--------|
| uriOrPath | string | Yes | URI or path. The URI must conform to one of the following formats, or a valid path can be passed in. If the format is invalid, error code 14300002 is thrown:<br/>-&nbsp; Application sandbox URI: file://\<bundleName>/\<sandboxPath> <br/>-&nbsp; User directory file URI: file://docs/storage/Users/currentUser/\<publicPath> <br/>-&nbsp; User directory media URI: file://media/\<mediaType>/IMG_DATETIME_ID/\<displayName> |

**Error codes**

For details about the error codes, see [File Management Error Codes](errorcode-filemanagement.md).

| ID| Error Message       |
| -------- | ---------- |
| 13900005 | I/O error |
| 13900042 | Unknown error |
| 13900020 | Invalid argument |
| 14300002 | Invalid uri |

**Example**

  ```ts
  let pathDir = this.context.filesDir; // Obtain the application sandbox path.
  let path = pathDir + '/test';
  let uri = fileUri.getUriFromPath(path);  // file://<packageName>/data/storage/el2/base/haps/entry/files/test
  let fileUriObject = new fileUri.FileUri(uri);
  console.info(`The name of FileUri is ${fileUriObject.name}`);
  ```

### getFullDirectoryUri<sup>11+</sup>

getFullDirectoryUri(): string

Obtains the URI of the path. If the URI points to a file, the URI of the path is returned. If the URI points to a directory, the original string is returned without processing. If the file specified by the URI does not exist, or the file attributes cannot be obtained, an empty string is returned.

For a file, this API returns the URI of the directory where the file is located. For example, `xxx` will be returned for the `xxx/example.txt` file.

For a directory, this API returns the URI of the directory.

**Atomic service API**: This API can be used in atomic services since API version 15.

**System capability**: SystemCapability.FileManagement.AppFileService

**Return value**

| Type| Description|
| --------- |--------|
| string | URI of the directory where the current file is located or URI of the current folder.|

**Error codes**

For details about the error codes, see [File Management Error Codes](errorcode-filemanagement.md).

| ID| Error Message|
| -------- |--------|
| 13900002 | No such file or directory |
| 13900012 | Permission denied         |
| 13900042 | Unknown error             |

**Example**

  ```ts
  import { BusinessError } from '@kit.BasicServicesKit';
  try {
    let pathDir = this.context.filesDir; // Obtain the application sandbox path.
    let path = pathDir + '/test.txt';
    let fileUriObject = new fileUri.FileUri(path);
    let directoryUri = fileUriObject.getFullDirectoryUri();
    console.info(`success to getFullDirectoryUri: ${JSON.stringify(directoryUri)}`);
  } catch (error) {
    console.error(`failed to getFullDirectoryUri because: ${JSON.stringify(error)}`);
  }
  ```

### isRemoteUri<sup>12+</sup>

isRemoteUri(): boolean

Checks whether the current URI is a remote URI. A remote URI contains the remote identifier `networkid`.

**Atomic service API**: This API can be used in atomic services since API version 15.

**System capability**: SystemCapability.FileManagement.AppFileService

**Return value**

| Type| Description|
| -------- |---------|
| boolean | - Returns **true**, indicating that the current FileUri points to a remote URI, for example, `file://com.example.demo/data/storage/el2/base/test.txt?networkid=xxxx`.<br>- Returns **false**, indicating that the current FileUri points to a local URI. |

**Error codes**

For details about the error codes, see [File Management Error Codes](errorcode-filemanagement.md).

| ID| Error Message|
| --------- |--------|
| 13900042 | Unknown error|

**Example**

  ```ts
  function isRemoteUriExample() {
    let uri = 'file://com.example.demo/data/storage/el2/base/test.txt?networkid=xxxx'; // ?networkid device ID, the identifier of the remote URI.
    let fileUriObject = new fileUri.FileUri(uri);
    let ret = fileUriObject.isRemoteUri();
    if (ret) {
      console.info('It is a remote URI.');
    }
  }
  ```

## fileUri.getUriFromPath

getUriFromPath(path: string): string

Generates the application's own URI based on the passed path. When the path is converted to a URI, Chinese characters and special characters other than alphanumeric characters in the path are percent-encoded and concatenated into the URI. The passed path can be obtained through the application context, for example, context.filesDir.

**Atomic service API**: This API can be used in atomic services since API version 15.

**System capability**: SystemCapability.FileManagement.AppFileService

**Parameters**

| Name| Type  | Mandatory| Description|
| ------ | ------ | ---- | ------- |
| path   | string | Yes   | Sandbox path of the file. Chinese characters and special characters other than digits and letters in the path are percent-encoded. Error code 401 is thrown if the parameter is invalid. |

**Return value**

  | Type| Description|
  | ------- |------|
  | string | URI generated from the passed path. |

**Error codes**  

For details about the error codes, see [Universal Error Codes](../errorcode-universal.md).
| ID| Error Message       |
| ---------- | ---------- |
| 401 | The input parameter is invalid. Possible causes: 1. Mandatory parameters are left unspecified. 2. Incorrect parameter types. |

**Example**

  ```ts
  let pathDir = this.context.filesDir; // Obtain the application sandbox path.
  let filePath = pathDir + '/test';
  let uri = fileUri.getUriFromPath(filePath);
  ```
