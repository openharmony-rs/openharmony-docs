## Overview

Provides methods for mutual conversion between URIs and paths, directory URI retrieval, and URI format validation, applicable to URI conversion and validation in file sharing scenarios.

**System capability**: SystemCapability.FileManagement.AppFileService

### OH_FileUri_GetPathFromUri()

```c
FileManagement_ErrCode OH_FileUri_GetPathFromUri(const char *uri, unsigned int length, char **result)
```

**Description**

Converts a URI into the corresponding sandbox path.<br>1. During URI-to-path conversion, percent-encoded characters in the URI are decoded and concatenated in place. A URI generated by a non-system API may contain characters that do not conform to the encoding specification, which may prevent the string from being concatenated properly. 2. The conversion is performed based on the string replacement rules agreed upon by the system (these rules may change as the system evolves). No path validation is performed during the conversion, so the conversion result is not guaranteed to be accessible.

**System capability**: SystemCapability.FileManagement.AppFileService

**Since**: 12

**Parameters**

| Name| Description|
| -- | -- |
| const char *uri | Indicates the URI to convert, which must comply with the system URI format specification. |
| unsigned int length | Indicates the byte length of the URI string to convert, which must be consistent with the actual length of uri. |
| char **result | Output parameter, indicating the converted path. Need to use the free() method of the standard library to release the allocated resource. |

**Returns**

| Type| Description|
| -- | -- |
| [FileManagement_ErrCode](capi-error-code-h.md#filemanagement_errcode) | Returns a specific error code. For details, see [FileManagement_ErrCode](capi-error-code-h.md#filemanagement_errcode).<br>         ERR_INVALID_PARAMETER 401 - The input parameter is invalid. Possible causes:<br>                  1. The **uri** parameter is a null pointer.<br>                  2. The **result** parameter is a null pointer.<br>                  3. The length of the input URI is inconsistent with the value of **length**.<br>         ERR_UNKNOWN 13900042 - Unknown error. This error is returned if the length of the converted path is 0.<br>         ERR_ENOMEM 13900011 - The memory allocation or copy fails.<br>         ERR_OK 0 - The API is called successfully.|
