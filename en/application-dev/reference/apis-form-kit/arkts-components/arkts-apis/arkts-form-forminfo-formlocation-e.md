# FormLocation

Enumerates the widget locations.

**Since:** 20

**System capability:** SystemCapability.Ability.Form

## DESKTOP

```TypeScript
DESKTOP = 0
```

The widget is located on the home screen.

**Since:** 20

**Atomic service API:** This API can be used in atomic services since API version 20.

**System capability:** SystemCapability.Ability.Form
