# InputMethod

## Overview

InputMethod provides functions to use input methods.

**System capability**: SystemCapability.MiscServices.InputMethodFramework

**Since**: 12

| [inputmethod_attach_options_capi.h](capi-inputmethod-attach-options-capi-h.md) | Provides methods for creating, destroying, reading, and writing input method attach option objects, used to manage configuration parameters when an app attaches to an input method. |
| [inputmethod_controller_capi.h](capi-inputmethod-controller-capi-h.md) | Provides methods for binding and unbinding input methods. |
