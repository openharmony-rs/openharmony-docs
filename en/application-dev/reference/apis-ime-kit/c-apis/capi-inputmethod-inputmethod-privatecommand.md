## Overview

Private command structure, which uses the key-value mechanism and functions as the carrier for transferring private data between the text box and the input method application. It can be used to transfer customized instructions, extended capability parameters, and specific scenario data, improving the scalability and compatibility of the input method function. Each PrivateCommand instance contains a key (identifier string) and a value. (Boolean, integer, or string. You can select only one of the three types.), the data type of the value is identified by InputMethod_CommandValueType. <br> <br> Purpose: Transfers private data between the input method application and the edit box client to implement customized communication between the two parties. The input method application sends a private instruction to the edit box client through the OH_InputMethodProxy_SendPrivateCommand. The edit box client receives private instructions from the input method application through the OH_TextEditorProxy_ReceivePrivateCommandFunc callback. Each PrivateCommand instance carries a key-value private data record. A maximum of five private data instances can be sent at the same time. The total size of all private data and key values sent at a time is limited to 32 KB. <br><br>Application scenario: <br>-An input method application sends a private instruction to the edit box: An input method application creates a PrivateCommand instance, sets the key and value, and sends the private instruction to the edit box client through [OH_InputMethodProxy_SendPrivateCommand](capi-inputmethod-inputmethod-proxy-capi-h. md#oh_inputmethodproxy_sendprivatecommand). <br>- The edit box client receives private instructions: The edit box client receives the private command instance array in the [OH_TextEditorProxy_ReceivePrivateCommandFunc] (capi-inputmethod-text-editor-proxy-capi-h. md#oh_texteditorproxy_receiveprivatecommandfunc)
