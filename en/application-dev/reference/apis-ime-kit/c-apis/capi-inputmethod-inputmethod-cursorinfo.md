# InputMethod_CursorInfo

```c
typedef struct InputMethod_CursorInfo InputMethod_CursorInfo
```

## Overview

InputMethod_CursorInfo is the opaque type of cursor information. It is used to describe the position and size of the cursor on the physical screen during text input. include that horizontal coordinate(left), vertical coordinate(top), width(width), and height(height) of the cursor. The unit is px. <br> <br> Purpose: Provide the accurate position and size of the cursor for the input method service. The input method implements the following functions based on the information: <br>- Cursor Follow: The keyboard panel adjusts the display position based on the cursor position to ensure that the keyboard does not block the area where the cursor is located. <br>- Candidate word positioning: The candidate word area of the input method is displayed near the cursor, providing accurate input experience. <br>-Avoidance calculation: The input method calculates the area to be avoided based on the cursor height and position. <br> <br>Application scenario: <br>1. The cursor information is carried in TextConfig: When the application returns TextConfig in [OH_TextEditorProxy_GetTextConfigFunc](capi-inputmethod-text-editor-proxy-capi-h. md#oh_texteditorproxy_gettextconfigfunc) callback, CursorInfo notifies the input method of the current cursor position and size. <br>2. Actively notify cursor update: when the cursor position changes(e.g. cursor shift caused by user moving or text insertion) The application notifies the input method of the latest cursor position through the [OH_InputMethodProxy_NotifyCursorUpdate](capi-inputmethod-inputmethod-proxy-capi-h. md#oh_inputmethodproxy_notifycursorupdate). <br> <br>Relationship with other structures:<br>-Relationship with InputMethod_TextConfig: CursorInfo is a sub-attribute of TextConfig. When the application returns TextConfig in the [OH_TextEditorProxy_GetTextConfigFunc]( capi-inputmethod-text-editor-proxy-capi-h. md#oh_texteditorproxy_gettextconfigfunc) callback, TextConfig contains CursorInfo. The input method obtains cursor information through [OH_TextConfig_GetCursorInfo](capi-inputmethod-text-config-capi-h. md#oh_textconfig_getcursorinfo). Therefore, the application needs to create CursorInfo, set the correct cursor coordinates, and then put CursorInfo into TextConfig in the GetTextConfig callback. <br>-Relationship with OH_InputMethodProxy_NotifyCursorUpdate: CursorInfo is directly transferred as a parameter of the NotifyCursorUpdate function and is used to notify the input method when the cursor position changes. After an app creates or updates CursorInfo, the app sends the latest cursor information to the input method through NotifyCursorUpdate. <br>- Relationship with InputMethod_InputMethodProxy: The NotifyCursorUpdate function requires the InputMethod_InputMethodProxy parameter(returned by Attach) and the InputMethod_CursorInfo parameter. The inputMethodProxy parameter identifies the interaction channel and the cursorInfo parameter carries the cursor information. <br> <br>Handles and ownership: Only valid handles created by this API or borrowed handles provided by the framework can be used. Only independently created objects can be destroyed. The object provided by the callback and the child object view of TextConfig are borrowed objects. The provider returns IME_ERR_PARAMCHECK for an unregistered or invalid handle. The null parameter still returns an error according to the original rule. <br>Protection boundary: Lifecycle check does not ensure thread safety of object members, nor does it identify all invalid addresses after address reuse. After the object is destroyed, the pointer should be null. The callback object must not be retained after the callback ends.
