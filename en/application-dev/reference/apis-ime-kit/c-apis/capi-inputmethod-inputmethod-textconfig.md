# InputMethod_TextConfig

```c
typedef struct InputMethod_TextConfig InputMethod_TextConfig
```

## Overview

Structure for configuring the text input behavior of the text input box. The input box transfers core input rules to the input method framework. The input method framework executes the corresponding input behavior based on the configuration. You can configure input attributes (such as the input type and text format) to meet input requirements in different scenarios and improve user input experience. This mode is applicable to text input scenarios that require refined control of input behavior. This structure is of the opaque type. The caller cannot directly access its internal members and can perform operations only through the function interface provided by this module. <br> <br>Function of the structure: <br>InputMethod_TextConfig carries the configuration information of the edit box. including input type, enter key type, pre-screen support, selection range, cursor information, avoidance information, window ID, placeholder text, abilityName, etc. The configuration information is used in the [OH_TextEditorProxy_GetTextConfigFunc](capi-inputmethod-text-editor-proxy-capi-h. md#oh_texteditorproxy_gettextconfigfunc) callback. Developers need to set configuration items in the config parameter in the callback. The input method framework adjusts the keyboard layout and input behavior accordingly. <br><br>InputMethod_TextConfig contains the following substructure information: <br>- [InputMethod_CursorInfo](capi-inputmethod-inputmethod-cursorinfo.md): cursor information, including the cursor position and height. This command can be obtained through [OH_TextConfig_GetCursorInfo](capi-inputmethod-text-config-capi-h.md#oh_textconfig_getcursorinfo). It returns a writable borrowable view with embedded cursor information by outputting double pointers. No new object is allocated and no ownership is transferred. <br>- [InputMethod_TextAvoidInfo](capi-inputmethod-inputmethod-textavoidinfo.md): avoidance information, including the location and size of the avoidance area. It can be obtained through [OH_TextConfig_GetTextAvoidInfo](capi-inputmethod-text-config-capi-h.md#oh_textconfig_gettextavoidinfo). The output double pointer returns a writable borrowable view with embedded avoidance information. No new object is allocated and no ownership is transferred. <br> <br> Related functions: <br> <br> - Create/Destroy function: <br>
