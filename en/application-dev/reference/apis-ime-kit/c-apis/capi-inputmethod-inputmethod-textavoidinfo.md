# InputMethod_TextAvoidInfo

```c
typedef struct InputMethod_TextAvoidInfo InputMethod_TextAvoidInfo
```

## Overview

Text box avoidance information structure, which describes the position and height of the text box on the physical screen. The input method framework calculates the avoidance area based on positionY and height in TextAvoidInfo. When the soft keyboard pops up, the edit box can automatically move up or adjust the layout. This ensures that the input area is not blocked by the keyboard and the input content can be viewed and operated by users. <br> <br>Use: Serves as a parameter carrier for the edit box to avoid the keyboard area and transmits the vertical position and height information of the edit box to the input method framework. Input method framework based on positionY (Y coordinate at the top of the edit box. The value must be greater than or equal to 0.) and height (height of the edit box. The value must be a valid height value greater than 0.) Determine the complete vertical range (positionY to positionY+height) of the edit box on the screen, compare it with the screen area occupied by the keyboard, and calculate whether to avoid and the offset. <br> <br>Application scenario: After the edit box is bound to the input method service (through OH_InputMethodController_Attach), the edit box client transfers TextAvoidInfo to the input method framework through InputMethod_TextConfig. When the keyboard pops up, the input method framework reads the avoidance information, determines whether the edit box is in the keyboard block area, and triggers the corresponding avoidance adjustment.
