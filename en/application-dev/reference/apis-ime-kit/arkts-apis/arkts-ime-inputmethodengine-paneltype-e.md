# PanelType

Enumerates the types of the input method panel.<br> <br>

| Name | Value| Description |  
| ------------ | -- | ------------------ |  
| [SOFT_KEYBOARD](arkts-ime-inputmethodengine-paneltype-e.md) | 0 | Soft keyboard type.|
| [STATUS_BAR](arkts-ime-inputmethodengine-paneltype-e.md) | 1 | Status bar type.|

**Since:** 10

**System capability:** SystemCapability.MiscServices.InputMethodFramework

## SOFT_KEYBOARD

```TypeScript
SOFT_KEYBOARD = 0
```

Panel for displaying a virtual software keyboard.

**Since:** 10

**System capability:** SystemCapability.MiscServices.InputMethodFramework

## STATUS_BAR

```TypeScript
STATUS_BAR
```

Panel for displaying status bar.

**Since:** 10

**System capability:** SystemCapability.MiscServices.InputMethodFramework
