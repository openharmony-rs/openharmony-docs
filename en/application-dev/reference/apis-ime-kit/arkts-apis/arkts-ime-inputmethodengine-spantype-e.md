# SpanType

```TypeScript
export enum SpanType
```

Enumerates the types of spans in the rich text.<br> <br>

| Name | Value| Description |  
| -------- | -- | -------- |  
| TEXT | 0 | Plain text.|  
| IMAGE | 1 | Image.|  
| SYMBOL | 2 | Symbol.|  
| CUSTOM | 3 | Custom.|

**Since:** 26.1.0
