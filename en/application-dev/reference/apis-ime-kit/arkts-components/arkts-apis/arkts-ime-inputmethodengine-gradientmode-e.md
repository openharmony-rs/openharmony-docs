# GradientMode

```TypeScript
export enum GradientMode
```

Enumerates the gradient modes of the input method.<br> <br>

| Name | Value| Description |  
| ------------ | -- | ------------------ |  
| NONE | 0 | The gradient mode is not used.|
| [LINEAR_GRADIENT](arkts-ime-inputmethodengine-gradientmode-e.md) | 1 | Linear gradient.|

**Since:** 20

**System capability:** SystemCapability.MiscServices.InputMethodFramework

## NONE

```TypeScript
NONE = 0
```

Disable gradient mode.

**Since:** 20

**System capability:** SystemCapability.MiscServices.InputMethodFramework

## LINEAR_GRADIENT

```TypeScript
LINEAR_GRADIENT = 1
```

Linear gradient mode.

**Since:** 20

**System capability:** SystemCapability.MiscServices.InputMethodFramework
