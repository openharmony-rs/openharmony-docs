# HyperSnapErrorCode

Enumerates the Hyper Snap error codes.

**Since:** 26.1.0

**System capability:** SystemCapability.Ability.AbilityRuntime.Core

## ERR_OK

```TypeScript
ERR_OK = 0
```

No error.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.Ability.AbilityRuntime.Core

## ERR_SYSTEM_INNER

```TypeScript
ERR_SYSTEM_INNER = 1
```

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.Ability.AbilityRuntime.Core
