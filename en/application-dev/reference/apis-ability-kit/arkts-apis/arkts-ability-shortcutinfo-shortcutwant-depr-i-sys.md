# ShortcutWant (System API)


> **NOTE:** 
> 
> This API has been supported since API version 7 and deprecated since API version 9. You are advised to use
> [bundleManager-ShortcutWant](#shortcutwant-system-api) instead.

**Since:** 7

**Deprecated since:** 9

**Substitutes:** [ShortcutWant](#shortcutwant-system-api)

**System capability:** SystemCapability.BundleManager.BundleFramework

**System API:** This is a system API.

## targetBundle

```TypeScript
readonly targetBundle: string
```

Target bundle of the shortcut.

**Type:** string

**Since:** 7

**Deprecated since:** 9

**Substitutes:** targetBundle

**System capability:** SystemCapability.BundleManager.BundleFramework

**System API:** This is a system API.
