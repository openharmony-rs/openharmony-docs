## Summary

### Interfaces

| Name | Description |
| --- | --- |
| [AbilityMonitor](arkts-ability-abilitymonitor-i.md) | The module provides the capability of listening for lifecycle state changes of a specified [UIAbility](arkts-ability-app-ability-uiability-uiability-c.md). You can use AbilityMonitor as an input parameter of [abilityDelegator.addAbilityMonitor](arkts-ability-abilitydelegator-i.md#addabilitymonitor) to register a listener. |
