# PluginBundleInfo

The module defines plugin information, which is obtained through the
 [bundleManager.getAllPluginInfo](arkts-ability-bundlemanager-getallplugininfo-f-sys.md) API.

> **NOTE**
 >
 > The APIs provided by this module are system APIs.



## Summary

### Interfaces

| Name | Description |
| --- | --- |
| [PluginBundleInfo](arkts-ability-pluginbundleinfo-i.md) | Defines the plugin information. |
| [PluginModuleInfo](arkts-ability-pluginbundleinfo-pluginmoduleinfo-i.md) | Defines the module information of a plugin. |
