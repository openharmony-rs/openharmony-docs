# BundleInfo(BundleInfo)

## Summary

### Interfaces

| Name | Description |
| --- | --- |
| [AlternateIconInfo](arkts-ability-bundleinfo-alternateiconinfo-i.md) | Describes the app backup icon information. |
| [AppCloneIdentity](arkts-ability-bundleinfo-appcloneidentity-i.md) | Describes the identity information of an application clone. |
| [BundleInfo](arkts-ability-bundleinfo-i.md) | The module defines the bundle information. An application can obtain its own bundle information through [bundleManager.getBundleInfoForSelf](arkts-ability-bundlemanager-getbundleinfoforself-f.md), with [bundleFlags](arkts-ability-bundlemanager-bundleflag-e.md) set to the information to be contained in the returned [BundleInfo](arkts-ability-bundleinfo-i.md). |
| [ReqPermissionDetail](arkts-ability-bundleinfo-reqpermissiondetail-i.md) | Provides the detailed information of the permissions to request from the system. |
| [SignatureInfo](arkts-ability-bundleinfo-signatureinfo-i.md) | Describes the signature information of the app package, which can identify the app source, ensure app integrity, and be used for app security verification and identification. |
| [UsedScene](arkts-ability-bundleinfo-usedscene-i.md) | Describes the use scenario and timing of the permission, helping developers request and use permissions properly. |
