# OH_AbilityRuntime_ModObjExtensionInfoHandle

```c
typedef struct OH_AbilityRuntime_ModObjExtensionInfoHandle OH_AbilityRuntime_ModObjExtensionInfoHandle
```

## Overview

Represents the information handle of a single ModularObjectExtensionAbility. The handle points to the complete information of a ModularObjectExtensionAbility, including attributes such as the launch mode, process mode, thread mode, component name (AbilityBase_Element), and disabled state.

**System capability**: SystemCapability.Ability.AbilityRuntime.Core
