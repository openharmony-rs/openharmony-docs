# CliToolEvent (System API)

```TypeScript
export interface CliToolEvent
```

Describes an event generated by a CLI tool or command during execution.

**Since:** 26.0.0

**System capability:** SystemCapability.Ability.AgentRuntime.Core

**System API:** This is a system API.

## data

```TypeScript
data: string
```

Indicates the data payload of this tool event.

**Type:** string

**Since:** 26.0.0

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.Ability.AgentRuntime.Core

**System API:** This is a system API.

## toolEventType

```TypeScript
toolEventType: ToolEventType
```

**Since:** 26.0.0
