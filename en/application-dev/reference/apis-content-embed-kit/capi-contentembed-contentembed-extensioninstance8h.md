## Overview

Defines the pointer type of the OE extension instance. In the [OH_AbilityRuntime_OnNativeExtensionCreate](../apis-ability-kit/capi-extension-ability-h.md#oh_abilityruntime_onnativeextensioncreate) function, you need to obtain the OE extension instance when the OE extension is started by calling [OH_ContentEmbed_Extension_GetExtensionInstance](capi-content-embed-extension-h.md#oh_contentembed_extension_getextensioninstance).
