## isFrameType4Supported

```TypeScript
function isFrameType4Supported(): boolean
```

Checks whether the current device supports radio frame type 4.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.1.0.

<!--Device-manager-function isFrameType4Supported(): boolean--><!--Device-manager-function isFrameType4Supported(): boolean-End-->

**System capability:** SystemCapability.Communication.NearLink.Base

**Return value:**

| Type | Description |
| --- | --- |
| boolean | Whether the current device supports radio frame type 4. The value **true** indicates that the device supports radio frame type 4, and **false** indicates the opposite. |
