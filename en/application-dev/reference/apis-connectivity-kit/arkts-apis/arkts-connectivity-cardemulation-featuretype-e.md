# FeatureType

```TypeScript
enum FeatureType
```

Enumerates the NFC card emulation types.

> **NOTE:** 
> 
> This API is supported since API version 6 and deprecated since API version 9. Use
> [hasHceCapability](arkts-connectivity-cardemulation-hashcecapability-f.md) instead.

**Since:** 6

**Deprecated since:** 9
