# AdvertisingParams

Enumerates the advertising parameters.

**Since:** 26.0.0

**System capability:** SystemCapability.Communication.NearLink.Base

## Modules to Import

```TypeScript
import { advertising } from '@kit.ConnectivityKit';
```

```TypeScript
advertisingData: AdvertisingData
```
