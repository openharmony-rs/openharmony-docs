# RemoteDeviceDriver

Represents information about a remote device driver.

**Since:** 11

**System capability:** SystemCapability.Driver.ExternalDevice

## Modules to Import

```TypeScript
import { deviceManager } from '@kit.DriverDevelopmentKit';
```

## deviceId

```TypeScript
deviceId: number
```

ID of the peripheral device.

**Type:** number

**Since:** 11

**System capability:** SystemCapability.Driver.ExternalDevice
