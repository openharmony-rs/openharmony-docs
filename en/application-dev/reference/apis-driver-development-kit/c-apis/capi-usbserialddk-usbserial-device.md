# UsbSerial_Device

```c
typedef struct UsbSerial_Device UsbSerial_Device
```

## Overview

Defines the data structures for the USB serial port device (opaque), which is used to indicate the USB serial port device. You can obtain this structure instance by calling the [OH_UsbSerial_Open](capi-usb-serial-api-h.md#oh_usbserial_open) API.

**System capability**: SystemCapability.Driver.UsbSerial.Extension

**Since**: 18

**Related module**: [USBSerialDDK](capi-others-usbserialddk.md)

**Header file**: [usb_serial_types.h](capi-usb-serial-types-h.md)
