# hid_ddk_types.h

## Overview

Defines the enum variables and structs used in the HID DDK, allowing you to define and operate HID devices during driver development. This module is applicable to scenarios where input devices such as the mouse, keyboard, and touchscreen are used. It provides comprehensive definitions of device features, event types, key value encoding, and coordinate axes, helping you quickly develop drivers for HID devices.

**File to Include**: <hid/hid_ddk_types.h>

**Library**: libhid.z.so

**System capability**: SystemCapability.Driver.HID.Extension

**Since**: 11

**Related module**: [HidDdk](capi-driver-development-kit-hidddk.md)
