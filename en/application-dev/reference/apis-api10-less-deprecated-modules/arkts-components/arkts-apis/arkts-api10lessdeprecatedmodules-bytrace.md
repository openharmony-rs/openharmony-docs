# @ohos.bytrace(Performance Tracing)

The **bytrace** module implements performance tracing for processes.

> **NOTE:** 
> 
> - The APIs provided by this module are deprecated since API version 8. You are advised to use the new APIs [@ohos.hiTraceMeter](../../apis-performance-analysis-kit/arkts-apis/arkts-performanceanalysis-hitracemeter.md) instead.
