## Overview

Provides C APIs for the scan module, which support functions such as discovering and connecting to scanners, scanning images from scanners, obtaining the image scanning progress, and setting scanner parameters. You can integrate scanner-related operations into your app. For details about the APIs, see [ohscan.h](capi-ohscan-h.md).
