# @ohos.annotation(Annotation)

This module defines the annotation types of OpenHarmony ArkTS APIs, such as the minimum available version
 of the lifecycle and suppressing warnings generated by APIs.
 It helps developers identify and manage API features such as compatibility and warning suppression.
 This module addresses issues such as version compatibility warnings, permission warnings,
 and multi-device adaptation warnings encountered during cross-version development
 and third-party SDK integration.
 Annotations are used to suppress unnecessary warnings, improving code maintainability
 and development efficiency.

> **NOTE**
 >
 > - The initial APIs of this module are supported since API version 22.
 >   Newly added APIs will be marked with a superscript to indicate their earliest API version.



## Modules to Import

```TypeScript
import { Available, SuppressWarnings, SuppressWarningsType } from '@kit.BasicServicesKit';
```

## Summary

### Annotation

| Name | Description |
| --- | --- |
| [Available](arkts-basicservices-annotation-available-a.md) | Annotates the minimum available version supported by an API. This annotation capability can be used on classes, interfaces, functions, variables, types, modules, and enums. After the annotation is added to the source code, the compilation tool checks for potential compatibility issues. If the value of minApiVersion is greater than that of compatibleSdkVersion specified in build-profile.json5, a compatibility warning is reported. |
| [SuppressWarnings](arkts-basicservices-annotation-suppresswarnings-a.md) | Suppresses warnings generated by APIs. This annotation capability is provided by the system and can be used on classes, functions, variables, types, and interfaces. After the corresponding annotation is added to the source code, the compiler automatically suppresses the corresponding warning based on the preset rules. The preset rules are applicable to compatibility warnings generated when the API version is later than the compatible version, multi-device warnings generated when the device does not support a system capability, and permission warnings generated when the permission configuration is missing. This module can be used to temporarily ignore certain warnings in specific scenarios or prevent the compiler from generating interfering warnings. This helps you focus on key issues and improve development efficiency. |

### Enums

| Name | Description |
| --- | --- |
| [SuppressWarningsType](arkts-basicservices-annotation-suppresswarningstype-e.md) | Defines the warning types that support suppression. Developers can selectively suppress compatibility warnings, multi-device warnings, and permission warnings as required. This helps ensure code quality, reduce unnecessary warning interference, and improve development experience. |
