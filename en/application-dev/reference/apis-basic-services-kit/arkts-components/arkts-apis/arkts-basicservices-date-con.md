# Constants

## AUTO_GAIN_TIME

```TypeScript
const AUTO_GAIN_TIME: string
```

Specifies whether the date, time, and time zone are automatically obtained from the Network Identity and Time Zone (NITZ).

<p>If the value is `true`, the information is automatically obtained from NITZ. If the value is `false`, the information is not obtained from NITZ.

**Type:** string

**Since:** 7

**Deprecated since:** 21

**System capability:** SystemCapability.Applications.Settings.Core

## DATE_FORMAT

```TypeScript
const DATE_FORMAT: string
```

Indicates the date format.

<p>The formats `mm/dd/yyyy`, `dd/mm/yyyy`, and `yyyy/mm/dd` are available.

**Type:** string

**Since:** 7

**Deprecated since:** 21

**System capability:** SystemCapability.Applications.Settings.Core

## TIME_FORMAT

```TypeScript
const TIME_FORMAT: string
```

Specifies whether the time is displayed in 12-hour or 24-hour format.

<p>If the value is `12`, the 12-hour format is used. If the value is `24`, the 24-hour format is used.

**Type:** string

**Since:** 7

**System capability:** SystemCapability.Applications.Settings.Core
