# StopBits

Enumerates the number of stop bits.

**Since:** 26.0.0

**System capability:** SystemCapability.BusManager.Serial

## ONE

```TypeScript
ONE = 1
```

One stop bit.

**Since:** 26.0.0

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.BusManager.Serial

## TWO

```TypeScript
TWO = 2
```

Two stop bits.

**Since:** 26.0.0

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.BusManager.Serial
