# SuppressWarnings

```TypeScript
export @interface SuppressWarnings
```

Suppresses warnings generated by APIs. This annotation capability is provided by the system and can be used on classes, functions, variables, types, and interfaces. After the corresponding annotation is added to the source code, the compiler automatically suppresses the corresponding warning based on the preset rules. The preset rules are applicable to compatibility warnings generated when the API version is later than the compatible version, multi-device warnings generated when the device does not support a system capability, and permission warnings generated when the permission configuration is missing. This module can be used to temporarily ignore certain warnings in specific scenarios or prevent the compiler from generating interfering warnings. This helps you focus on key issues and improve development efficiency.

**Since:** 23

**System capability:** SystemCapability.Base

## Modules to Import

```TypeScript
import { Available, SuppressWarnings, SuppressWarningsType } from '@kit.BasicServicesKit';
```

## rules

```TypeScript
rules: Array<SuppressWarningsType>
```

Rules that support warning suppression. This parameter is used to specify the types of warnings to be suppressed. Multiple rules can be passed through an array to suppress multiple types of warnings. The array must contain at least one element. For details about the options, see [SuppressWarningsType](arkts-basicservices-annotation-suppresswarningstype-e.md). You are advised to use this parameter only after confirming that the warning does not affect app functions or compatibility processing has been performed. This prevents potential problems from being covered up.

**Type:** Array&lt;[SuppressWarningsType](arkts-basicservices-annotation-suppresswarningstype-e.md)&gt;

**Since:** 23

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 23.

**Widget capability:** This API can be used in ArkTS widgets since API version 23.

**System capability:** SystemCapability.Base
