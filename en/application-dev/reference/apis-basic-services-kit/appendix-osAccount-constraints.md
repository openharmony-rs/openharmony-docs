| Constraint                                 | Description                          |
| ------------------------------------- | ------------------------------ |
| constraint.os.account.remove | Disallow removal of OS accounts.|
| constraint.os.account.create | Disallow creation of new OS accounts.|
| constraint.os.account.set.icon | Disallow setting of OS account icons.|
| constraint.os.account.activate | Disallow activating of OS accounts in the foreground.|
