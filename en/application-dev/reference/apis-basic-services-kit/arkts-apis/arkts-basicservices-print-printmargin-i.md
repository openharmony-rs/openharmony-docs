# PrintMargin

Defines the page margins for printing.

**Since:** 24

**System capability:** SystemCapability.Print.PrintFramework

## Modules to Import

```TypeScript
import { print } from '@kit.BasicServicesKit';
```

## bottom

```TypeScript
bottom?: number
```

Bottom margin of the page, in millimeters. The default value is **0**.

**Type:** number

**Since:** 24

**System capability:** SystemCapability.Print.PrintFramework
