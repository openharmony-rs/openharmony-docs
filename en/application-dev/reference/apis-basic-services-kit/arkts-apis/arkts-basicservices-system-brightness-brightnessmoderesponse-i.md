# BrightnessModeResponse

Defines a response that returns the screen brightness mode.

**Since:** 3

**Deprecated since:** 7

## mode

```TypeScript
mode: number
```

The value **0** indicates the manual adjustment mode, and the value **1** indicates the automatic adjustment mode.

**Type:** number
