# getAuthorizationManager

## Modules to Import

import { authorization } from '@kit.BasicServicesKit';

## getAuthorizationManager

```TypeScript
function getAuthorizationManager(): AuthorizationManager
```

Obtains an [AuthorizationManager](arkts-basicservices-authorization-authorizationmanager-i.md) instance.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**System capability:** SystemCapability.Account.OsAccount

**Return value:**

| Type | Description |
| --- | --- |
| [AuthorizationManager](arkts-basicservices-authorization-authorizationmanager-i.md) | Instance of the authorization manager. |
