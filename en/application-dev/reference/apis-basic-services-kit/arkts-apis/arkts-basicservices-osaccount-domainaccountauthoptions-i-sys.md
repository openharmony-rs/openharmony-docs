# DomainAccountAuthOptions (System API)

Defines the options for domain account authentication.

**Since:** 24

**System capability:** SystemCapability.Account.OsAccount

**System API:** This is a system API.

## Modules to Import

```TypeScript
import { osAccount } from '@kit.BasicServicesKit';
```

## serverParams

```TypeScript
serverParams?: Record<string, Object>
```

Configuration parameters of the domain account authentication server. The default value is **undefined**.

**Type:** Record&lt;string, Object&gt;

**Since:** 24

**System capability:** SystemCapability.Account.OsAccount

**System API:** This is a system API.
