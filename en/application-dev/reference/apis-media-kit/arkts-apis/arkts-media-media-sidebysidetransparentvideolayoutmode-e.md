# SideBySideTransparentVideoLayoutMode

```TypeScript
enum SideBySideTransparentVideoLayoutMode
```

Transparent video layout enumeration definition in side-by-side mode; It is used to specify the position of alpha data of the transparent video in the image, so that the player can correctly synthesize the transparent video.

**Since:** 26.1.0

<!--Device-media-enum SideBySideTransparentVideoLayoutMode--><!--Device-media-enum SideBySideTransparentVideoLayoutMode-End-->

**System capability:** SystemCapability.Multimedia.Media.Core

## SIDE_BY_SIDE_LAYOUT_HORIZONTAL

```TypeScript
SIDE_BY_SIDE_LAYOUT_HORIZONTAL = 0
```

Indicates that the transparent video is left-right layout, and the left data is alpha data.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.
