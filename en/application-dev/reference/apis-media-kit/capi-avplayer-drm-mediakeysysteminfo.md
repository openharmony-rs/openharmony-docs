## Overview

Defines the **DRM_MediaKeySystemInfo** struct, which is used to store and manage DRM media key system information.

**Use scenarios**
- Obtains DRM system information during online video playback.
- Queries the media key system status in copyright protection applications.
- Passes key system configuration information during the DRM authentication process.
