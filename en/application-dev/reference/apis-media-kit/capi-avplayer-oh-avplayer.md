## Overview

**OH_AVPlayer** is the core struct of the media player, which is used to manage audio/video playback and support multiple media formats, playback control, and state listening. With this struct, you can easily load, play, pause, and fast-forward media files. It applies to scenarios such as audio/video playback, streaming media playback, and local media file processing, effectively improving the development efficiency of media playback and user experience.
