# AVRecorder

## Overview

AVRecorder enables media recording and supports configuration of recording parameters and real-time status callback. It is suitable for scenarios where audio and video need to be recorded and saved as files, such as video call recording and voice notes.<br> You can refer to the corresponding development guide and samples based on your development requirements.<br> - [Using AVRecorder to Record Audio (C/C++)](../../../media/media/using-ndk-avrecorder-for-audio-recording.md)<br> - [Using AVRecorder to Record Videos (C/C++)](../../../media/media/using-ndk-avrecorder-for-video-recording.md)<br>
