# OH_VideoProcessing

```c
typedef struct OH_VideoProcessing OH_VideoProcessing
```

## Overview

Define the video processing object.<br> Define a null pointer of OH_VideoProcessing and call [OH_VideoProcessing_Create](capi-video-processing-h.md#oh_videoprocessing_create) to create a video processing instance. The pointer should be null before creating instance. User can create multiple video processing instances for different processing types.
