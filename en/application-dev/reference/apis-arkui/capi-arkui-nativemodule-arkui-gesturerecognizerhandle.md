## Overview

Defines a gesture recognizer handle, which is an alias wrapper of the **ArkUI_GestureRecognizer** pointer type and is used to represent a gesture recognizer object in the ArkUI native gesture APIs. This handle can be used as an object reference in scenarios such as gesture recognizer creation, property configuration, and event callback listening, facilitating unified passing, management, and operation of gesture recognizers at the native layer. For details about how to obtain and use it, see [native_gesture.h](capi-native-gesture-h.md).
