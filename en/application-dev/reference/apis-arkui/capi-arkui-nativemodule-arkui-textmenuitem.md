## Overview

Defines a text menu item, used to represent a single menu item in a text selection menu. This struct supports setting attributes such as the title, icon, and enabled state of the menu item. It is applicable to scenarios where you need to customize text selection menu content and menu item extension, helping you flexibly customize the text selection menu.
