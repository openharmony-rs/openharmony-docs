## Overview

Defines **OHNativeWindow**, which is a wrapper of the native window. It provides a surface for graphics rendering at the native layer, and supports operations such as obtaining window capabilities, setting/obtaining window properties, and refreshing window buffers. It is applicable to scenarios such as graphics rendering and image display at the native layer.
