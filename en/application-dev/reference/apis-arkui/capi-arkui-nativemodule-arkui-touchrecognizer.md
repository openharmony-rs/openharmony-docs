## Overview

Defines a touch recognizer. A touch recognizer is used to represent the touch event processing object returned in gesture interruption or gesture collection interception information. You can obtain its node handle or cancel the touch event through related APIs. For details about the APIs, see [native_gesture.h](capi-native-gesture-h.md).
