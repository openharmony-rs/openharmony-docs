## Overview

Defines the navigation indicator style of the **Swiper** component, which is used to display the current position and switching state in scenarios such as carousels. It supports custom configuration of attributes such as the indicator size, color, and spacing, which improves the user's awareness of the current browsing position and enhances the user interaction experience. It is applicable to various application scenarios such as displaying carousel images, ad slots, and content navigation.
