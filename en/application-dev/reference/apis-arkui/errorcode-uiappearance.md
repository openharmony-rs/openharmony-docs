## 500001 Internal Error

**Error Message**

Internal error.

**Description**

This error code is reported when an internal error occurs, for example, a parameter persistence error, a failure to obtain the service, or a failure to set the color mode.

**Possible Causes**

A parameter persistence error, a failure to obtain the service, or a failure to set the color mode occurs.

**Solution**

1. Verify that the parameter persistence configuration is correct.
2. Verify that the related service is running properly.
3. Verify that the color mode setting is correct. If the problem persists, restart the application or contact technical support.
