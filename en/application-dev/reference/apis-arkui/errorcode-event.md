> **NOTE**
>
> The interaction event error codes are used to locate exceptions in component event handling, event dispatching, scrollable containers, gesture recognizers, and event data operations, helping you quickly select the correct component, event, or API parameter based on the error cause and resolve the issue. Only the error codes specific to this module are described below. For details about the universal error codes, see [Universal Error Codes](../errorcode-universal.md).

## 100017 Component Does Not Support Default Event Prevention

**Error Message**

Component does not support prevent function.

**Description**

This error code is reported when the component does not support preventing the default event. This error code is of the string type.

**Possible Causes**

The component used does not support the [preventDefault](./arkui-ts/ts-universal-events-touch.md#touchevent) API.

**Solution**

Use the component that supports the **preventDefault** functionality.

## 106102 Unsupported Component Attributes or Events

**Error Message**

The component does not support specific properties or events.

**Description**

This error code is reported when the component does not support the specified properties or events. This error code is of the string type.

**Possible Causes**

The component does not support the currently set attribute or event.

**Solution**

Use a component that supports the current property or event.

## 180001 Component Is Not a Scrollable Container

**Error Message**

Component is not a scroll container.

**Description**

This error code is reported when the container is not scrollable. This error code is of the string type.

**Possible Causes**

The component being used is not a scrollable container.

**Solution**

Use a scrollable container.

## 180002 Buffer Is Not Large Enough

**Error Message**

Buffer is not large enough.

**Description**

This error code is reported when the storage buffer is insufficient. This error code is of the string type.

**Possible Causes**

The length of the passed-in array is less than the length required by the API.

**Solution**

Expand the size of the input array.

## 180003 Input Event Is Not a Cloned Event

**Error Message**

The input event pointer is not a cloned event pointer.

**Description**

This error code is reported when the event is not a cloned event. This error code is of the string type.

**Possible Causes**

When calling the cloned event API, you must pass in the pointer to a cloned event generated by the cloned event API.

**Solution**

Use the cloned event pointer as the API parameter.

## 180004 Abnormal Component State

**Error Message**

The component status is abnormal.

**Description**

This error code is reported when the component is in an abnormal state. This error code is of the string type.

**Possible Causes**

The component state is abnormal when the cloned event is dispatched to the component.

**Solution**

Use the component that has been mounted but is not destroyed.

## 180005 No Component Hit to Respond to the Event

**Error Message**

No component hit to response to the event.

**Description**

This error code is reported when no component is found to handle the event. This error code is of the string type.

**Possible Causes**

No component is available to handle the event when the cloned event is dispatched.

**Solution**

Add an event listener for the component, or use a component that supports response to the event.

## 180006 Input Event Type Not Supported

**Error Message**

Input event type not supported.

**Description**

This error code is reported when the input event type is not supported. This error code is of the string type.

**Possible Causes**

The current API does not support the input event type passed in.

**Solution**

Pass an input event object of a type supported by this API as described in the API documentation.

## 180102 Gesture Recognizer Type Is Not Supported

**Error Message**

The gesture recognizer type is not supported.

**Description**

This error code is reported when the gesture recognizer type is not supported. This error code is of the string type.

**Possible Causes**

The gesture recognizer type specified in the gesture API is not supported.

**Solution**

Call the gesture recognizer that matches the type.
