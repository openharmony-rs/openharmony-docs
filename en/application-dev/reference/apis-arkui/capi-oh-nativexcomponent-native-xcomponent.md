## Overview

**OH_NativeXComponent** provides the surface and touch event capabilities held by the ArkUI **XComponent**, which can be used for displaying custom drawing content such as EGL/OpenGL ES rendering output and media data on the screen, and implements event interaction such as touch between the native layer and ArkUI. It is applicable to scenarios such as game/graphics rendering, video playback, and camera preview that require high-performance drawing on the native side and interactive linkage with ArkUI. For details, see [NativeXComponent](../../ui/napi-xcomponent-guidelines.md).
