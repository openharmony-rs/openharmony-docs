## Overview

Defines **OH_NativeXComponent**, which is the native‑side instance wrapper for **XComponent** provided by ArkUI. It is used to embed custom rendering content (such as EGL/OpenGL ES/Vulkan rendering surfaces) on ArkUI pages, and supports event interaction between the native layer and the ArkUI layer, including touch events and size changes. It applies to scenarios such as games, maps, and video rendering that require integrating high-performance custom drawing content into applications.
