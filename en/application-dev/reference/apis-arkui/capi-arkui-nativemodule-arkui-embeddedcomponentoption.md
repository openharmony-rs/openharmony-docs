## Overview

Defines the **ArkUI_EmbeddedComponentOption** parameter for **EmbeddedComponent**, which is used to set the configuration option of the component when creating or configuring **EmbeddedComponent**. It is applicable to embedded UI development scenarios where the UI provided by an **EmbeddedUIExtensionAbility** within the current application (or one that meets the cross-application embedding permission conditions) needs to be embedded into a page and its lifecycle needs to be managed.
