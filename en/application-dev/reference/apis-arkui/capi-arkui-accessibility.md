## Overview

Describes the native capabilities provided by ArkUI Accessibility, such as querying accessibility nodes and reporting accessibility events. It is applicable to scenarios where third-party platforms need to integrate their own UI components into the ArkUI accessibility system and interact with the system accessibility capabilities, helping you build accessibility features and improve the accessibility experience of applications.
