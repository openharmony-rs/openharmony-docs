## Overview

Defines gesture collection interception information, which describes the interception-related information in gesture collection interception scenarios. It implements interception decision and process control for gesture events, and is applicable to scenarios that require fine-grained management of gesture collection and interception. For details about the APIs related to gesture collection interception, see [native_gesture.h](capi-native-gesture-h.md).
