## Overview

Defines touch test information items. Touch test information items contain information about child components in a touch test. They are applicable to scenarios where child component information needs to be obtained and identified during a touch test. You can use the [OH_ArkUI_TouchTestInfoItem_Get](./capi-ui-input-event-h.md#oh_arkui_touchtestinfoitem_getx)XXX series APIs to obtain child component information, helping you process touch test results.
