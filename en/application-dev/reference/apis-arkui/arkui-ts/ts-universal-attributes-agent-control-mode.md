Agent input control is used to set the control level of a component over input events generated by an agent. It applies to scenarios where input events generated by an agent need to be restricted from operating on sensitive or critical components, thereby improving the controllability of an application over agent input operations.

**Since:** 26.1.0

## agentControlMode

agentControlMode(value: AgentControlMode | undefined): T

Sets the input control level of a component for events generated by an agent. Events generated by an agent include events generated by the system agent and events injected by applications with the **ohos.permission.CONTROL_COMPONENT** permission. This setting does not affect input events generated by users or other injected events.

**Since:** 26.1.0

**Atomic service API:** This API can be used in atomic services since API version 26.1.0.

**System capability**: SystemCapability.ArkUI.ArkUI.Full

**Model restriction**: This API can be used only in the stage model.

**Parameters**

| Name | Type | Mandatory | Description |
| -------- | -------- | -------- | -------- |
| value | [AgentControlMode](ts-appendix-enums.md#agentcontrolmode)&nbsp;\|&nbsp;undefined | Yes | Input control level for events generated by an agent. When value is undefined, no control level is set, and the component processes events generated by an agent in the same way as when this attribute is not set (agent-generated event injection is allowed by default). |

**Return value**

| Type | Description |
| -------- | -------- |
| T | Current component, which is used for chained calls. |
