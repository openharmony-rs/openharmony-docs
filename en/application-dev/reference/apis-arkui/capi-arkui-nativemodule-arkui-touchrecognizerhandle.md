## Overview

Defines a touch recognizer handle, which is used to represent a touch recognizer object and to pass and manage the object in touch recognition or gesture processing APIs. It applies to scenarios such as custom gesture recognition, multi-touch event processing, and fine-grained interception and dispatch control of touch events.
