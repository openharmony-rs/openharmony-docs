## Overview

Defines the linear gradient effect options, which describe the linear color gradient configuration of a UI component. It supports setting the gradient direction, angle, and color, helping you implement flexible linear gradient effects and improve the visual presentation of the UI. It is applicable to scenarios where a linear gradient style needs to be applied to a component.
