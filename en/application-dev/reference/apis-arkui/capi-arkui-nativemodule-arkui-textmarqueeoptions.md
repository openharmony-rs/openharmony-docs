## Overview

Defines text marquee mode options, which are used to configure the display parameters of the text marquee effect. It is suitable for scenarios where long text content needs to be displayed cyclically in limited space, such as scrolling notification messages and scrolling titles, effectively solving the display problem when text exceeds the display area.
