# Text

```TypeScript
type Text = TypedFrameNode<TextInterface, TextAttribute>
```

Represents a FrameNode of the **Text** type. This type of node does not allow child components to be added.

**Since:** 12

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 12.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

**Type:** [TypedFrameNode](arkts-arkui-framenode-typedframenode-i.md)&lt;TextInterface, [TextAttribute](../arkts-components/arkts-arkui-text-comp-attribute.md)&gt;
