# ListItemGroup

```TypeScript
type ListItemGroup = TypedFrameNode<ListItemGroupInterface, ListItemGroupAttribute>
```

Represents a FrameNode of the **ListItemGroup** type. Only ListItem child components can be added.

**Since:** 12

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 12.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

**Type:** [TypedFrameNode](arkts-arkui-framenode-typedframenode-i.md)&lt;ListItemGroupInterface, [ListItemGroupAttribute](../arkts-components/arkts-arkui-listitemgroup-comp-attribute.md)&gt;
