# TitleBarType

Enumerates the title bar types. The default type is **ROUND_ICON**.

**Since:** 18

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## SQUARED_ICON

```TypeScript
SQUARED_ICON = 1
```

Square icon style.

**Since:** 18

**Atomic service API:** This API can be used in atomic services since API version 18.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
