# SplitLayout

Declare SplitLayout.The SplitLayout is used for upper and lower graphic layouts.

**Since:** 22

**Decorator:** @Component

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## Modules to Import

```TypeScript
import { SplitLayout } from '@kit.ArkUI';
```

## container

```TypeScript
container: () => void
```
