# AttributeUpdater

## Summary

### Classes

| Name | Description |
| --- | --- |
| [AttributeUpdater](arkts-arkui-attributeupdater-c.md) | Sets attributes directly to a component to trigger UI re-renders, without marking them as state variables. This is applicable to scenarios where component attributes need to be dynamically updated without defining state variables, such as dynamically modifying component constructor parameters or avoiding defining state variables for one-time attribute updates. |

### Types

| Name | Description |
| --- | --- |
| [Initializer](arkts-arkui-initializer-t.md) | Defines the type of the initialization function for component attributes, which is used to create and return an attribute instance of the component. |
