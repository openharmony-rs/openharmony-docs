# AgentControlMode

```TypeScript
declare enum AgentControlMode
```

Defines the input control mode for Agent-generated events.

Agent-generated events include events generated by a System Agent and events injected by an application with the ohos.permission.CONTROL_COMPONENT permission. The control applies only to such Agent-generated input events.

**Since:** 26.1.0

## ALLOW

```TypeScript
ALLOW = 0
```

Allows Agent-generated input operations without user confirmation.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.1.0.
