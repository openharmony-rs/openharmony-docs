# ModifierUtils

## Summary

### Classes

| Name | Description |
| --- | --- |
| [ModifierUtils](arkts-arkui-modifierutils-c.md) | **ModifierUtils** is a utility class for [AttributeModifier](../../../ui/arkts-user-defined-extension-attributeModifier.md), used to provide methods for attribute operations. For example, it can determine whether a given instance is of a specified component type. This is applicable to scenarios where different component types need to be distinguished and differentiated attribute settings need to be applied within a unified **AttributeModifier**. |
