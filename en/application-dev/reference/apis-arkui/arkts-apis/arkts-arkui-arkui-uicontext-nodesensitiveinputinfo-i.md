## isAgent

```TypeScript
isAgent: boolean
```

Whether the event is an Agent-generated event. The value **true** indicates that the event is generated by a System Agent or injected by an application with the ohos.permission.CONTROL_COMPONENT permission. The value **false** indicates a user-generated input event or another injected event.

**Type:** boolean

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.1.0.
