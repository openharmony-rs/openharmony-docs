# SegmentButtonV2InteractionMode

```TypeScript
export declare enum SegmentButtonV2InteractionMode
```

Defines the drag interaction mode of the segmented button.

**Since:** 26.2.0

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## FOLLOWING_DRAG

```TypeScript
FOLLOWING_DRAG = 0
```

Enables following drag. Without system material, only the following drag animation is enabled.

**Since:** 26.2.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.2.0.

## NORMAL_DRAG

```TypeScript
NORMAL_DRAG = 1
```

Enables normal drag. Only drag positioning and selection updates differ from following drag. System material feedback, including configured light effects, is retained.

**Since:** 26.2.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.2.0.
