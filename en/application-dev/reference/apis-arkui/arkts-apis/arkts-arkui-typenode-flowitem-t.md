# FlowItem

```TypeScript
type FlowItem = TypedFrameNode<FlowItemInterface, FlowItemAttribute>
```

Represents a FrameNode of the **FlowItem** type. This type of node allows only one child component to be added.

**Since:** 12

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 12.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

**Type:** [TypedFrameNode](arkts-arkui-framenode-typedframenode-i.md)&lt;FlowItemInterface, [FlowItemAttribute](../arkts-components/arkts-arkui-flowitem-comp-attribute.md)&gt;
