# ArkUI_DragAndDropInfo

```c
typedef struct ArkUI_DragAndDropInfo ArkUI_DragAndDropInfo
```

## Overview

Defines drag and drop information returned through a drag status listener after dragging is proactively initiated. You can obtain the drag start or end status and the drag event data when the drag ends from this struct, and perform subsequent processing based on the status. For details about how to register the drag callback, see drag_and_drop.h.
