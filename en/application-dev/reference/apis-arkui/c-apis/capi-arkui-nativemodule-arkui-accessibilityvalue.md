# ArkUI_AccessibilityValue

```c
typedef struct ArkUI_AccessibilityValue ArkUI_AccessibilityValue
```

## Overview

Defines a component accessibility value, describing the accessibility state of the component, such as the minimum, maximum, and current values of a range-type component, as well as text descriptions. It is applicable to scenarios where the current state information of a component needs to be provided to the accessibility service.
