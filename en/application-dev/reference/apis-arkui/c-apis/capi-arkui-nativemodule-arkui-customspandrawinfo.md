# ArkUI_CustomSpanDrawInfo

```c
typedef struct ArkUI_CustomSpanDrawInfo ArkUI_CustomSpanDrawInfo
```

## Overview

Defines the drawing information of a custom span, which is passed to you in the drawing callback of the span. You can obtain and use the information in the custom drawing process to achieve custom drawing effects for the span.
