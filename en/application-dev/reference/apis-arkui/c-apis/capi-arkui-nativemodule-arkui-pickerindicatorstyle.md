# ArkUI_PickerIndicatorStyle

```c
typedef struct ArkUI_PickerIndicatorStyle ArkUI_PickerIndicatorStyle
```

## Overview

Defines the style of the selected item indicator. It contains attribute configurations such as the indicator color and size, used to enhance the visual effect of the selected item in the **Picker** component and improve the user interaction experience.
