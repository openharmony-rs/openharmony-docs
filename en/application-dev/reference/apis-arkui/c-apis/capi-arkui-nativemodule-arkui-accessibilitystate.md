# ArkUI_AccessibilityState

```c
typedef struct ArkUI_AccessibilityState ArkUI_AccessibilityState
```

## Overview

Defines a component accessibility state, describing the selected, checked, disabled, and other states of the component. It is applicable to scenarios where the accessibility service reads data and interacts with the component, helping users obtain the current state of the component.
