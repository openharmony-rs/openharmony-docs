# ArkUI_RenderNodeMaskOption

```c
typedef struct ArkUI_RenderNodeMaskOption ArkUI_RenderNodeMaskOption
```

## Overview

Defines a render node mask option. It is used to describe the mask area of a render node through a rectangle, rounded rectangle, circle, ellipse, or custom path, and serves as the input parameter of [OH_ArkUI_RenderNodeUtils_SetMask](capi-native-render-h.md#oh_arkui_rendernodeutils_setmask) to apply a mask to the render node.

**System capability**: SystemCapability.ArkUI.ArkUI.Full

**Since**: 20

**Related module**: [ArkUI_RenderNodeUtils](capi-arkui-rendernodeutils.md)

**Header file**: [native_render.h](capi-native-render-h.md)
