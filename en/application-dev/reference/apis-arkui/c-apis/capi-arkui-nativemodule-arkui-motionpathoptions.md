# ArkUI_MotionPathOptions

```c
typedef struct ArkUI_MotionPathOptions ArkUI_MotionPathOptions
```

## Overview

Defines the motion path configuration options of path animation, which are used to set the trajectory and related parameters of a component moving along a specified path during animation, so that the component can perform displacement animation along the preset motion path.
