# ArkUI_CoastingAxisEvent

```c
typedef struct ArkUI_CoastingAxisEvent ArkUI_CoastingAxisEvent
```

## Overview

Defines a coasting axis event, which supports listening for the decaying sliding process generated by a two-finger swipe on the touchpad. It is suitable for handling the inertial scrolling effect after a regular axis event.<br> When the user performs a two-finger swipe on the touchpad, the system constructs a coasting axis event based on the finger lift speed, following the system-preset decaying curve. You can listen for this type of event to handle the inertial scrolling effect immediately after a regular axis event.<br> You can receive this event only when the following conditions are met: The user performs a two-finger swipe on the touchpad, and a component registered for the [NODE_ON_COASTING_AXIS_EVENT](capi-native-node-h.md#arkui_nodeeventtype) event via [registerNodeEvent](capi-arkui-nativemodule-arkui-nativenodeapi-1.md#registernodeevent) exists at the pointer position. When this event is no longer needed, unregister the event listener through [unregisterNodeEvent](capi-arkui-nativemodule-arkui-nativenodeapi-1.md#unregisternodeevent) to prevent the callback from being triggered continuously.
