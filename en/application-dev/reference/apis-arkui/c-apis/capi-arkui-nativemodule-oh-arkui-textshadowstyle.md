## Overview

Defines a text shadow style.<br> {@link OH_ArkUI_TextShadowStyle_Create} can be used to create a text<br>shadow style object.<br> {@link OH_ArkUI_TextShadowStyle_Destroy} can be used to destroy the text shadow<br>style object.<br> After the object is created, {@link OH_ArkUI_TextShadowStyle_SetTextShadow} can be used to set a style.
