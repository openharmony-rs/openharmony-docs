## Overview

Defines **ArkUI_UIInputEvent**, which represents the UI input event in ArkUI. It is used by the event APIs in the **ArkUI_EventModule** module to transfer and process input event information. It is applicable to scenarios where user input events need to be identified, distributed, or responded to.
