## Overview

Defines **OH_NativeXComponent_KeyEvent**, which is used to encapsulate the key event information of the **XComponent** component, providing key data such as the key value, action type, and event timestamp. It is applicable to scenarios where the native side receives and processes key events of the ArkUI **XComponent** component.
