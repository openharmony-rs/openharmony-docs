## 106205 Color Inversion Capability Configuration Error

**Error Message**

Force dark config is invalid.

**Description**

This error code is reported when the color inversion capability configuration is invalid.

**Possible Causes**

The parameters you pass in are incorrect, for example, the parameter values are out of the valid range or the parameter types do not match. For details about the parameter constraints, see the API description related to the color inversion capability.

**Solution**

Check and modify the parameters passed in to ensure that the parameter values and types meet the color inversion capability configuration requirements. For details about the parameter constraints, see the API description related to the color inversion capability.
