# TabsSidebarDisplayStyle

```TypeScript
declare enum TabsSidebarDisplayStyle
```

Enumerates the display styles of the tab side bar.

**Since:** 26.2.0

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## EMBED

```TypeScript
EMBED = 0
```

The embedded style. The tab bar is embedded in the content area of the **Tabs** container, taking up space within it.

**Since:** 26.2.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.2.0.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## DISPLACE

```TypeScript
DISPLACE = 1
```

The displaced style. The tab bar is displayed as a sidebar, pushing the content area of the **Tabs** container aside.

**Since:** 26.2.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.2.0.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
