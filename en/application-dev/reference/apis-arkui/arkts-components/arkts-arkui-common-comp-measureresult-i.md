# MeasureResult

```TypeScript
declare interface MeasureResult extends SizeResult
```

Provides the measurement result of the component. This API inherits from [SizeResult](arkts-arkui-common-comp-sizeresult-i.md).

**Inheritance/Implementation:** MeasureResult extends [SizeResult](arkts-arkui-common-comp-sizeresult-i.md)

**Since:** 10

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 11.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
