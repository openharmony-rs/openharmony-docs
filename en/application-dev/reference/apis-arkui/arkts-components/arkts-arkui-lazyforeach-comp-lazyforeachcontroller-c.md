# LazyForEachController

```TypeScript
declare class LazyForEachController
```

Defines a controller of the **LazyForEach** component. You can bind the controller to the **LazyForEach** component through the **controller** field in [LazyForEachOptions](arkts-arkui-lazyforeach-comp-lazyforeachoptions-i.md) and call [clearCache](#clearcache) to clear the child components prebuilt by the **LazyForEach** component as needed.

**Since:** 26.1.0

## clearCache

```TypeScript
clearCache(): void
```

Clears the child components prebuilt by the **LazyForEach** component bound to this controller.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.1.0.
