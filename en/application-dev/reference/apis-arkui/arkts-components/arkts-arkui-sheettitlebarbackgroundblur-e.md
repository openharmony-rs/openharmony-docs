# SheetTitleBarBackgroundBlur

Enum of title bar background blur styles.

**Since:** 26.1.0

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## NONE

```TypeScript
NONE = 0
```

No blur effect.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.1.0.

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## GRADIENT

```TypeScript
GRADIENT = 1
```

Gradient blur: fades from the top of the title bar downward to transparent. The gradient range adapts to the title bar height, using system preset values.

**Since:** 26.1.0

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 26.1.0.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
