# LayoutSafeAreaType

```TypeScript
declare enum LayoutSafeAreaType
```

Enumerates the types for expanding layout safe areas.

**Since:** 12

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## SYSTEM

```TypeScript
SYSTEM = 0
```

The component's layout range can be expanded to include both component-level safe areas ([safeAreaPadding](arkts-arkui-common-comp-commonmethod-c.md#safeareapadding)) and page-level safe areas (status bar, navigation bar, and cutout area).

**Since:** 12

**Model restriction:** This API can be used only in the stage model.

**Atomic service API:** This API can be used in atomic services since API version 12.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
