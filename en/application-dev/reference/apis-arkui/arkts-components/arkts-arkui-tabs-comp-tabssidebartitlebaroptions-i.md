# TabsSidebarTitleBarOptions

```TypeScript
declare interface TabsSidebarTitleBarOptions<T>
```

Defines ths options for the title bar of the sidebar tab bar. The title bar is displayed above the header area. When the title bar is set, the expand/collapse button moves from the default left side to the right side of the title bar.

**Since:** 26.1.0
