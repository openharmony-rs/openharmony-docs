# GridRowSizeOption

```TypeScript
declare interface GridRowSizeOption
```

Describes the gutter sizes for different device width types.

**Since:** 9

**System capability:** SystemCapability.ArkUI.ArkUI.Full

## lg

```TypeScript
lg?: Length
```

Gutter of the grid child components on large-width type devices. Value range: a number or string greater than or equal to 0.

Default value: **0vp**

Unit: vp

Invalid value: handled as the default value.

**Type:** [Length](../arkts-apis/arkts-arkui-length-t.md)

**Since:** 9

**Atomic service API:** This API can be used in atomic services since API version 11.

**Widget capability:** This API can be used in ArkTS widgets since API version 9.

**System capability:** SystemCapability.ArkUI.ArkUI.Full
