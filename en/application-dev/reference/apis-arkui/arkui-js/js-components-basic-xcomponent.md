  > **NOTE**
  > This component is supported since API version 8. Updates will be marked with a superscript to indicate their earliest API version.

  The **\<xcomponent>** displays the components to which the EGL/OpenGL ES or media data is written. It supports two types: surface, where content is displayed separately and composited directly to the screen, and component, where content is composited with other components before being displayed. It is suitable for scenarios such as camera preview that require displaying EGL/OpenGL ES rendering content or media data.

## Required Permissions

  None

## Child Components

  Not supported

## Attributes

In addition to the [universal attributes](js-components-common-attributes.md), the following attributes are supported.

| Name         | Type  | Mandatory  | Description                                      |
| ----------- | ------ | ---- | ---------------------------------------- |
| id          | string | Yes    | Unique ID of the component. The maximum string length is 128.                   |
| type        | string | Yes    | Type of the **XComponent** component. The options are as follows:<br/>- **surface**: The component content is displayed separately and directly composited to the screen. It is applicable to scenarios such as camera preview and video playback.<br/>- **component**: The component content is composited with other components and then displayed. It is applicable to scenarios where the component needs to be displayed together with other components.<br/> |
| libraryname | string | No    | Name of the dynamic library generated by compiling the native layer of the application. After this attribute is set, the component loads the dynamic library, and the methods registered in the library can be called on the JavaScript side through the context in the **onLoad** callback or through **getXComponentContext**. If this attribute is not set, the dynamic library is not loaded.                      |

## Styles

The [universal styles](js-components-common-styles.md) are supported.

## Events

In addition to the [universal events](js-components-common-events.md), the following events are supported.

| Name                              | Description                                    |
| -------------------------------- | ---------------------------------------- |
| onLoad(context?: object) => void | Triggered when the **XComponent** component is loaded. If the **libraryname** attribute is set, this callback is triggered when the plug-in (the native dynamic library loaded through the **libraryname** attribute) is loaded.<br/>**context**: instance object of the **XComponent** method you extend. You define the APIs of the context object. |
| onDestroy() => void              | Triggered when the **XComponent** component is destroyed. If the **libraryname** attribute is set, this callback is triggered when the plug-in is destroyed. |

## Methods

In addition to the [universal methods](js-components-common-methods.md), the following methods are supported.

| Name                      | Parameter                                      | Return Value Type | Description                                      |
| ------------------------ | ---------------------------------------- | ------ | ---------------------------------------- |
| getXComponentSurfaceId   | -                                        | string | Obtains the ID of the surface corresponding to the **XComponent**, for use by @ohos APIs, such as camera-related APIs. Call this method after the **onLoad** callback. |
| setXComponentSurfaceSize | {<br/>surfaceWidth: number,<br/>surfaceHeight: number  <br/>} | -      | Sets the width and height of the surface held by the **XComponent**, in px. Call this method after the **onLoad** callback.             |
| getXComponentContext     | -                                        | object | Obtains the instance object of the **XComponent** method you extend. You define the APIs of this object. Set the **libraryname** attribute first.               |

## Example

Provide a surface-type **\<xcomponent>** to support camera preview and other capabilities.

```html
<!-- xxx.hml -->
<div style="height: 500px; width: 500px; flex-direction: column; justify-content: center; align-items: center;">
    <text id = 'camera' class = 'title'>camera_display</text>
    <xcomponent id = 'xcomponent' type = 'surface' onload = 'onload' ondestroy = 'ondestroy'></xcomponent>
</div>
```

```js
// xxx.js
import camera from '@ohos.multimedia.camera';
export default {
    onload() {
        var surfaceId = this.$element('xcomponent').getXComponentSurfaceId();
        camera.createPreviewOutput(surfaceId).then((previewOutput) => {
            console.info('Promise returned with the PreviewOutput instance');
        });
    },
    ondestroy() {
    }
}
```
