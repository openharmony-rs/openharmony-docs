## Overview

The Universal Keystore (HUKS) parameter set supports the use of key management APIs, including lifecycle management functions such as initializing a parameter set, adding parameters, constructing a parameter set, and releasing a parameter set, as well as functions such as obtaining parameters, copying a parameter set, querying a parameter set, and checking validity.
