# AVSessionType

```TypeScript
type AVSessionType = 'audio' | 'video' | 'voice_call' | 'video_call' | 'photo'
```

Session type supports audio & video, voice_call, video_call, photo

**Since:** 10

**Atomic service API:** This API can be used in atomic services since API version 12.
