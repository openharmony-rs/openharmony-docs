The audio template provides data interaction capabilities. This method allows media apps to access the audio template controller, which displays pages in a unified manner and responds to operation instructions.

This module provides the following features:

[AVMusicTemplate](arkts-apis-avMusicTemplate-AVMusicTemplate.md): Audio template, which can be used to exchange data with the audio template controller.

> **NOTE**
>
> - The initial APIs of this module are supported since API version 23. Newly added APIs will be marked with a superscript to indicate their earliest API version.
> - This module applies only to cars running API version 23 or later.

## Modules to Import

```ts
import { avMusicTemplate } from '@kit.AVSessionKit';
```
