## B

### BlendMode

Defines how the current content interacts with the existing content to generate a new effect. The calculation method and effect vary according to the blend mode.

### Brush

A drawing tool used to set the fill effect for the interior area of a graphic. It works together with the Pen to achieve fill and stroke effects.

## F

### Font

Manages font drawing attributes, including the font, size, and scale.

## G

### Glyph

The specific graphic representation of a character in a typeface. The same character usually corresponds to different glyphs in different typefaces.

## I

### Image Filter

A crucial image processing technology which can highlight or remove elements from images. Different filters can be added for the drawn content to enrich visual effects.

## P

### Pen

A drawing tool used to set the outline stroke effect for a graphic. It works together with the Brush to achieve stroke and fill effects.

## S

### Shader

A running program, mainly used for image rendering and processing. It can control the processing of vertices or pixels, including color calculation and shadow effects. Different shader effects can be applied to the drawn content to achieve rich and varied visual effects.

### Sprite Sheet

A resource form in which multiple small animation frames are arranged in rows and columns and merged into a single large image. A specific frame is located and displayed by specifying the row and column counts and the frame index. It is commonly used for frame-by-frame animation. This approach reduces the number of image resources and lowers texture switching overhead, and it is a common term in the game and graphics fields. A sprite sheet is also often called an Atlas, and the two terms are generally interchangeable.

## T

### TextBlob

A set of glyph elements and their positions that use the same typeface.

### Typeface

A collection of designs used to present characters in a specific visual graphic style. It includes attributes such as the typeface name, bold, and italic.
