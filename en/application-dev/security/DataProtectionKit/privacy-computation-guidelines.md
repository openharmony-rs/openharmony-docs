## Introduction

Starting from API version 26.0.1, privacy-preserving data comparison and retrieval capabilities are provided, including privacy target generation, privacy search, and search result retrieval. Without disclosing the original data and data set content to the other party, you can determine whether a target element exists in the other party's data set, or retrieve the associated value of a matching item.

Privacy computation supports two types of protocols:

- **PSI protocol** (Private Set Intersection): Determines whether a target element exists in a data set without revealing the element or the data set content.
- **PIR protocol** (Private Information Retrieval): Retrieves the key that matches a data set without revealing the key or the retrieved value.

A complete privacy computation consists of three steps:

1. The initiator calls [genPrivacyTarget](../../reference/apis-data-protection-kit/js-apis-privacyComputation.md#privacycomputationgenprivacytarget) to generate a privacy target (an encrypted representation of the target element).
2. The responder calls [privacySearch](../../reference/apis-data-protection-kit/js-apis-privacyComputation.md#privacycomputationprivacysearch) to perform a privacy search on the data set based on the privacy target and return the result ciphertext.
3. The initiator calls [getSearchResult](../../reference/apis-data-protection-kit/js-apis-privacyComputation.md#privacycomputationgetsearchresult) to decrypt the result ciphertext and obtain whether the target is matched and the associated value of the matching item.

For the specific protocol development steps, see [Using the PSI Protocol for Private Set Intersection](privacy-computation-psi.md) and [Using the PIR Protocol for Private Information Retrieval](privacy-computation-pir.md).

## Basic Concepts

Before developing privacy computing features, you need to understand the following basic concepts.

- **Privacy target**

  An encrypted representation generated by the initiator after processing the target element. It can be sent to the responder for privacy search without revealing the original data of the target element.

- **Privacy search**

  A search operation performed by the responder on the dataset in the ciphertext domain based on the privacy target. It returns the result ciphertext without exposing the target or the dataset content during the search.

- **Result ciphertext**

  The ciphertext generated by the privacy search must be decrypted by the initiator through `getSearchResult` to obtain the final matching result.

- **Dataset size**

  The number of comparisons that a single result ciphertext can contain. The total number of result ciphertexts is determined by `elements.size`/`dataSetSize`. Select an appropriate value based on the number of elements in the privacy search and the acceptable size of each result ciphertext.

## Environment Setup
 
Before using the privacy computing capabilities, ensure that the following environment requirements are met:
 
- Device: a device running OpenHarmony API version 26.0.1 or later.
- System capability: the device must support `SystemCapability.Security.Asset`. You can use [canIUse](../../reference/common/js-apis-syscap.md#caniuse) to check whether this SysCap is available.
