The ArkTS common library is a rich set of APIs designed to provide a series of essential and practical functional modules.

The ArkTS base library mainly provides capabilities such as [XML Overview](xml-overview.md), [Buffer and FastBuffer](buffer.md), [various container class libraries](container-overview.md), [URL string parsing](../reference/apis-arkts/js-apis-url.md), and [the arbitrary precision math library Decimal](../reference/apis-arkts/js-apis-arkts-decimal.md), simplifying development work and improving development efficiency.
