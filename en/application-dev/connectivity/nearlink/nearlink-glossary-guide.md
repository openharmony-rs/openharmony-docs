## A

### Asynchronous Connection-Oriented Bidirectional (ACB)

An asynchronous bidirectional data transmission link in NearLink technology, used to reliably transmit data between devices.

## C

### Client Property Configuration Descriptor (CPCD)

A type of property descriptor that defines how a specific client configures property values.

### Coordinated Devices Set Management (CDSM)

Management of a coordinated devices set. A coordinated devices set is a unified whole composed of a group of coordinated device members that provides specific services.

## S

### SparkLink Service Access Protocol (SSAP)

Defines the discovery and access processes of the service structure, as well as the signaling used in these processes. Through service management, SparkLink/NearLink devices can achieve service-level interconnection.
