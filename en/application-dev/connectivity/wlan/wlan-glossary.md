## B

### Basic Service Set Identifier (BSSID)
A unique MAC address that identifies an access point in a wireless network and distinguishes it from other access points.

## C

### Captive Portal
A web page authentication mechanism for public WLAN networks, used to verify users in places such as hotels, airports, and coffee shops.

## E

### Extensible Authentication Protocol (EAP)
A framework protocol for network authentication that supports methods such as PEAP, TLS, and TTLS.

### Enhanced Multi-link Single Radio (EMLSR)
A connection type in [MLO](#multi-link-operation-mlo) that provides better coordination when switching frequency bands and lower latency than MLSR.

## G

### GroupOwnerBand
The operating frequency band used by a group in a P2P connection. Its values are automatic mode (`GO_BAND_AUTO`), the 2.4 GHz band (`GO_BAND_2GHZ`), and the 5 GHz band (`GO_BAND_5GHZ`).

## M

### Multi-link Single Radio (MLSR)
A connection type in [MLO](#multi-link-operation-mlo) in which a device shares one radio across multiple frequency bands for data transmission.

### Multi-Link Operation (MLO)
A multi-band concurrent transmission technology introduced by Wi-Fi 7 (802.11be). It allows devices to transmit data over multiple frequency bands at the same time, improving throughput and reliability by aggregating the bandwidth of multiple links.

## O

### Opportunistic Wireless Encryption (OWE)
A security enhancement for open [Wi-Fi](#wi-fi) networks that automatically encrypts traffic.

## P

### Peer-to-Peer (P2P)
A [WLAN](#wireless-local-area-network-wlan) direct connection technology that allows devices to connect and transfer data without an access point (AP).

### Pre-Shared Key (PSK)
A symmetric key used by WPA/WPA2 Personal on [WLAN](#wireless-local-area-network-wlan) networks. The same password is configured on the device and wireless router in advance.

## R

### Received Signal Strength Indicator (RSSI)
An indicator of received signal strength in wireless communication, measured in dBm.

## S

### Simultaneous Authentication of Equals (SAE)
A key exchange protocol used by WPA3-Personal that addresses the vulnerability of [PSK](#pre-shared-key-psk) to offline dictionary attacks.

### Service Set Identifier (SSID)
The name of a [Wi-Fi](#wi-fi) network, used to identify a WLAN.

### Station (STA)
A terminal device connected to a wireless network. It accesses the network as a client through an AP.

## W

### WLAN Authentication and Privacy Infrastructure (WAPI)
A wireless LAN security standard developed in China that uses certificate-based authentication.

### Wireless Local Area Network (WLAN)
A technology that uses radio waves to establish network connections within a given range, enabling wireless network access.

### Wired Equivalent Privacy (WEP)
An early [WLAN](#wireless-local-area-network-wlan) encryption protocol with severe security vulnerabilities, superseded by WPA/WPA2.

### Wi-Fi
A brand name for wireless communication based on [WLAN](#wireless-local-area-network-wlan) technology. It is maintained and certified by the Wi-Fi Alliance and follows the IEEE 802.11 standards series.

### Wi-Fi Protected Access (WPA)
A [WLAN](#wireless-local-area-network-wlan) security protocol standard designed to replace [WEP](#wired-equivalent-privacy-wep).

### Wi-Fi Protected Access II (WPA2)
An upgrade to WPA that replaces TKIP with the AES encryption algorithm to provide stronger security.

### Wi-Fi Protected Access III (WPA3)
The latest [Wi-Fi](#wi-fi) security standard. It supports the SAE key exchange protocol and provides stronger encryption and more secure authentication.
