## B

### Basic Service Set Identifier (BSSID)

A unique MAC address used to identify an access point in a wireless network, distinguishing different access points from one another.

## D

### Dynamic Host Configuration Protocol (DHCP)

A protocol that automatically assigns network configuration information such as IP addresses. After a device connects to a [WLAN](#wireless-local-area-network-wlan), it obtains an IP address through DHCP.

### Domain Name System (DNS)

A system that resolves domain names into IP addresses, serving as one of the fundamental services of the Internet.

## E

### Extensible Authentication Protocol (EAP)

A framework protocol for network authentication that supports multiple authentication methods, including PEAP, TLS, and TTLS.

## G

### GroupOwnerBand

The operating frequency band used by the group in a P2P connection. It has three values: automatic mode (`GO_BAND_AUTO`), 2.4 GHz band (`GO_BAND_2GHZ`), and 5 GHz band (`GO_BAND_5GHZ`).

## M

### Enhanced Multi-link Single Radio (EMLSR)

A connection type in [MLO](#multi-link-operation-mlo) technology, offering better band switching coordination and lower latency than MLSR.

### Multi-link Single Radio (MLSR)

A connection type in [MLO](#multi-link-operation-mlo) technology, where a device shares a single radio across multiple frequency bands for data transmission.

### Multi-Link Operation (MLO)

A multi-band concurrency technology introduced by Wi-Fi 7 (802.11be) that allows devices to transmit data simultaneously on multiple frequency bands, improving transmission rate and reliability by aggregating the bandwidth of multiple links.

## O

### Opportunistic Wireless Encryption (OWE)

A security enhancement mechanism for open [Wi-Fi](#wi-fi) networks that automatically encrypts traffic on open networks.

## P

### Peer-to-Peer (P2P)

A [WLAN](#wireless-local-area-network-wlan) direct connection technology that allows devices to establish connections and transfer data directly without going through an AP.

### Captive Portal (Portal)

A web page authentication mechanism for public WLAN networks, used for identity verification in venues such as hotels, airports, and coffee shops.

### Pre-Shared Key (PSK)

A symmetric key used in the [WLAN](#wireless-local-area-network-wlan) WPA/WPA2 Personal mode, where the same password is pre-configured on both the device and the wireless router.

## R

### Received Signal Strength Indicator (RSSI)

An indicator used in wireless communications to quantify the signal strength at the receiver in dBm.

## S

### Simultaneous Authentication of Equals (SAE)

A key exchange protocol used by WPA3-Personal that addresses the vulnerability of [PSK](#pre-shared-key-psk) to offline dictionary attacks.

### Service Set Identifier (SSID)

The name of a [Wi-Fi](#wi-fi) network, used to identify a WLAN.

### STA Station (STA)

A terminal device connected to a wireless network, functioning as a client that accesses the network through an AP.

## W

### WLAN Authentication and Privacy Infrastructure (WAPI)

A WLAN security protocol standard developed by China, which uses a certificate-based authentication mechanism.

### Wireless Local Area Network (WLAN)

A technology that uses radio waves to establish network connections within a certain range, enabling devices to access the network wirelessly.

### Wired Equivalent Privacy (WEP)

An early [WLAN](#wireless-local-area-network-wlan) encryption protocol with critical security vulnerabilities, superseded by WPA/WPA2.

### Wi-Fi

A brand name for wireless communication based on [WLAN](#wireless-local-area-network-wlan) technology, maintained and certified by the Wi-Fi Alliance, conforming to the IEEE 802.11 standards series.

### Wi-Fi Protected Access (WPA)

A [WLAN](#wireless-local-area-network-wlan) security protocol standard, designed as a replacement for [WEP](#wired-equivalent-privacy-wep).

### Wi-Fi Protected Access II (WPA2)

An upgraded version of WPA that introduces the AES encryption algorithm to replace TKIP, providing stronger security.

### Wi-Fi Protected Access III (WPA3)

The latest [Wi-Fi](#wi-fi) security standard. It supports the SAE key exchange protocol and provides stronger encryption algorithms and a more secure authentication mechanism.
