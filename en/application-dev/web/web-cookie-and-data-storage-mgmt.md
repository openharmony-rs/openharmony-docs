A cookie is data generated by the server and sent to the client. The client holds the cookie so that the server can quickly identify the identity and status.

For cookies, the default value of **SameSite** is **Lax**, indicating that cookies are sent only when a user navigates to the source site and are not sent in cross-site requests.

## Cookie Management

The Web component provides the [WebCookieManager](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md) class to manage cookie information.

The following uses the [configCookieSync](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md#configcookiesync11) API as an example to set the value "value=test" for a single cookie of "www\.example.com".

<!-- @[set_the_value_of_a_single_cookie](https://gitcode.com/openharmony/applications_app_samples/blob/master/code/DocsSample/ArkWeb/SetBasicAttrsEvts/SetBasicAttrsEvtsTwo/entry/src/main/ets/pages/CookieManagement.ets) -->

``` TypeScript
import { webview } from '@kit.ArkWeb';
import { BusinessError } from '@kit.BasicServicesKit';

@Entry
@Component
struct WebComponent {
  controller: webview.WebviewController = new webview.WebviewController();

  build() {
    Column() {
      Button('configCookieSync')
        .onClick(() => {
          try {
            webview.WebCookieManager.configCookieSync('https://www.example.com', 'value=test');
          } catch (error) {
            console.error(
              `ErrorCode: ${(error as BusinessError).code},  Message: ${(error as BusinessError).message}`);
          }
        })
      Web({ src: 'www.example.com', controller: this.controller });
    }
  }
}
```

Starting from API version 22, developers can use [setLazyInitializeWebEngine](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md#setlazyinitializewebengine22) to defer the initialization of the ArkWeb kernel. When calling configCookieSync to set the value "value=test" for a single cookie of "www\.example.com", the initialization of the ArkWeb kernel is skipped, thereby saving the time consumed by the [configCookieSync](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md#configcookiesync11) API. For other cookie-related functions and usage, see the [WebCookieManager](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md) API documentation.

<!-- @[set_lazy_initialize_web_engine](https://gitcode.com/openharmony/applications_app_samples/blob/master/code/DocsSample/ArkWeb/SetBasicAttrsEvts/SetBasicAttrsEvtsTwo/entry/src/main/ets/pages/CookieManagement_LazyInitializeWebEngine.ets) -->

``` TypeScript
    try {
      webview.WebCookieManager.configCookieSync('https://www.example.com', 'value=test');
    } catch (error) {
      console.error(
        `ErrorCode: ${(error as BusinessError).code},  Message: ${(error as BusinessError).message}`);
    }
  }

  build() {
    Column() {
      Web({ src: 'www.example.com', controller: this.controller })
    }
  }
}
```

> **Note:**
>
> Cookies are saved to the disk periodically every 30 seconds. You can also use the [saveCookieAsync](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md#savecookieasync) API to force persistence to the disk. (PC/2-in-1 and Tablet devices do not persist session cookies. Even if saveCookieAsync is called, session cookies are not written to the disk.)
>
> Starting from API version 26.0.1, after [setLazyInitializeWebEngine](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md#setlazyinitializewebengine22) is called and set to true, the APIs of [WebCookieManager](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md) can be used in asynchronous threads. When it is set to false or the API is not called, the APIs of [WebCookieManager](../reference/apis-arkweb/arkts-apis-webview-WebCookieManager.md) cannot be used in asynchronous threads and can only be used in the UI thread.

## Cache and Storage Management

When accessing a website, network resource requests usually take a long time. You can save resources locally through Cache and DOM Storage to speed up access to the same website.


### Cache

Use [cacheMode](../reference/apis-arkweb/arkts-basic-components-web-attributes.md#cachemode) to configure the cache mode for page resources. The Web component provides developers with four cache modes:

- Default: Resources are loaded preferentially from the unexpired cache. If the cache does not exist, resources are obtained from the network.
 
- None: Resources are loaded preferentially from the cache (including expired ones). If the resource is not in the cache, it is obtained from the network.

- **Online**: Page resources are not loaded from the cache. They are all obtained from the network.

- **Only**: Page resources are only loaded from the cache.


In the following example, the cache mode is set to **None**.
<!-- @[configure_the_caching_mode_for_page_resources](https://gitcode.com/openharmony/applications_app_samples/blob/master/code/DocsSample/ArkWeb/SetBasicAttrsEvts/SetBasicAttrsEvtsTwo/entry/src/main/ets/pages/Cache_one.ets) -->

``` TypeScript
import { webview } from '@kit.ArkWeb';

@Entry
@Component
struct WebComponent {
  @State mode: CacheMode = CacheMode.None;
  controller: webview.WebviewController = new webview.WebviewController();

  build() {
    Column() {
      Web({ src: 'www.example.com', controller: this.controller })
        .cacheMode(this.mode)
    }
  }
}
```

``` TypeScript
import { webview } from '@kit.ArkWeb';
import { BusinessError } from '@kit.BasicServicesKit';

@Entry
@Component
struct WebComponent {
  @State mode: CacheMode = CacheMode.None;
  controller: webview.WebviewController = new webview.WebviewController();

  build() {
    Column() {
      Button('removeCache')
        .onClick(() => {
          try {
            // If this parameter is set to true, the cache in both the ROM and RAM is cleared. If this parameter is set to false, only the cache in the RAM is cleared.
            this.controller.removeCache(true);
          } catch (error) {
            console.error(`ErrorCode: ${(error as BusinessError).code},  Message: ${(error as BusinessError).message}`);
          }
        });
      Web({ src: 'www.example.com', controller: this.controller })
        .cacheMode(this.mode)
    }
  }
}
```


### DOM Storage

DOM Storage includes two types: Session Storage and Local Storage. Session Storage stores temporary data, and its storage and release follow the session lifecycle. Local Storage stores persistent data and is saved in the application directory. Data of both types is stored in the form of key-value pairs and is used when accessing pages that require client-side storage. ## FAQs

### What is the size limit of ArkWeb for caching static resource files?

The size limit of ArkWeb for caching static resources of a single app is 100 MB.
