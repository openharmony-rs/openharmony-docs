# TrailOptimization 取值范围（progressThreshold / responseDecayFactor）勘误记录

日期：2026-09-08

## 问题

`zh-cn/application-dev/reference/apis-arkui/js-apis-curve-sys.md` 中 `TrailOptimization` 参数表与 SDK d.ts、引擎实现不一致：

- docs zh 原写 `responseDecayFactor` 取值范围为 `[0, 1]`（含 0），"小于0时取值为0"；
- SDK 英文 d.ts 两个字段均写 `Value range: <0, 1>.`（尖括号，疑为笔误，且两字段区间本应不同）；
- SDK 中文 d.ts 写 `progressThreshold: [0, 1]`、`responseDecayFactor: (0, 1]`。

## 修改依据（实现为准）

### 1. ace_engine 引擎实现（判定基准）

`foundation/arkui/ace_engine/interfaces/inner_api/ace_kit/include/ui/animation/curve.h:468-492`：

```cpp
struct TrailOptimization {
    float progressThreshold = 1.0f;
    float responseDecayFactor = 1.0f;
    static constexpr float FLOAT_ZERO = 0.0f;
    static constexpr float MAX_PROGRESS_THRESHOLD = 1.0f;
    static constexpr float MIN_RESPONSE_DECAY_FACTOR = 1e-8f;
    static constexpr float MAX_RESPONSE_DECAY_FACTOR = 1.0f;

    void validate()
    {
        if (progressThreshold < FLOAT_ZERO) {
            progressThreshold = FLOAT_ZERO;
        }
        if (progressThreshold > MAX_PROGRESS_THRESHOLD) {
            progressThreshold = MAX_PROGRESS_THRESHOLD;
        }
        if (responseDecayFactor < MIN_RESPONSE_DECAY_FACTOR) {
            responseDecayFactor = MIN_RESPONSE_DECAY_FACTOR;
        }
        if (responseDecayFactor > MAX_RESPONSE_DECAY_FACTOR) {
            responseDecayFactor = MAX_RESPONSE_DECAY_FACTOR;
        }
    }
};
```

结论：

- `progressThreshold`：钳位到 `[0, 1]`，默认值 1；
- `responseDecayFactor`：钳位到 `[1e-8, 1]`，即有效取值 `(0, 1]`，默认值 1。1e-8 是实现细节，对用户语义即"必须大于 0"，文档不写 1e-8（评审意见）。

### 2. SDK d.ts 声明

- 中文 `interface/sdk-js/zh-cn/api/@ohos.curves.d.ts:524-551`：`progressThreshold` "取值范围：[0, 1]"、`responseDecayFactor` "取值范围：(0, 1]"——与实现一致，**原本正确，未修改**；
- 英文 `interface/sdk-js/api/@ohos.curves.d.ts:463-486`：两字段均为 "Value range: <0, 1>."——与实现及中文版均不一致，**属笔误，本次修正**。

### 3. 解析链路佐证（无额外钳位）

- ArkTS 侧 `frameworks/bridge/common/utils/utils.cpp:153-158`（TrailOptimizedSpringMotionCreator）原样透传参数；
- `frameworks/bridge/declarative_frontend/engine/jsi/modules/jsi_curves_module.cpp` 同路径；
- 即取值范围的唯一裁决点为上述 `curve.h` 的 `validate()`，不存在"负数回退0vp"之类的其他逻辑。
