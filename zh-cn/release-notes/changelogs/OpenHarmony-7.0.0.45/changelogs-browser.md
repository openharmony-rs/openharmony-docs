# 默认浏览器变更说明

## cl.browser.1 新增默认浏览器权限

**访问级别**

公共能力

**变更原因**

为避免非专业或低安全性应用引发的安全风险与体验割裂，鸿蒙系统通过引入权限管控机制对默认浏览器生态进行规范。该机制从安全、隐私及用户体验三个维度设定了严格的准入标准，旨在全面保障并提升用户的网络浏览体验。

**变更影响**

变更前：
1. 只要声明支持打开HTTP协议即可展示在默认浏览器备选列表并且可以被设置为默认浏览器。

变更后：
1. 需要申请默认浏览器权限才可以展示在默认浏览器备选列表。
2. 具备默认浏览器权限的应用才可以被设置为默认浏览器。

**起始 API Level**

26.1.0

**变更发生版本**

从OpenHarmony SDK 7.0.0.45开始。

**变更的接口/组件**

不涉及

**适配指导**

默认浏览器权限面向浏览器类应用，用于将应用设置为系统默认浏览器，接管系统及第三方应用发出的网页链接打开请求，统一管理网页内容的跳转与展示。仅满足浏览器品类标准，并通过安全、隐私、用户体验三项审核的应用方可申请此权限。

一、浏览器品类标准：
- 应用首页可以输入URL并访问，也可以输入关键词用于搜索引擎在互联网上查找相关网站链接。
- 应用应提供搜索引擎选择或者设置入口，用户可以自定义搜索引擎。
- 应用可以访问HTTP、HTTPS链接并展示网页内容，且支持显示网页域名和URL。
- 应用支持书签/历史/下载、多标签页管理、无痕浏览等浏览器基础功能。
- 访问非HTTPS站点或者证书错误时应有风险提示。
- 遵从系统级且完整的权限申请机制规范。

二、默认浏览器规范：

安全：
- 应用应提供恶意网址检测能力，用户访问风险网址需要给予提示。
- 应用应支持双向认证即客户端与服务端的双向认证（较多场景如与银行类应用双向认证等）。
- 应用不应该开启本地文件跨域特权，会导致任意本地文件窃取、跨域隐私数据外传等风险。
- 应用需支持阻止第三方网站保存和读取用户cookie数据。

隐私保护：
- 未成年保护模式：应用应适配系统未成年保护模式，在未成年保护模式下不允许给恶意网站提供继续访问选项。
- 无痕模式：无痕模式启用后，任何网页和资讯访问历史（浏览记录）、搜索记录、应用使用信息（网页缓存和Cookie）不会被记录。
- 匿名化处理：恶意网址拦截匿名化，搜索引擎网站相关URL数据仅在客户端本地处理并要求数据脱敏和匿名处理；搜索记录仅储存在本地设备端，且支持用户手动清除。

用户体验：
- 应用应为用户提供广告拦截功能，网页浏览过程中自动为用户过滤广告。
- 应用应为用户提供简洁主页，以提高加载速度、简化用户操作。
- 应用应支持系统级深浅色模式、字体大小调整等基础体验功能。

应用满足以上标准即可申请默认浏览器权限，权限审核需要3个工作日。权限审核通过应用即可被用户设置为默认浏览器。
