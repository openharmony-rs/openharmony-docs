# EdgeLightMode.EDGELIGHT_AUTO 两处文档描述一致性分析

## 背景

- `zh-cn/application-dev/reference/apis-arkui/arkui-ts/ts-appendix-enums-sys.md:98`（枚举表通用规则）：`EDGELIGHT_AUTO` 依据设备算力档位和系统设置中的沉浸光感配置自动生效——高算力在"强/均衡"生效、"弱"不生效；中算力仅"强"生效；低算力不生效。
- `zh-cn/application-dev/reference/apis-arkui/arkui-ts/ts-universal-attributes-sheet-transition-sys.md:30`（半模特例）："对于半模态弹窗的边缘光效动画，EDGELIGHT_AUTO：在所有算力设备都关闭"。

问题：两处说法哪个准确？

## 结论

**两个说法都准确，适用范围不同，互不矛盾。**

1. **枚举表 = 通用规则**（适用于弹窗、菜单等在组件接口处未做特殊说明的组件）：AUTO 按算力档位与沉浸光感配置自动生效。代码可证。
2. **半模态 = 已声明的特例**：AUTO 在所有算力设备都关闭，与算力档位无关。代码可证。
3. 枚举表描述开头已写明"组件类型不同，流光效果的自动生效规则不同""对于在组件接口处未做特殊说明的组件"才按通用规则，半模态文档正是那条"特殊说明"，两处文档写法自洽。

## 代码依据

### 1. 通用规则（dialog / menu 等）

- `foundation/arkui/ace_engine/frameworks/core/components_ng/pattern/dialog/dialog_pattern.cpp:3513-3525`（`DialogPattern::NeedEdgeLight`）：
  - `EDGELIGHT_ENABLED` → 生效；`EDGELIGHT_DISABLED` → 不生效；
  - `EDGELIGHT_AUTO` → 需材质为 `IMMERSIVE`（或非 UiMaterial 类型）且 `DialogManager::IsUseImmersiveEdgeLightEffect()` 为 true 才生效。
- `foundation/arkui/ace_engine/frameworks/core/components_ng/pattern/menu/menu_pattern.cpp:1845-1850`：菜单 AUTO 分支同样走 `IsUseImmersiveEdgeLightEffect()`。
- `foundation/arkui/ace_engine/frameworks/core/components_ng/pattern/overlay/dialog_manager.cpp:258-272`（`DialogManager::IsUseImmersiveEdgeLightEffect`）：

```cpp
bool DialogManager::IsUseImmersiveEdgeLightEffect()
{
    auto materialLevel = SystemProperties::GetUiMaterialLevel();
    if (materialLevel == UiMaterialLevel::SMOOTH) {
        return false;
    }
    auto transparencyLevel = static_cast<UiMaterialTransparency>(
        TransparencyUtils::GetTransparencyLevel(static_cast<int32_t>(materialLevel)));
    if (materialLevel == UiMaterialLevel::EXQUISITE) {
        return transparencyLevel == UiMaterialTransparency::NORMAL ||
               transparencyLevel == UiMaterialTransparency::THIN;
    }
    // GENTLE: edge light is true only for GENTLE_THIN
    return transparencyLevel == UiMaterialTransparency::GENTLE_THIN;
}
```

即：低档（SMOOTH）一律关闭；高档（EXQUISITE）在对应"强/均衡"配置生效、"弱"不生效；中档（GENTLE）仅特定配置生效——与枚举表"高/中/低算力 + 沉浸光感配置"的描述一致。

### 2. 半模态特例（bindSheet）

- `foundation/arkui/ace_engine/frameworks/core/components_ng/pattern/sheet/sheet_edge_light.cpp:106-121`：

```cpp
bool SheetEdgeLightBase::CheckIfNeedShowEdgeLight(EdgeLightMode mode, SheetType sheetType)
{
    if (sheetType != SHEET_BOTTOM) {
        return false;
    }
    if (mode == EdgeLightMode::EDGELIGHT_DISABLED) {
        return false;
    }
    if (mode == EdgeLightMode::EDGELIGHT_ENABLED) {
        return true;
    }
    if (mode == EdgeLightMode::EDGELIGHT_AUTO) {
        return false;
    }
    return false;
}
```

AUTO 分支无条件 `return false`，不查任何算力档位/系统配置；sheet 默认值为 `EDGELIGHT_DISABLED`（`sheet_presentation_pattern.h:1304`），且仅 `SHEET_BOTTOM` 样式可能开启——均与半模态文档描述一致。
