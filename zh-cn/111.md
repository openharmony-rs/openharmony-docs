# EDGELIGHT_AUTO「在所有算力设备都关闭」描述准确性分析

## 背景

`application-dev/reference/apis-arkui/arkui-ts/ts-universal-attributes-sheet-transition-sys.md` 第 30 行 `bindSheet` 参数 `edgeLightMode` 说明中写道：

> 对于半模态弹窗的边缘光效动画，EDGELIGHT_AUTO：在所有算力设备都关闭；EDGELIGHT_ENABLED：开启边缘光效动画；EDGELIGHT_DISABLED：关闭边缘光效动画。

本文分析该描述与 ace_engine 实现是否一致。

## 代码依据

判定逻辑位于 `foundation/arkui/ace_engine/frameworks/core/components_ng/pattern/sheet/sheet_edge_light.cpp:106`（`SheetEdgeLightBase::CheckIfNeedShowEdgeLight`）：

```cpp
bool SheetEdgeLightBase::CheckIfNeedShowEdgeLight(EdgeLightMode mode, SheetType sheetType)
{
    if (sheetType != SHEET_BOTTOM) {
        return false;
    }
    if (mode == EdgeLightMode::EDGELIGHT_DISABLED) {
        return false;
    }
    if (mode == EdgeLightMode::EDGELIGHT_ENABLED) {
        return true;
    }
    if (mode == EdgeLightMode::EDGELIGHT_AUTO) {
        return false;
    }
    return false;
}
```

补充依据：

- 调用点：`sheet_presentation_pattern.cpp:1410-1413`，仅当 `CheckIfNeedShowEdgeLight` 为 true 且转场入场时才播放边缘光效。
- 默认值：`sheet_presentation_pattern.h:1304`，`sheetEdgeLightMode_` 初始为 `EdgeLightMode::EDGELIGHT_DISABLED`，与文档"未设置该属性时，边缘光效动画默认关闭""默认值：EdgeLightMode.EDGELIGHT_DISABLED"一致。
- 枚举定义：`frameworks/core/components/common/properties/ui_material.h:52-55`，`EDGELIGHT_AUTO = 0`。

## 分析

1. `EDGELIGHT_AUTO` 分支无条件 `return false`，代码中不存在任何设备算力档位、"沉浸光感"系统配置等判断逻辑，因此"在所有算力设备都关闭"的说法成立。
2. `sheetType != SHEET_BOTTOM` 时直接返回 false，与文档"边缘流光动画仅在 SheetType 为 BOTTOM 样式时生效"一致。
3. `EDGELIGHT_ENABLED` 返回 true、`EDGELIGHT_DISABLED` 返回 false，与文档对应描述一致。
4. 与通用枚举说明的差异：`ts-appendix-enums-sys.md:98` 中 `EDGELIGHT_AUTO` 的通用定义是"依据设备算力档位和系统设置中的沉浸光感配置自动生效"。半模态弹窗属于特例，其 AUTO 行为不遵循通用规则；`ts-universal-attributes-sheet-transition-sys.md` 的参数说明已用专门语句覆盖通用规则，两处文档并存不构成矛盾。

## 结论

该描述**准确**，与当前 ace_engine 实现一致，无需修改：

- EDGELIGHT_AUTO：半模态下在所有算力设备都关闭 ✅（代码无条件 return false）
- 仅 BOTTOM 样式生效 ✅
- 默认值 EDGELIGHT_DISABLED（默认关闭）✅
