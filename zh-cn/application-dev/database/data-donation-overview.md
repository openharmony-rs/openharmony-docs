## 功能简介

数据捐赠是一种应用向系统订阅所需数据的能力。应用无需自行采集数据，即可获取与自身业务相关的数据，用于业务分析等场景。

## 运作机制

数据捐赠的运作流程如下：

1. 应用配置订阅信息，并订阅数据捐赠事件。
2. 系统根据订阅信息采集并处理数据。
3. 系统通过回调向应用返回数据处理结果。
4. 应用不再需要接收数据时，取消订阅。

各环节的具体操作方式与参数说明，请参见[地址数据捐赠](address-donation-sys.md)。

## 能力范围

当前提供地址数据捐赠能力，支持应用订阅通勤导航场景下的地址数据更新事件，具体请参见[地址数据捐赠](address-donation-sys.md)。

数据捐赠能力的使用范围、支持的业务场景、数据采集与上报条件，以及设备和权限要求，由具体的数据捐赠能力决定。
