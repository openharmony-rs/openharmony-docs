从API版本26.1.0开始，支持安全访问围栏服务。安全访问围栏服务可以协助用户在使用智能体操作系统时进行访问控制决策，负责管控用户敏感数据及系统能力的访问行为，并管理访问控制策略与访问记录的全生命周期。当前提供以下独立能力：

- **获取CLI凭据：** 系统提供了丰富的CLI命令行工具（如ohos-batteryManager total-energy），用于查询电池信息、设备状态等系统能力。第三方应用在设备管理、运维诊断等场景下需要调用这些CLI工具。然而，CLI工具涉及系统级权限，若由应用直接执行存在权限越权和安全风险。系统通过签发可验证的ticket凭据，确保只有获得用户授权的应用才能调用相关命令。具体可参考[获取CLI凭据(Ticket)](secure-access-fence-guidelines.md)。
- **查询与请求权限控制目标应用：** 系统提供了模拟点击等系统操作能力，应用可在用户授权下操作其他应用以完成业务逻辑。然而，模拟点击等能力若被恶意应用滥用，可能在用户无感的情况下静默执行敏感操作（如转账确认、删除数据），造成财产损失和隐私泄露。系统管控应用通过模拟点击等方式操控目标应用的行为，并提供控制权限的查询与请求机制：应用可先查询目标应用的控制权限状态，若为拒绝（DENY），再向用户请求控制授权，确保只有获得用户授权的应用才能控制目标应用。具体可参考[查询与请求权限控制目标应用](app-control-permission-guidelines.md)。

## 相关能力

与程序访问控制（@ohos.abilityAccessCtrl）提供的能力相比，程序访问控制的机制管控的是应用访问系统资源（图片、文本、通讯录等）及系统能力（摄像头、麦克风等）的权限，是面向普通应用对系统资源的直接访问。安全访问围栏服务则聚焦于智能体场景，管控的是智能体在执行任务过程中会调用的系统资源与工具（如CLI命令行工具、对其他应用的控制操作等）。
