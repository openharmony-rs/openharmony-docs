## 概述

UI信息采集和交互注入是ArkUI NDK面向UI实例提供的信息采集与交互控制能力。从API版本26.1.0开始，应用可以通过ArkUI NDK接口采集自身UI实例的控件树信息，并向目标节点提交控件命令。例如，先采集控件树并从中定位目标输入框，再构造并提交设置文本命令，最后在完成回调中确认执行结果。

UI信息采集和交互注入提供如下场景开发指导，建议先了解数据格式，再按任务选择对应指南。

- **[UI信息数据格式说明](ndk-ui-info-data-structure.md)**：介绍JSONWrapper的创建、读取和销毁方法，以及业务JSON的组织方式。适用于构造控件命令或解析采集结果的场景。
- **[采集控件树信息](ndk-ui-info-collect-tree.md)**：说明控件树采集从树类型选择、属性配置到同步/异步结果解析的流程。适用于定位节点，或获取交互、无障碍及高阶属性信息的场景。
- **[注入控件命令](ndk-ui-command-injection.md)**：说明控件命令从构造、提交到回调与验证的完整流程。命令支持文本的设置、插入、删除、选择与复制，以及[Swiper](../reference/apis-arkui/arkui-ts/ts-container-swiper.md)、[Tabs](../reference/apis-arkui/arkui-ts/ts-container-tabs.md)切换。适用于通过命令修改组件内容或切换页面的场景。
- **[UI结构化数据映射附录](ndk-ui-appendix.md)**：汇总控件命令参数和控件树字段解析。用于提交前核对组件与参数，或解析采集结果。

## 亮点特征

- **统一的采集与注入架构**：面向应用自身UI实例提供标准化的控件树信息采集与控件命令注入能力，实现从节点定位到交互控制的完整闭环。
- **按需可配的控件树采集**：支持全量树与可见树采集，可按需配置采集范围以及交互、无障碍、高阶属性等字段，并兼顾同步与异步结果解析。
- **丰富的节点交互控制**：支持按节点标识向目标组件提交文本编辑、文本选择、内容复制以及Swiper、Tabs切换等控件命令，满足多样化的UI交互控制需求。
- **结构化的数据封装与映射**：基于JSONWrapper提供统一的业务JSON创建、读取与销毁机制，并提供标准化的命令参数与控件树字段映射，降低构造与解析复杂度。

## 约束与限制

- 上下文必须取自当前应用的目标UI实例，不得手动构造句柄；获取与复用限制见[管理上下文生命周期](ndk-ui-info-collect-tree.md#管理上下文生命周期)。
- 页面或窗口销毁后，原上下文随之失效，不得继续使用其发起请求；需要继续操作时，应在当前有效实例中重新获取。
- 控件树采集和控件命令注入必须在目标实例的UI线程调用。
- 避免逐帧采集或在UI线程循环重试。异步不会减少UI线程开销，高频调用会占用UI线程、影响正常业务，且前一请求完成前重复提交不会被受理。应按业务需要发起请求，处理完结果后再决定下一次操作。
- 编译时需使用API版本26.1.0及以上的SDK；运行设备的API版本需不低于26.1.0。
