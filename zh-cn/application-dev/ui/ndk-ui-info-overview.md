## 概述

UI信息采集和交互注入是ArkUI NDK（Native Development Kit）面向UI实例提供的信息采集与交互控制能力。从API版本26.1.0开始，应用可以通过ArkUI NDK接口采集自身UI实例的控件树信息，并向目标节点提交控件命令。例如，读取控件树定位输入框，再提交设置文本命令。

本专题按基础数据、控件树采集、命令注入和数据映射与结果解析的顺序组织以下开发指南。建议先了解数据格式，再按任务选择对应指南。

- **[UI信息数据格式说明](ndk-ui-info-data-structure.md)**：说明JSONWrapper的创建、读取和销毁，以及业务JSON的组织方式。适用于构造控件命令或解析采集结果的场景。
- **[采集控件树信息](ndk-ui-info-collect-tree.md)**：说明全量树、可见树、采集配置和同步/异步结果解析。适用于定位节点，以及获取交互、无障碍或组件属性信息的场景。
- **[注入控件命令](ndk-ui-command-injection.md)**：说明文本编辑、选择、复制和[Swiper](../reference/apis-arkui/arkui-ts/ts-container-swiper.md)、[Tabs](../reference/apis-arkui/arkui-ts/ts-container-tabs.md)切换命令的构造、提交与结果处理。适用于按节点标识修改或切换UI内容的场景。
- **[UI结构化数据映射附录](ndk-ui-appendix.md)**：汇总控件命令参数和控件树字段解析。用于提交前核对组件与参数，或解析采集结果。

## 亮点特征

提供统一的控件树采集与交互注入架构，支持按需配置采集范围和属性，并向目标节点注入文本、选择、复制及切换等操作。

## 约束与限制

使用本专题能力前，应确认UI实例范围、调用线程及SDK与设备实现的匹配关系。

- 为当前应用的目标UI实例获取有效上下文，不手动构造句柄。页面或窗口销毁后，不继续使用原上下文发起请求。
- 控件树采集和控件命令注入必须在目标实例的UI线程调用。
- 避免逐帧采集或在UI线程循环重试。应按业务需要发起请求，处理完结果后再决定下一次操作。
- 使用包含相关公开头文件的SDK，并确保运行设备提供匹配的实现。
