# LaunchReason

卡片创建原因枚举。

**起始版本：** 10

**系统能力：** SystemCapability.Ability.Form

## FORM_DEFAULT

```TypeScript
FORM_DEFAULT = 1
```

表示卡片创建原因为默认创建。

**起始版本：** 10

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form

## FORM_SHARE

```TypeScript
FORM_SHARE = 2
```

表示卡片创建原因为共享创建。

**起始版本：** 10

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form

## FORM_SIZE_CHANGE

```TypeScript
FORM_SIZE_CHANGE = 3
```

表示卡片创建原因为尺寸变化。

**起始版本：** 20

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form
