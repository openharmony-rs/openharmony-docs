# Rect

通用矩形区域信息。可用于描述卡片坐标区域、互动卡片动效区域等信息。

**起始版本：** 20

**系统能力：** SystemCapability.Ability.Form

## 导入模块

```TypeScript
import { formInfo } from '@kit.FormKit';
```

## height

```TypeScript
height: number
```

描述矩形的高度，单位：vp，用于定义卡片区域的尺寸。范围参考[请求参数约束](../../../form/arkts-ui-liveform-sceneanimation-development.md#请求参数约束)。

**类型：** number

**起始版本：** 20

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form

## left

```TypeScript
left: number
```

描述矩形的左上角顶点的 x 坐标，单位：vp，用于定位卡片区域的位置。范围参考 [请求参数约束](../../../form/arkts-ui-liveform-sceneanimation-development.md#请求参数约束)。

**类型：** number

**起始版本：** 20

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form
