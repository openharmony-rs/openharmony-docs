# Rect

通用矩形区域信息。可用于描述卡片坐标区域、互动卡片动效区域等信息。

**起始版本：** 23

<!--Device-formInfo-interface Rect--><!--Device-formInfo-interface Rect-End-->

**系统能力：** SystemCapability.Ability.Form

## 导入模块

```TypeScript
import { formInfo } from '@kit.FormKit';
```

## height

```TypeScript
height: double
```

描述矩形的高度，单位：vp，用于定义卡片区域的尺寸。范围参考[请求参数约束](../../../form/arkts-ui-liveform-sceneanimation-development.md#请求参数约束)。

**类型：** double

**起始版本：** 23

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。

<!--Device-Rect-height: double--><!--Device-Rect-height: double-End-->

**系统能力：** SystemCapability.Ability.Form
