# ColorMode

卡片主题样式统一跟随系统的颜色模式，卡片支持的颜色模式枚举。

> **说明：**
> 
> 从API version 9开始支持，从API version 20开始废弃。无替代接口。

**起始版本：** 9

**废弃版本：** 20

**系统能力：** SystemCapability.Ability.Form

## MODE_AUTO

```TypeScript
MODE_AUTO = -1
```

表示自动模式。

**起始版本：** 9

**废弃版本：** 20

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form

## MODE_DARK

```TypeScript
MODE_DARK = 0
```

表示暗色。

**起始版本：** 9

**废弃版本：** 20

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form

## MODE_LIGHT

```TypeScript
MODE_LIGHT = 1
```

表示亮色。

**起始版本：** 9

**废弃版本：** 20

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.Form
