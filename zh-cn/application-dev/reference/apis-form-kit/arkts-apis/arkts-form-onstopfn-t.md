# OnStopFn

```TypeScript
type OnStopFn = () => void
```

Called when this ability breaks the last link, notifying the provider that the provider process is about to stop.

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。
