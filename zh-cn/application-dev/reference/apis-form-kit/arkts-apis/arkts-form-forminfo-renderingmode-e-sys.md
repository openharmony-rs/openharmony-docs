# RenderingMode（系统接口）

卡片支持的渲染模式枚举。

**起始版本：** 18

**系统能力：** SystemCapability.Ability.Form

**系统接口：** 此接口为系统接口。

## AUTO_COLOR

```TypeScript
AUTO_COLOR = 0
```

表示自动模式。

**起始版本：** 18

**系统能力：** SystemCapability.Ability.Form

**系统接口：** 此接口为系统接口。

FULL_COLOR = 1
