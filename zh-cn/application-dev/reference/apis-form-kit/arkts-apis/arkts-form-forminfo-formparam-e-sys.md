## FORM_MANAGER_SHOW_SINGLE_FORM

```TypeScript
FORM_MANAGER_SHOW_SINGLE_FORM = 'ohos.extra.param.key.form_manager_show_single_form'
```

打开卡片管理页是否只显示特定单张卡片  
- true：表示只显示特定单张卡片。  
- false：表示显示所有卡片。  
**系统接口：** 此接口为系统接口。

**起始版本：** 23

**系统能力：** SystemCapability.Ability.Form

**系统接口：** 此接口为系统接口。
