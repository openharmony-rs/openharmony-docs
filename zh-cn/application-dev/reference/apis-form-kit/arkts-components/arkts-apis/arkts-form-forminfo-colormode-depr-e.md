# ColorMode

卡片支持的颜色模式枚举。

**起始版本：** 8

**废弃版本：** 9

**替代接口：** [ColorMode](arkts-form-forminfo-colormode-e.md)

**系统能力：** SystemCapability.Ability.Form

## MODE_AUTO

```TypeScript
MODE_AUTO = -1
```

表示自动模式。

**起始版本：** 8

**废弃版本：** 9

**替代接口：** [MODE_AUTO](arkts-form-forminfo-colormode-e.md#mode_auto)

**系统能力：** SystemCapability.Ability.Form
