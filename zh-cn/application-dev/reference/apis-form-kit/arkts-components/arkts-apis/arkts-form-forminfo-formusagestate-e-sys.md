# FormUsageState（系统接口）

卡片当前使用状态枚举。

**起始版本：** 11

**系统能力：** SystemCapability.Ability.Form

**系统接口：** 此接口为系统接口。

## USED

```TypeScript
USED = 0
```

表示卡片在使用中。

**起始版本：** 11

**系统能力：** SystemCapability.Ability.Form

**系统接口：** 此接口为系统接口。

```TypeScript
UNUSED = 1
```

表示卡片未被使用。

**起始版本：** 11

**系统能力：** SystemCapability.Ability.Form

**系统接口：** 此接口为系统接口。
