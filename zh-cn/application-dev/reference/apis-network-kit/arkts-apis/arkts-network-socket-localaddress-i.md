# LocalAddress

LocalSocket本地套接字文件路径信息，在传入套接字路径进行绑定时，会在此路径下创建套接字文件。

**起始版本：** 11

**系统能力：** SystemCapability.Communication.NetStack

## 导入模块

```TypeScript
import { socket } from '@kit.NetworkKit';
```

## address

```TypeScript
address: string
```

本地套接字路径。

**类型：** string

**起始版本：** 11

**系统能力：** SystemCapability.Communication.NetStack
