# FirewallRuleAction

枚举类型，防火墙规则行为，包含允许网络连接、阻止网络连接。

**起始版本：** 15

**系统能力：** SystemCapability.Communication.NetManager.NetFirewall

## RULE_ALLOW

```TypeScript
RULE_ALLOW = 0
```

允许。

**起始版本：** 15

**系统能力：** SystemCapability.Communication.NetManager.NetFirewall

## RULE_DENY

```TypeScript
RULE_DENY = 1
```

阻止。

**起始版本：** 15

**系统能力：** SystemCapability.Communication.NetManager.NetFirewall
