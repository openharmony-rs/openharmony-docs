# HttpDataType

HTTP的数据类型。  
| 名称 | 值 | 说明 | | ------------------ | -- | ----------- | | STRING | 0 | 字符串类型。 | | OBJECT | 1 | 对象类型。 | | ARRAY_BUFFER | 2 | 二进制数组类型。|

**起始版本：** 9

**系统能力：** SystemCapability.Communication.NetStack

## STRING

```TypeScript
STRING = 0
```

The returned type is string.

**起始版本：** 9

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Communication.NetStack
