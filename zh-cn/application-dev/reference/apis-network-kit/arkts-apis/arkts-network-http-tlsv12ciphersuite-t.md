# TlsV12CipherSuite

```TypeScript
export type TlsV12CipherSuite = TlsV11CipherSuite | TlsV12SpecificCipherSuite
```

TLS1.2的加密套件声明函数，支持TLS1.2版本，兼容TLS1.1版本。

**起始版本：** 23

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。
