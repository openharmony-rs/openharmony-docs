# UdpNetPortStatesInfo

UDP端口状态信息。

**起始版本：** 24

**系统能力：** SystemCapability.Communication.NetManager.Core

## 导入模块

```TypeScript
```

## udpLocalIp

```TypeScript
udpLocalIp: string
```

UDP网络本地IP地址。

**类型：** string

**起始版本：** 24

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.NetManager.Core

## udpLocalPort

```TypeScript
udpLocalPort: number
```

UDP网络本地端口，取值范围[0, 65535]。

**类型：** number

**起始版本：** 24

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.NetManager.Core

## udpPid

```TypeScript
udpPid: number
```

监听该UDP端口的进程PID。

**类型：** number

**起始版本：** 24

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.NetManager.Core

## udpUid

```TypeScript
udpUid: number
```

监听该UDP端口的用户UID。

**类型：** number

**起始版本：** 24

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.NetManager.Core
