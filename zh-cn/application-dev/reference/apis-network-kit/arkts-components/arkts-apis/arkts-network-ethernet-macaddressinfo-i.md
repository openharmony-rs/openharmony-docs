# MacAddressInfo

以太网网卡名称及MAC地址信息。

**起始版本：** 14

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

## 导入模块

```TypeScript
import { ethernet } from '@kit.NetworkKit';
```

## iface

```TypeScript
iface: string
```

以太网网卡名称。

**类型：** string

**起始版本：** 14

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

## macAddress

```TypeScript
macAddress: string
```

**类型：** string

**起始版本：** 14

**系统能力：** SystemCapability.Communication.NetManager.Ethernet
