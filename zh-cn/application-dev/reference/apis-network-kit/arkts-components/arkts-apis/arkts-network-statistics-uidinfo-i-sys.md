# UidInfo（系统接口）

查询应用历史流量参数信息。

**起始版本：** 10

**系统能力：** SystemCapability.Communication.NetManager.Core

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { statistics } from '@kit.NetworkKit';
```

ifaceInfo: IfaceInfo

**起始版本：** 10

**系统接口：** 此接口为系统接口。
