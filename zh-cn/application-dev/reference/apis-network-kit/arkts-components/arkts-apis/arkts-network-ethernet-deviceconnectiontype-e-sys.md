# DeviceConnectionType（系统接口）

以太网设备连接模式。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

**系统接口：** 此接口为系统接口。

## BUILT_IN

```TypeScript
BUILT_IN = 0
```

以太网设备为内置连接模式。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

**系统接口：** 此接口为系统接口。

## EXTERNAL

```TypeScript
EXTERNAL = 1
```

以太网设备为外接连接模式。例如，以太网设备通过USB连接。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

**系统接口：** 此接口为系统接口。
