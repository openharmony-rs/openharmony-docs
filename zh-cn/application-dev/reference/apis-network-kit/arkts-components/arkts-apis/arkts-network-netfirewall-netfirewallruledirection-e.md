# NetFirewallRuleDirection

枚举类型，防火墙规则方向，包含入站、出站。

**起始版本：** 15

**系统能力：** SystemCapability.Communication.NetManager.NetFirewall

## RULE_IN

```TypeScript
RULE_IN = 1
```

入站。

**起始版本：** 15

**系统能力：** SystemCapability.Communication.NetManager.NetFirewall

## RULE_OUT

```TypeScript
RULE_OUT = 2
```

出站。

**起始版本：** 15

**系统能力：** SystemCapability.Communication.NetManager.NetFirewall
