# ServerCert

指定服务端证书的信息，包括服务端证书文件路径和服务端证书的私钥文件路径。

**起始版本：** 19

**系统能力：** SystemCapability.Communication.NetStack

## 导入模块

```TypeScript
import { webSocket } from '@kit.NetworkKit';
```

## certPath

```TypeScript
certPath: string
```

服务端证书文件路径。

**类型：** string

**起始版本：** 19

**系统能力：** SystemCapability.Communication.NetStack

## keyPath

```TypeScript
keyPath: string
```

服务端证书的私钥文件路径。

**类型：** string

**起始版本：** 19

**系统能力：** SystemCapability.Communication.NetStack
