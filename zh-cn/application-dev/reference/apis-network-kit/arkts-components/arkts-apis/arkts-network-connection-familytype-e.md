# FamilyType

需要查询的具体IP地址类型。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.NetManager.Core

## FAMILY_TYPE_ALL

```TypeScript
FAMILY_TYPE_ALL = 0
```

查询所有IPv4和IPv6地址。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.NetManager.Core

## FAMILY_TYPE_IPV4

```TypeScript
FAMILY_TYPE_IPV4 = 1
```

仅查询IPv4地址。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.NetManager.Core

## FAMILY_TYPE_IPV6

```TypeScript
FAMILY_TYPE_IPV6 = 2
```

仅查询IPv6地址。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.NetManager.Core
