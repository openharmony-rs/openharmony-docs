# InterfaceStateInfo（系统接口）

监听以太网卡状态变化。

**起始版本：** 11

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { ethernet } from '@kit.NetworkKit';
```

## active

```TypeScript
active: boolean
```

以太网卡是否处于激活状态。true表示激活，false表示未激活。

**类型：** boolean

**起始版本：** 11

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

**系统接口：** 此接口为系统接口。

## iface

```TypeScript
iface: string
```

以太网卡名称。

**类型：** string

**起始版本：** 11

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

**系统接口：** 此接口为系统接口。
