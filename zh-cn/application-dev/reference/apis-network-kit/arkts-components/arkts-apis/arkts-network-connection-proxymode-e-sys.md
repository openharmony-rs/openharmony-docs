# ProxyMode（系统接口）

表示代理模式的枚举。使用Promise异步回调。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.NetManager.Core

**系统接口：** 此接口为系统接口。

## PROXY_MODE_OFF

```TypeScript
PROXY_MODE_OFF = 0
```

关闭代理模式。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.NetManager.Core

**系统接口：** 此接口为系统接口。

## PROXY_MODE_AUTO

```TypeScript
PROXY_MODE_AUTO = 1
```

自动代理模式。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.NetManager.Core

**系统接口：** 此接口为系统接口。
