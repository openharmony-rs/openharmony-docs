# net_ethernet_type.h

为以太网网卡模块C接口定义数据结构。

**系统能力：** SystemCapability.Communication.NetManager.Ethernet

**起始版本：** 26.0.0

**相关模块：** [NetEthernet](capi-netethernet.md)
