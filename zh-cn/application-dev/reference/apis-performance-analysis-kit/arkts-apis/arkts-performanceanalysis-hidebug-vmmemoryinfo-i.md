# VMMemoryInfo

VM内存信息。

**起始版本：** 12

**系统能力：** SystemCapability.HiviewDFX.HiProfiler.HiDebug

## 导入模块

```TypeScript
```

## allArraySize

```TypeScript
allArraySize: bigint
```

表示当前虚拟机的所有数组对象大小，以KB为单位。

**类型：** bigint

**起始版本：** 12

**系统能力：** SystemCapability.HiviewDFX.HiProfiler.HiDebug

## heapUsed

```TypeScript
heapUsed: bigint
```

表示当前虚拟机使用的堆大小，以KB为单位。

**类型：** bigint

**起始版本：** 12

**系统能力：** SystemCapability.HiviewDFX.HiProfiler.HiDebug

## totalHeap

```TypeScript
totalHeap: bigint
```

表示当前虚拟机的堆总大小，以KB为单位。

**类型：** bigint

**起始版本：** 12

**系统能力：** SystemCapability.HiviewDFX.HiProfiler.HiDebug
