## 导入模块

import { authorization } from '@kit.BasicServicesKit';

## getAuthorizationManager

```TypeScript
function getAuthorizationManager(): AuthorizationManager
```

获取[AuthorizationManager](arkts-basicservices-authorization-authorizationmanager-i.md)实例。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Account.OsAccount

**返回值：**

| 类型 | 说明 |
| --- | --- |
| [AuthorizationManager](arkts-basicservices-authorization-authorizationmanager-i.md) | 授权管理器的实例。 |
