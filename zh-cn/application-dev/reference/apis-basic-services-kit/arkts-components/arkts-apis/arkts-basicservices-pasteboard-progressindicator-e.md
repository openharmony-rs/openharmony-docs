# ProgressIndicator

```TypeScript
enum ProgressIndicator
```

定义进度条指示选项，可选择是否采用系统默认进度显示。

**起始版本：** 15

## NONE

```TypeScript
NONE = 0
```

不采用系统默认进度显示。

**起始版本：** 15

**原子化服务API（仅ArkTS-Dyn）：** 从API版本15开始，该接口支持在原子化服务中使用。
