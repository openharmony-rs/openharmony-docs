# OsAccountSubProfileEvent（系统接口）

枚举系统账号子身份资料的事件。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Account.OsAccount

**系统接口：** 此接口为系统接口。

## CREATED

```TypeScript
CREATED = 0
```

表示子身份创建完成事件，当系统账号子身份资料创建完成时触发。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Account.OsAccount

**系统接口：** 此接口为系统接口。

## DELETED
