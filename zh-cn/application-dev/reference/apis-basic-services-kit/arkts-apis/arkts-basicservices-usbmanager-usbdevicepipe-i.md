# USBDevicePipe

USB设备连接通道，用于确定总线地址和设备地址。

**起始版本：** 9

**系统能力：** SystemCapability.USB.USBManager

## 导入模块

```TypeScript
import { usbManager } from '@kit.BasicServicesKit';
```

## busNum

```TypeScript
busNum: number
```

总线地址。

**类型：** number

**起始版本：** 9

**系统能力：** SystemCapability.USB.USBManager

## devAddress

```TypeScript
devAddress: number
```

设备地址。

**类型：** number

**起始版本：** 9

**系统能力：** SystemCapability.USB.USBManager
