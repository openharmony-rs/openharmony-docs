# PhotoQualityPrioritization

枚举，拍照画质优先策略。

**起始版本：** 21

**系统能力：** SystemCapability.Multimedia.Camera.Core

## HIGH_QUALITY

```TypeScript
HIGH_QUALITY = 0
```

画质优先，拍照需要较长的时间，以输出高画质的图片。

**起始版本：** 21

**原子化服务API：** 从API版本21开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core

## SPEED

```TypeScript
SPEED = 1
```

性能优先，会降低画质来提升拍照的速度。

**起始版本：** 21

**原子化服务API：** 从API版本21开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core
