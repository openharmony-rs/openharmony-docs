# FoldStatus

枚举，折叠机折叠状态。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Camera.Core

## NON_FOLDABLE

```TypeScript
NON_FOLDABLE = 0
```

表示当前设备不可折叠。

**起始版本：** 12

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core

## EXPANDED

```TypeScript
EXPANDED = 1
```

表示当前设备折叠状态为完全展开。

**起始版本：** 12

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core

## FOLDED

```TypeScript
FOLDED = 2
```

表示当前设备折叠状态为折叠。

**起始版本：** 12

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core
