# FoldStatus

枚举，折叠机折叠状态。

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。

<!--Device-camera-enum FoldStatus--><!--Device-camera-enum FoldStatus-End-->

**系统能力：** SystemCapability.Multimedia.Camera.Core

## NON_FOLDABLE

```TypeScript
NON_FOLDABLE = 0
```

表示当前设备不可折叠。

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。
