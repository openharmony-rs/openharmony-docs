# PreconfigType

枚举，提供预配置的类型。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Camera.Core

## PRECONFIG_720P

```TypeScript
PRECONFIG_720P = 0
```

720P预配置。

**起始版本：** 12

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core
