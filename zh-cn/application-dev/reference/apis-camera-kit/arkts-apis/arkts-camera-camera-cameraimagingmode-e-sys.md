# CameraImagingMode（系统接口）

Enumerates the camera imaging modes.

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Multimedia.Camera.Core

**系统接口：** 此接口为系统接口。

## AUTO

```TypeScript
AUTO = 0
```

Auto imaging mode.

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。
