# DepthProfile（系统接口）

Describes the profile of depth data. It inherits from [Profile](arkts-camera-camera-profile-i.md#Profile).

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
