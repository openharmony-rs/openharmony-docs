# PhotoSessionForSys（系统接口）

Implements a photo session for system applications, which sets the parameters of the normal photo mode and saves all [CameraInput]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ and [CameraOutput]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_ instances required to run the camera. It inherits from [Session]\_\_\_JSDOC\_LINK\_DESC\_USD\_2\_\_\_.

**继承/实现关系：** PhotoSessionForSys extends [PhotoSession](arkts-camera-camera-photosession-i.md), [Beauty](arkts-camera-camera-beauty-i-sys.md), [ColorEffect](arkts-camera-camera-coloreffect-i-sys.md), [ColorManagement](arkts-camera-camera-colormanagement-i.md), [Macro](arkts-camera-camera-macro-i.md), [SceneDetection](arkts-camera-camera-scenedetection-i-sys.md), [EffectSuggestion](arkts-camera-camera-effectsuggestion-i-sys.md), [DepthFusion](arkts-camera-camera-depthfusion-i-sys.md), [ImagingMode](arkts-camera-camera-imagingmode-i-sys.md)

**起始版本：** 11

**ArkTS模式：** ArkTS-Dyn起始版本为11；ArkTS-Sta起始版本为23。
