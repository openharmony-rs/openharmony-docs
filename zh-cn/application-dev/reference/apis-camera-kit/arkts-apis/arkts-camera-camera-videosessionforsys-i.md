# VideoSessionForSys（系统接口）

Implements a video session for system applications, which sets the parameters of the normal video mode and saves all [CameraInput](arkts-camera-camera-camerainput-i.md) and [CameraOutput](arkts-camera-camera-cameraoutput-i.md) instances required to run the camera. It inherits from [Session](arkts-camera-camera-session-i.md).

**继承/实现关系：** VideoSessionForSys extends [VideoSession](arkts-camera-camera-videosession-i.md), [Beauty](arkts-camera-camera-beauty-i-sys.md), [ColorEffect](arkts-camera-camera-coloreffect-i-sys.md), [ColorManagement](arkts-camera-camera-colormanagement-i.md), [Macro](arkts-camera-camera-macro-i-sys.md), [Aperture](arkts-camera-camera-aperture-i-sys.md), [ColorReservation](arkts-camera-camera-colorreservation-i-sys.md), [EffectSuggestion](arkts-camera-camera-effectsuggestion-i-sys.md), [ImagingMode](arkts-camera-camera-imagingmode-i-sys.md)

**起始版本：** 23
