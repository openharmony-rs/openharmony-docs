# ZoomQuery

提供了与设备的缩放相关的查询功能，包括获取支持的缩放比例范围。 > **说明：** > > - 本Interface的起始版本为API version 12。接口在API version 12发生兼容变更，保留了内层元素的起始版本信息，会出现外层元素@since版本号大于内层元素的情况，不影响接口使用。

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。
