**起始版本：** 10

**系统能力：** SystemCapability.Multimedia.Camera.Core

## 导入模块

```TypeScript
```

## altitude

```TypeScript
altitude: number
```

海拔（米）。

**类型：** number

**起始版本：** 10

**系统能力：** SystemCapability.Multimedia.Camera.Core
