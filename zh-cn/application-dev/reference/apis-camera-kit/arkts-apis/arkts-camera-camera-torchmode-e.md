# TorchMode

枚举，手电筒模式。

**起始版本：** 11

**系统能力：** SystemCapability.Multimedia.Camera.Core

## OFF

```TypeScript
OFF = 0
```

常关模式。

**起始版本：** 11

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core

## ON

```TypeScript
ON = 1
```

常开模式。

**起始版本：** 11

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core

## AUTO

```TypeScript
AUTO = 2
```

自动模式，系统根据环境自动调节手电筒亮度。

**起始版本：** 11

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Camera.Core
