# NotificationFlagStatus

描述通知标志状态。

**起始版本：** 11

**系统能力：** SystemCapability.Notification.Notification

## TYPE_NONE

```TypeScript
TYPE_NONE = 0
```

未设置标志时的默认值，与TYPE_OPEN效果相同。

**起始版本：** 11

**系统能力：** SystemCapability.Notification.Notification

## TYPE_OPEN

```TypeScript
TYPE_OPEN = 1
```

通知标志打开。

**起始版本：** 11

**系统能力：** SystemCapability.Notification.Notification

## TYPE_CLOSE

```TypeScript
TYPE_CLOSE = 2
```

通知标志关闭。

**起始版本：** 11

**系统能力：** SystemCapability.Notification.Notification
