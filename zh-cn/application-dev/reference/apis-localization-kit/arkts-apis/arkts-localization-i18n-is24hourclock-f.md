# is24HourClock

## is24HourClock

```TypeScript
export function is24HourClock(): boolean
```

判断系统时间是否为24小时制。

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为7。

**废弃版本：** 9

**替代接口：** [is24HourClock](arkts-localization-i18n-system-c.md#is24HourClock)
