# TemplateId

标记模板的数据结构，TemplateId是在[addTemplate]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_中自动生成的，在 [addTemplate]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_后，可以使用模板id来标记模板。

**起始版本：** 10

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

## bundleNameOfOwner

```TypeScript
bundleNameOfOwner: string
```

指定创建模板的模板所有者的bundleName，与[addTemplate]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_中的bundleName相同。

**类型：** string

**起始版本：** 10

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

## subscriberId

```TypeScript
subscriberId: string
```

指定处理回调的订阅者的id，与[addTemplate]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_中的subscriberId相同，每个订阅者的ID是唯一的。

**类型：** string

**起始版本：** 10

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
