# Schema

表示数据库模式，可以在创建或打开数据库时创建Schema对象并将它们放入[Options](arkts-arkdata-distributeddata-options-i.md)中。

**起始版本：** 8

**废弃版本：** 9

**替代接口：** Schema

**系统能力：** SystemCapability.DistributedDataManager.KVStore.DistributedKVStore
