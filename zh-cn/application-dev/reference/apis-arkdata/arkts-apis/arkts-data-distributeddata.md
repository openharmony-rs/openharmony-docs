# @ohos.data.distributedData

分布式数据管理为应用程序提供不同设备间数据库的分布式协同能力。通过调用分布式数据各个接口，应用程序可将数据保存到分布式数据库中，并可对分布式数据库中的数据进行增加、删除、修改、查询、同步等操作。 该模块提供以下分布式数据管理相关的常用功能： - [KVManager]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_：数据管理实例，用于获取KVStore的相关信息。 - [KvStoreResultSet\_\_\_HTML\_TAG\_DESC\_USD\_10\_\_\_8+\_\_\_HTML\_TAG\_DESC\_USD\_11\_\_\_]\_\_\_JSDOC\_LINK\_DESC\_USD\_2\_\_\_：提供获取KVStore数据库结果集的相关方法，包括查询和移动数据读取位置等。 - [Query\_\_\_HTML\_TAG\_DESC\_USD\_12\_\_\_8+\_\_\_HTML\_TAG\_DESC\_USD\_13\_\_\_]\_\_\_JSDOC\_LINK\_DESC\_USD\_3\_\_\_：使用谓词表示数据库查询，提供创建Query实例、查询数据库中的数据和添加谓词的方法。 - [KVStore]\_\_\_JSDOC\_LINK\_DESC\_USD\_4\_\_\_：KVStore数据库实例，提供增加数据、删除数据和订阅数据变更、订阅数据同步完成的方法。 - [SingleKVStore]\_\_\_JSDOC\_LINK\_DESC\_USD\_5\_\_\_：单版本分布式数据库，继承自[KVStore]\_\_\_JSDOC\_LINK\_DESC\_USD\_6\_\_\_，不对数据 所属设备进行区分，提供查询数据和同步数据的方法。 - [DeviceKVStore\_\_\_HTML\_TAG\_DESC\_USD\_14\_\_\_8+\_\_\_HTML\_TAG\_DESC\_USD\_15\_\_\_]\_\_\_JSDOC\_LINK\_DESC\_USD\_7\_\_\_：设备协同数据库，继承自 [KVStore]\_\_\_JSDOC\_LINK\_DESC\_USD\_8\_\_\_，以设备维度对数据进行区分，提供查询数据和同步数据的方法。 > **说明：** > - 从API Version 9开始，该接口不再维护，推荐使用新接口 > [\_\_\_INLINE\_CODE\_DESC\_USD\_0\_\_\_]\_\_\_JSDOC\_LINK\_DESC\_USD\_9\_\_\_。 > - 本模块中所有需要获取deviceId的接口，都仅系统应用可用。
