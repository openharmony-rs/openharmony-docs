# Origin

表示数据来源。请使用枚举名称而非枚举值。

**起始版本：** 11

**系统能力：** SystemCapability.DistributedDataManager.CloudSync.Client

## LOCAL

```TypeScript
LOCAL = 0
```

表示本地数据。

**起始版本：** 11

**系统能力：** SystemCapability.DistributedDataManager.CloudSync.Client

## CLOUD

```TypeScript
CLOUD = 1
```

表示云端同步的数据。

**起始版本：** 11

**系统能力：** SystemCapability.DistributedDataManager.CloudSync.Client

## REMOTE

```TypeScript
REMOTE = 2
```

表示端端同步的数据。

**起始版本：** 11

**系统能力：** SystemCapability.DistributedDataManager.CloudSync.Client
