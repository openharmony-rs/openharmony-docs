# EncryptionAlgo

数据库的加密方式枚举。请使用枚举名称而非枚举值。

**起始版本：** 14

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

## AES_256_GCM

```TypeScript
AES_256_GCM = 0
```

数据库使用AES_256_GCM加密。

**起始版本：** 14

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

## AES_256_CBC

```TypeScript
AES_256_CBC = 1
```

数据库使用AES_256_CBC加密。

**起始版本：** 14

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

## PLAIN_TEXT

```TypeScript
PLAIN_TEXT = 2
```

数据库不进行加密。

**起始版本：** 22

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core
