# DistributedOrigin（系统接口）

表示数据来源。请使用枚举名称而非枚举值。

**起始版本：** 24

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

**系统接口：** 此接口为系统接口。

## ORI_LOCAL

```TypeScript
ORI_LOCAL = 0
```

表示本地数据。

**起始版本：** 24

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

**系统接口：** 此接口为系统接口。
