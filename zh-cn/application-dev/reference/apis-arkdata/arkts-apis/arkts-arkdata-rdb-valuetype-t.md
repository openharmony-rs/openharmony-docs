# ValueType

```TypeScript
type ValueType = number | string | boolean
```

用于表示允许的数据字段类型。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [ValueType](arkts-arkdata-relationalstore-valuetype-t.md)

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

| 类型 | 说明 |
| --- | --- |
| number | 表示值类型为数字。 |
| string | 表示值类型为字符串。 |
| boolean | 表示值类型为布尔值。 |
