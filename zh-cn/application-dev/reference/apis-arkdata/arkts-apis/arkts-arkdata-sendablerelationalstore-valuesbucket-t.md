# ValuesBucket

```TypeScript
type ValuesBucket = collections.Map<string, ValueType>
```

表示[ValueType](arkts-arkdata-sendablerelationalstore-valuetype-t.md#ValueType)数据的键值对存储，用于支持ValueType数据跨线程传递。

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**废弃版本：** -1
