# Progress

描述端云同步过程的枚举。请使用枚举名称而非枚举值。

**起始版本：** 10

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

## SYNC_BEGIN

```TypeScript
SYNC_BEGIN = 0
```

表示端云同步过程开始。

**起始版本：** 10

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

## SYNC_IN_PROGRESS

```TypeScript
SYNC_IN_PROGRESS = 1
```

表示正在端云同步过程中。

**起始版本：** 10

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core

## SYNC_FINISH

```TypeScript
SYNC_FINISH = 2
```

表示端云同步过程已完成。

**起始版本：** 10

**系统能力：** SystemCapability.DistributedDataManager.RelationalStore.Core
