# SearchPlayInfoType

表示搜播信息类型的枚举。

@enum { string }

**起始版本：** 23

**系统能力：** SystemCapability.Multimedia.AVSession.AVMusicTemplate

## PLAY_MUSIC

```TypeScript
PLAY_MUSIC = 'playMusic'
```

播放音乐。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.AVSession.AVMusicTemplate

## PLAY_VIDEO

```TypeScript
PLAY_VIDEO = 'playVideo'
```

播放视频。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.AVSession.AVMusicTemplate
