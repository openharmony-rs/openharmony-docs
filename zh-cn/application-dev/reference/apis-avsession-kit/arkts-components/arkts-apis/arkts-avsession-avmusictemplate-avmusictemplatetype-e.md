# AVMusicTemplateType

表示音频模板类型的枚举。

@enum { string }

**起始版本：** 23

**系统能力：** SystemCapability.Multimedia.AVSession.AVMusicTemplate

## DEFAULT

```TypeScript
DEFAULT = 'smartCar'
```

音频模板类型的默认值。

用于标识当前音频模板应用的业务类型，开发者创建模板时可根据自身业务修改此值。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.AVSession.AVMusicTemplate
