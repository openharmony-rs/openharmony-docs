# ProtocolType

远端设备支持的协议类型的枚举。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.Multimedia.AVSession.AVCast

## TYPE_LOCAL

```TypeScript
TYPE_LOCAL = 0
```

本地设备，包括设备本身的内置扬声器或音频插孔、A2DP 设备。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。
