# SkipIntervals

表示session支持的快进快退时间间隔的枚举。 | 名称 | 值 | 说明 | | ---------------------- | -- | ----------------------- | | SECONDS\_10 | 10 | 时间为10秒。 | | SECONDS\_15 | 15 | 时间为15秒。 | | SECONDS\_30 | 30 | 时间为30秒。 |
