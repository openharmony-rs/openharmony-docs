# CallerType

表示调用方来源类型的枚举。

**起始版本：** 22

**系统能力：** SystemCapability.Multimedia.AVSession.Core

## TYPE_CAST

```TypeScript
TYPE_CAST = 'cast'
```

调用方来自投播。

**起始版本：** 22

**系统能力：** SystemCapability.Multimedia.AVSession.Core

## TYPE_BLUETOOTH

```TypeScript
TYPE_BLUETOOTH = 'bluetooth'
```

调用方来自蓝牙。

**起始版本：** 22

**系统能力：** SystemCapability.Multimedia.AVSession.Core

## TYPE_NEARLINK

```TypeScript
TYPE_NEARLINK = 'nearlink'
```

调用方来自星闪。

**起始版本：** 22

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.AVSession.Core

## TYPE_APP

```TypeScript
TYPE_APP = 'app'
```

**起始版本：** 22

**系统能力：** SystemCapability.Multimedia.AVSession.Core
