# MediaKeyStatus

媒体密钥状态。

**起始版本：** 11

**系统能力：** SystemCapability.Multimedia.Drm.Core

## 导入模块

```TypeScript
import { drm } from '@kit.DrmKit';
```

## name

```TypeScript
name: string
```

媒体密钥状态名称。常见名称包括：媒体密钥过期时间、内容保护安全级别等。具体可选名称由DRM解决方案决定。

**类型：** string

**起始版本：** 11

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Drm.Core

## value

```TypeScript
value: string
```

媒体密钥状态值。

**类型：** string

**起始版本：** 11

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Multimedia.Drm.Core
