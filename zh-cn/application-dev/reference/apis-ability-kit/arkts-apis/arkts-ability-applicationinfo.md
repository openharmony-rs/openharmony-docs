# ApplicationInfo(ApplicationInfo)

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| [ApplicationInfo](arkts-ability-applicationinfo-i.md) | 应用程序信息，可以通过[bundleManager.getBundleInfoForSelf](arkts-ability-bundlemanager-getbundleinfoforself-f.md)获取自身的应用程序信息，其中参数[bundleFlags](arkts-ability-bundlemanager-bundleflag-e.md)至少包含GET_BUNDLE_INFO_WITH_APPLICATION。 |
| [ModuleMetadata](arkts-ability-applicationinfo-modulemetadata-i.md) | 描述模块的元数据信息。 |
| [MultiAppMode](arkts-ability-applicationinfo-multiappmode-i.md) | 表示[应用多开](../../../quick-start/multiInstance.md)模式。 |
