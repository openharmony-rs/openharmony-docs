# ViewData

查看自动填充的数据。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Ability.AbilityRuntime.AbilityCore

## bundleName

```TypeScript
bundleName: string
```

包名称。

**类型：** string

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.0.0开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.AbilityCore
