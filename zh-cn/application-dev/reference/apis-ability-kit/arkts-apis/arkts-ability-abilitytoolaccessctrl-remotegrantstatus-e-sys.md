# RemoteGrantStatus（系统接口）

远程授权状态。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Security.Asset

**系统接口：** 此接口为系统接口。

## ENABLE

```TypeScript
ENABLE = 0x01
```

启用远程授权。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Security.Asset

**系统接口：** 此接口为系统接口。

## DISABLE

```TypeScript
DISABLE = 0x02
```

禁用远程授权。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Security.Asset

**系统接口：** 此接口为系统接口。
