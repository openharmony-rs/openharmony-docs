# AppProvisionInfo

The module provides information in the
 [HarmonyAppProvision configuration file](../../../security/app-provision-structure.md). The information can be
 obtained through
 [getAppProvisionInfo](arkts-ability-bundlemanager-getappprovisioninfo-f-sys.md)
 .
 > **NOTE**
 >
 > The APIs provided by this module are system APIs.


## 汇总

<!--Del-->
### 接口（系统接口）

| 名称 | 说明 |
| --- | --- |
| [AppProvisionInfo](arkts-ability-appprovisioninfo-i-sys.md) | 应用[HarmonyAppProvision配置文件](../../../security/app-provision-structure.md)中的信息。 |
| [Validity](arkts-ability-appprovisioninfo-validity-i-sys.md) | 配置文件中的有效期。 |
