# WindowMode

启动UIAbility时窗口的创建模式，类型为枚举。可配合 [startAbility]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_ 方法使用。

**起始版本：** 12

**ArkTS模式：** ArkTS-Dyn起始版本为12；ArkTS-Sta起始版本为23。
