# ProcessRunningInfo

运行进程信息，可以通过appManager中 [getProcessRunningInfos]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_方法来获取运行进程信息。

**起始版本：** 8

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为8。

**废弃版本：** 9
