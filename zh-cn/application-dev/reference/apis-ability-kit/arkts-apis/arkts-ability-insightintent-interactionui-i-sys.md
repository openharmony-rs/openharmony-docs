# InteractionUI（系统接口）

定义当前意图执行完成后需要展示的交互界面的信息。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { insightIntent } from '@kit.AbilityKit';
```

## interactionUIType

```TypeScript
interactionUIType: string
```

交互界面的类型。

**类型：** string

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

**系统接口：** 此接口为系统接口。
