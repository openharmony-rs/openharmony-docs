# AgentCard

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| [AgentAppInfo](arkts-ability-agentcard-agentappinfo-i.md) | Agent的应用信息。 |
| [AgentCapabilities](arkts-ability-agentcard-agentcapabilities-i.md) | 定义Agent支持的可选能力。 |
| [AgentCard](arkts-ability-agentcard-i.md) | AgentCard相当于Agent(智能体)的"名片"，用于描述Agent的能力和技能，由开发者在Agent的配置文件agent_config.json中配置。 一个Agent就是一个AgentExtensionAbility实例。开发者可以通过AgentExtensionContext中的agentCard属性获取到当前AgentExtensionAbility的AgentCard。 |
| [AgentProvider](arkts-ability-agentcard-agentprovider-i.md) | 表示Agent的服务提供商。 |
| [AgentSkill](arkts-ability-agentcard-agentskill-i.md) | 表示Agent可以执行的不同能力或功能。 |
