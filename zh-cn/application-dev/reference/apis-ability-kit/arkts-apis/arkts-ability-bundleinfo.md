# BundleInfo(BundleInfo)

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| [AlternateIconInfo](arkts-ability-bundleinfo-alternateiconinfo-i.md) | 描述应用备用图标信息。 |
| [AppCloneIdentity](arkts-ability-bundleinfo-appcloneidentity-i.md) | 描述应用包的身份信息。 |
| [BundleInfo](arkts-ability-bundleinfo-i.md) | 应用包信息，可以通过[bundleManager.getBundleInfoForSelf](arkts-ability-bundlemanager-getbundleinfoforself-f.md)获取自身的应用包信息，其中参数[bundleFlags](arkts-ability-bundlemanager-bundleflag-e.md)指定所返回的[BundleInfo](arkts-ability-bundleinfo-i.md)中所包含的信息。 |
| [ReqPermissionDetail](arkts-ability-bundleinfo-reqpermissiondetail-i.md) | 应用运行时需向系统申请的权限集合的详细信息。 |
| [SignatureInfo](arkts-ability-bundleinfo-signatureinfo-i.md) | 描述应用包的签名信息，可标识应用来源、确保应用完整性，并用于应用安全校验与识别。 |
| [UsedScene](arkts-ability-bundleinfo-usedscene-i.md) | 描述权限的使用场景和时机，帮助开发者合理申请和使用权限。 |
