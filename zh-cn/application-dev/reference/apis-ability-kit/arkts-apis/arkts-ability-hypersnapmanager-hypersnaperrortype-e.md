# HyperSnapErrorType

枚举Hyper Snap错误类型。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

## CREATE_SNAPSHOT

```TypeScript
CREATE_SNAPSHOT = 0
```

创建快照过程中出现的错误类型。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

## FORK_FROM_SNAPSHOT

```TypeScript
FORK_FROM_SNAPSHOT = 1
```

从快照生成进程期间发生的错误类型。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core
