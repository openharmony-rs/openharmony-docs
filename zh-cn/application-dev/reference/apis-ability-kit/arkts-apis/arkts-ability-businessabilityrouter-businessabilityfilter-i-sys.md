# BusinessAbilityFilter（系统接口）

此过滤值用于过滤查询的Ability类型。

**起始版本：** 10

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { businessAbilityRouter } from '@kit.AbilityKit';
```

## businessType

```TypeScript
businessType: BusinessType
```

标识Ability信息的类型。

**类型：** BusinessType

**起始版本：** 10

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

**系统接口：** 此接口为系统接口。
