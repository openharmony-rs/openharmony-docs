# ContinueCallbackInfo（系统接口）

当前任务流转状态监听的回调信息，包含流转状态和流转信息。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
