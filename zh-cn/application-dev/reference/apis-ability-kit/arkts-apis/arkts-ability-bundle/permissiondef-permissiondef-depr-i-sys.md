## grantMode

```TypeScript
grantMode: number
```

权限的授予模式。0表示安装后系统自动授予该权限，1表示使用时动态申请，用户授权后方可使用。

**类型：** number

**默认值：** Indicates the grant mode of this permission

**起始版本：** 8

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为8。

**废弃版本：** 9
