### 接口（系统接口）

| 名称 | 说明 |
| --- | --- |
| [RunningMultiInstanceInfo](arkts-ability-runningmultiinstanceinfo-i-sys.md) | 定义多实例应用在运行态的结构信息，包含实例标识、应用UID和进程ID。通过appManager的[getRunningMultiAppInfo](arkts-ability-appmanager-getrunningmultiappinfo-f-sys.md)来获取，用于监控和管理多实例应用的运行状态。应用多实例相关开发指南请参见[创建应用多实例](../../../quick-start/multiInstance.md)。 |
