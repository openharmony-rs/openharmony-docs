# ParameterItem

快捷方式配置信息中的自定义数据。由开发者自行决定传入的键值对，可以通过key值获取对应的value值。

**起始版本：** 20

**系统能力：** SystemCapability.BundleManager.BundleFramework.Launcher

## key

```TypeScript
key: string
```

快捷方式配置信息中的自定义数据的键。

**类型：** string

**起始版本：** 20

**系统能力：** SystemCapability.BundleManager.BundleFramework.Launcher

## value

```TypeScript
value: string
```

快捷方式配置信息中的自定义数据的值。

**类型：** string

**起始版本：** 20

**系统能力：** SystemCapability.BundleManager.BundleFramework.Launcher
