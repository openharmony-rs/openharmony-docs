# SessionStatus（系统接口）

执行CLI工具时，系统会为调用方和CLI工具建立一个会话，此字段描述会话状态。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Ability.AgentRuntime.Core

**系统接口：** 此接口为系统接口。

## RUNNING

```TypeScript
RUNNING = 'running'
```

会话正在进行中。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Ability.AgentRuntime.Core

**系统接口：** 此接口为系统接口。
