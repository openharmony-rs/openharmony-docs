# HyperSnapErrorCode

枚举Hyper Snap错误码。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core

## ERR_OK

```TypeScript
ERR_OK = 0
```

成功。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.Core
