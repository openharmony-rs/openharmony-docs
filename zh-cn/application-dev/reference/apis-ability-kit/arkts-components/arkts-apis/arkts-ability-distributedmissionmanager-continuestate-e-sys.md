# ContinueState（系统接口）

当前任务流转状态的枚举。模型约束：此接口仅可在Stage模型下使用。

**起始版本：** 10

**系统能力：** SystemCapability.Ability.AbilityRuntime.Mission

**系统接口：** 此接口为系统接口。

## ACTIVE

```TypeScript
ACTIVE = 0
```

表示当前任务流转处于激活状态。

**起始版本：** 10

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.Mission

**系统接口：** 此接口为系统接口。

## INACTIVE

```TypeScript
INACTIVE = 1
```

表示当前任务流转处于未激活状态。

**起始版本：** 10

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Ability.AbilityRuntime.Mission

**系统接口：** 此接口为系统接口。
