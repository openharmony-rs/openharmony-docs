# PluginCmd

可以执行的插件命令枚举。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Security.DataLossPrevention

## CMD_BASE_INSTALL_PLUGIN

```TypeScript
CMD_BASE_INSTALL_PLUGIN = 0x1001
```

表示安装插件的命令。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Security.DataLossPrevention
