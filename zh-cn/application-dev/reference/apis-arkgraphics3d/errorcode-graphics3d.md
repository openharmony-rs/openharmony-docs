## 25601002 场景销毁后被重复使用

**错误信息**

Scene used after destruction.

**错误描述**

Scene被销毁后仍被访问或使用。

**可能原因**

1. 开发者在Scene被销毁后仍持有Scene引用并继续调用其方法。
2. 异步回调（Promise、setTimeout等）中引用了已销毁的Scene。

**处理步骤**

1. 检查代码中Scene的销毁时机，确保销毁之后不再访问该Scene实例的任何属性或方法。
2. 检查所有异步操作（Promise回调、setTimeout、动画回调等）是否可能引用已销毁的Scene，在Scene销毁前取消所有未完成的异步操作或将引用置为null。

## 25601005 内存申请失败

**错误信息**

Memory allocation failed.

**错误描述**

内存申请失败，包括CPU内存、GPU显存或DMA缓冲区分配失败。

**可能原因**

1. 系统内存不足，无法分配所需的CPU内存。
2. GPU显存不足，无法分配GPU资源（纹理、缓冲区等）。
3. DMA缓冲区不足。
4. 存在内存泄漏导致可用内存耗尽。

**处理步骤**

1. 使用系统工具检查应用内存占用，确认是否接近系统限制。
2. 降低纹理分辨率或使用压缩纹理格式，减少场景中的模型数量或简化模型面数。
3. 降低离屏渲染目标分辨率，减少DMA缓冲区占用。
4. 检查资源生命周期管理，确保所有创建的资源在不需要时都被正确销毁，特别注意动画、材质、纹理等资源的释放。

## 25601006 使用已失效的资源

**错误信息**

Expired or invalid resource.

**错误描述**

使用已经失效的资源，包括Node、Material、Animation、Sampler、Environment或RenderTarget等已被销毁或失效的资源。

**可能原因**

1. 资源已销毁释放后仍被引用使用。
2. 资源所属的Scene已销毁，资源随之失效但仍被引用。

**处理步骤**

1. 检查资源的销毁时机，确保销毁后不再引用该资源，在Scene销毁前释放所有对该Scene资源的引用。
2. 在使用资源前检查其是否有效（如检查resourceType属性是否可访问）。使用try-catch包裹可能引用失效资源的代码，捕获异常后进行处理。

## 25603001 参数超出限制范围

**错误信息**

Parameter exceeds the allowed range.

**错误描述**

单个参数不满足接口的限制约束，包括但不限于取值范围、长度、内容合法性等方面的限制。

**可能原因**

1. 参数取值超出接口允许的范围。
2. 数组参数长度超出接口允许的上限。
3. 数组参数内容不满足接口的规则约束，如数组为空或元素不满足接口要求等。

**处理步骤**

1. 检查数值参数是否超出接口允许的取值范围。
2. 检查数组长度是否超出接口允许的上限。
3. 检查数组参数内容是否满足接口的规则约束。

## 25603002 参数类型或数量不匹配

**错误信息**

Input parameter type or count mismatch.

**错误描述**

接口存在多个输入参数时，参数之间的类型或数量不满足匹配约束。

**可能原因**

接口要求多个参数之间存在对应关系，实际传入的参数不满足该关系。

**处理步骤**

对照API参考文档，确认各参数之间的对应关系，按接口要求正确传入参数。
