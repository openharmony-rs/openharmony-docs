# ColorFringeSettings

色晕设置。当RenderingPipelineType为FORWARD_LIGHTWEIGHT时，此功能不可用。

**起始版本：** 22

**系统能力：** SystemCapability.ArkUi.Graphics3D

## intensity

```TypeScript
intensity?: number
```

作用强度，取值范围为[0, 1]，默认值为0.2。

**类型：** number

**默认值：** 0.2

**起始版本：** 22

**系统能力：** SystemCapability.ArkUi.Graphics3D
