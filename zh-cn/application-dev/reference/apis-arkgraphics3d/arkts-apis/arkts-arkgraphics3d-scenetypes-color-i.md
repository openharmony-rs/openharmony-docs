# Color

用于表示RGBA格式的颜色，包含四个分量，依次为红色、绿色、蓝色和透明度。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## a

```TypeScript
a: number
```

透明度分量，取值范围是[0, 1]。

**类型：** number

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## b

```TypeScript
b: number
```

蓝色分量，取值范围是[0, 1]。

**类型：** number

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## g

```TypeScript
g: number
```

绿色分量，取值范围是[0, 1]。

**类型：** number

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## r

```TypeScript
r: number
```

红色分量，取值范围是[0, 1]。

**类型：** number

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D
