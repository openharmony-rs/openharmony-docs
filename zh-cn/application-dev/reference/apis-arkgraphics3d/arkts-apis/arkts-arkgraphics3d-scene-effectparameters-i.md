# EffectParameters

特效参数配置，用于指定创建特效时所需的特效ID，作为createEffect接口的入参来创建特效对象。

**起始版本：** 23

<!--Device-unnamed-export interface EffectParameters--><!--Device-unnamed-export interface EffectParameters-End-->

**系统能力：** SystemCapability.ArkUi.Graphics3D

## effectId

```TypeScript
effectId: string
```

用于创建特效的ID，固定格式为'XXXXXXXX-XXXX-XXXX-XXXX-XXXXXXXXXXXX'，比如'e68a7f45-2d21-4a0d-9aef-7d9c825d3f12'。

**类型：** string

**起始版本：** 23
