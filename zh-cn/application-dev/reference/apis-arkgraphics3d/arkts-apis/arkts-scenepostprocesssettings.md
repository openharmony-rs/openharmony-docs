# ScenePostProcessSettings

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| [BloomSettings](arkts-arkgraphics3d-scenepostprocesssettings-bloomsettings-i.md) | 泛光设置。当RenderingPipelineType为FORWARD_LIGHTWEIGHT时，此功能不可用。 |
| [ColorFringeSettings](arkts-arkgraphics3d-scenepostprocesssettings-colorfringesettings-i.md) | 色晕设置。当RenderingPipelineType为FORWARD_LIGHTWEIGHT时，此功能不可用。 |
| [PostProcessSettings](arkts-arkgraphics3d-scenepostprocesssettings-postprocesssettings-i.md) | 后处理设置，用于配置相机渲染后的图像处理效果，包括色调映射、泛光、边缘暗角和色晕等，作为Camera的postProcess属性来使用。 |
| [ToneMappingSettings](arkts-arkgraphics3d-scenepostprocesssettings-tonemappingsettings-i.md) | 色调映射设置。 |
| [VignetteSettings](arkts-arkgraphics3d-scenepostprocesssettings-vignettesettings-i.md) | 边缘暗角设置。 |
