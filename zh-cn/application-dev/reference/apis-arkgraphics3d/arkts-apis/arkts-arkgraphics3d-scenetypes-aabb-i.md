# Aabb

轴对齐边界盒，主要用于判断空间中的物体是否重叠。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## aabbMax

```TypeScript
aabbMax: Vec3
```

轴对齐边界盒的大值点，单位为世界坐标系下的场景单位（比如cm、m、km等）。

**类型：** [Vec3](arkts-arkgraphics3d-scenetypes-vec3-i.md)

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## aabbMin

```TypeScript
aabbMin: Vec3
```

轴对齐边界盒的小值点，单位为世界坐标系下的场景单位（比如cm、m、km等）。

**类型：** [Vec3](arkts-arkgraphics3d-scenetypes-vec3-i.md)

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D
