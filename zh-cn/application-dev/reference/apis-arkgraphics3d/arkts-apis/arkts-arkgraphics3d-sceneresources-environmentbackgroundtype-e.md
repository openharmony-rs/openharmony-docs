# EnvironmentBackgroundType

环境背景类型枚举，用于定义场景的背景呈现方式。 @enum { number }

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## BACKGROUND_NONE

```TypeScript
BACKGROUND_NONE = 0
```

无背景。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## BACKGROUND_IMAGE

```TypeScript
BACKGROUND_IMAGE = 1
```

图片背景。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## BACKGROUND_CUBEMAP

```TypeScript
BACKGROUND_CUBEMAP = 2
```

立方体贴图背景。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## BACKGROUND_EQUIRECTANGULAR

```TypeScript
BACKGROUND_EQUIRECTANGULAR = 3
```

等距柱状投影背景。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D
