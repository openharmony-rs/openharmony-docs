# Rect

用于表示平面中的矩形。

**起始版本：** 23

<!--Device-unnamed-export interface Rect--><!--Device-unnamed-export interface Rect-End-->

**系统能力：** SystemCapability.ArkUi.Graphics3D

## height

```TypeScript
height: double
```

矩形高度，单位为世界坐标系下的场景单位（比如cm、m、km等），有效取值范围大于0。

**类型：** double

**起始版本：** 23
