# ToneMappingSettings

色调映射设置。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## exposure

```TypeScript
exposure?: number
```

曝光度，取值大于0，默认值为undefined。

**类型：** number

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D

## type

```TypeScript
type?: ToneMappingType
```

色调映射类型，默认值为undefined。

**类型：** [ToneMappingType](arkts-arkgraphics3d-scenepostprocesssettings-tonemappingtype-e.md)

**起始版本：** 12

**系统能力：** SystemCapability.ArkUi.Graphics3D
