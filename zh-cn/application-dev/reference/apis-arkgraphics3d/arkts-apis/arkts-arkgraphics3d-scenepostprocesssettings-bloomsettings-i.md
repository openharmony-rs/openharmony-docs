# BloomSettings

泛光设置。当RenderingPipelineType为FORWARD_LIGHTWEIGHT时，此功能不可用。

**起始版本：** 18

**系统能力：** SystemCapability.ArkUi.Graphics3D

## scaleFactor

```TypeScript
scaleFactor?: number
```

缩放因子，取值范围大于0，默认值为1.0。

**类型：** number

**起始版本：** 18

**系统能力：** SystemCapability.ArkUi.Graphics3D

## scatter

```TypeScript
scatter?: number
```

扩散量，取值范围大于0，默认值为1.0。

**类型：** number

**起始版本：** 18

**系统能力：** SystemCapability.ArkUi.Graphics3D

## thresholdHard

```TypeScript
thresholdHard?: number
```

硬阈值，取值范围是非负数，默认值为1.0。

**类型：** number

**起始版本：** 18

**系统能力：** SystemCapability.ArkUi.Graphics3D

## thresholdSoft

```TypeScript
thresholdSoft?: number
```

软阈值，取值范围是非负数，默认值为2.0。

**类型：** number

**起始版本：** 18

**系统能力：** SystemCapability.ArkUi.Graphics3D
