**系统能力：** SystemCapability.Location.Location.Core

```TypeScript
```

## index

```TypeScript
index: number
```

表示匹配的WLAN在wlanBssidArray中的索引。

**类型：** number

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.0.0开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Location.Location.Core
