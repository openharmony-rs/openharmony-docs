# DistrictInfo

表示区域信息。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Location.Location.Geocoder

## 导入模块

```TypeScript
```

## administrativeArea

```TypeScript
administrativeArea?: string
```

表示国家以下的一级行政区，一般是省/州。

**类型：** string

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.0.0开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Location.Location.Geocoder
