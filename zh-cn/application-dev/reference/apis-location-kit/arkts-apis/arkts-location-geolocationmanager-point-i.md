# Point

表示一个位置点。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Location.Location.Core

## 导入模块

```TypeScript
```

## latitude

```TypeScript
latitude: number
```

表示纬度信息，正值表示北纬，负值表示南纬。取值范围为-90到90。仅支持WGS84坐标系。

**类型：** number

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Location.Location.Core

## longitude

```TypeScript
longitude: number
```

表示经度信息，正值表示东经，负值表示西经。取值范围为-180到180。仅支持WGS84坐标系。

**类型：** number

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Location.Location.Core
