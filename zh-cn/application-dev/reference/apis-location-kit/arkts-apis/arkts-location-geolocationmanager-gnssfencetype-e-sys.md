# GnssFenceType（系统接口）

GNSS围栏类型。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Location.Location.Geofence

**系统接口：** 此接口为系统接口。

## POLYGON

```TypeScript
POLYGON = 1
```

表示多边形围栏。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Location.Location.Geofence

**系统接口：** 此接口为系统接口。
