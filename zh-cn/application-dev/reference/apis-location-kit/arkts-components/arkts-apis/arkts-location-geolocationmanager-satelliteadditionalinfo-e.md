# SatelliteAdditionalInfo

卫星附加信息类型。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Gnss

## SATELLITES_ADDITIONAL_INFO_NULL

```TypeScript
SATELLITES_ADDITIONAL_INFO_NULL = 0
```

默认值。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Gnss

## SATELLITES_ADDITIONAL_INFO_EPHEMERIS_DATA_EXIST

```TypeScript
SATELLITES_ADDITIONAL_INFO_EPHEMERIS_DATA_EXIST = 1
```

表示本卫星具有星历数据。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Gnss

## SATELLITES_ADDITIONAL_INFO_ALMANAC_DATA_EXIST

```TypeScript
SATELLITES_ADDITIONAL_INFO_ALMANAC_DATA_EXIST = 2
```

表示本卫星具有年历数据。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Gnss

## SATELLITES_ADDITIONAL_INFO_USED_IN_FIX

```TypeScript
SATELLITES_ADDITIONAL_INFO_USED_IN_FIX = 4
```

表示在最新的位置解算中使用了本卫星。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Gnss

## SATELLITES_ADDITIONAL_INFO_CARRIER_FREQUENCY_EXIST

```TypeScript
SATELLITES_ADDITIONAL_INFO_CARRIER_FREQUENCY_EXIST = 8
```

表示本卫星具有载波频率。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Gnss
