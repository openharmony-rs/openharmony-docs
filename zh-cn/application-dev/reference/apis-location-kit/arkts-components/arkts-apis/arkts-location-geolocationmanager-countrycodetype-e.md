# CountryCodeType

国家码来源类型。

**起始版本：** 9

**系统能力：** SystemCapability.Location.Location.Core

## COUNTRY_CODE_FROM_LOCALE

```TypeScript
COUNTRY_CODE_FROM_LOCALE = 1
```

从全球化模块的语言配置信息中获取到的国家码。

**起始版本：** 9

**系统能力：** SystemCapability.Location.Location.Core

## COUNTRY_CODE_FROM_SIM

```TypeScript
COUNTRY_CODE_FROM_SIM = 2
```

从SIM卡中获取到的国家码。

**起始版本：** 9

**系统能力：** SystemCapability.Location.Location.Core

## COUNTRY_CODE_FROM_LOCATION

```TypeScript
COUNTRY_CODE_FROM_LOCATION = 3
```

基于用户的位置信息，通过逆地理编码查询到的国家码。

**起始版本：** 9

**系统能力：** SystemCapability.Location.Location.Core

## COUNTRY_CODE_FROM_NETWORK

```TypeScript
COUNTRY_CODE_FROM_NETWORK = 4
```

从蜂窝网络注册信息中获取到的国家码。

**起始版本：** 9

**系统能力：** SystemCapability.Location.Location.Core
