# LocationIconStatus（系统接口）

定位图标状态。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Core

**系统接口：** 此接口为系统接口。

## LOCATING_NOT_STARTED

```TypeScript
LOCATING_NOT_STARTED = 0
```

表示当前无定位业务，无需显示定位图标。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Core

**系统接口：** 此接口为系统接口。

## LOCATING_STARTED

```TypeScript
LOCATING_STARTED = 1
```

表示当前在进行普通定位业务，需要显示普通定位图标。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Core

**系统接口：** 此接口为系统接口。

## HD_LOCATING_STARTED

```TypeScript
HD_LOCATING_STARTED = 2
```

表示当前正在进行高精度定位业务，需要显示高精度定位图标。

**起始版本：** 12

**系统能力：** SystemCapability.Location.Location.Core

**系统接口：** 此接口为系统接口。
