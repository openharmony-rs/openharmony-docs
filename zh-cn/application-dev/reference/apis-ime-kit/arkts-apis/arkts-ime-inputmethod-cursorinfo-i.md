## height

```TypeScript
height: double
```

光标的高度，单位为px。该参数应为整数，最小值为0，最大值为当前屏幕的高度。

**类型：** double

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。
