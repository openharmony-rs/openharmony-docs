# KeyEvent

按键属性值。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## keyAction

```TypeScript
readonly keyAction: int
```

按键事件类型。 - 当值为2时，表示按下事件； - 当值为3时，表示抬起事件。

**类型：** int

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
