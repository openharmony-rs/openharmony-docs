# ReportingMode（系统接口）

测距接口执行完成后结果的上报模式。@enum { number } 测距结果上报方式

**起始版本：** 23

**系统能力：** SystemCapability.MultimodalAwareness.DistanceMeasurement

**系统接口：** 此接口为系统接口。

## REPORT_MODE_PERIODIC_REPORTING

```TypeScript
REPORT_MODE_PERIODIC_REPORTING = 0
```

表示周期性上报。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.DistanceMeasurement

**系统接口：** 此接口为系统接口。

## REPORT_MODE_TRIGGERED_REPORTING

```TypeScript
REPORT_MODE_TRIGGERED_REPORTING = 1
```

表示触发式上报。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.DistanceMeasurement

**系统接口：** 此接口为系统接口。
