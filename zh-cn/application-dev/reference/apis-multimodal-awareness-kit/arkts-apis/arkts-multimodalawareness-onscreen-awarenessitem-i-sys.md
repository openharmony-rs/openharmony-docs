# AwarenessItem（系统接口）

提供页面信息。包括： * 页面基础信息，如页面内容、链接、截屏。 * 页面实体信息，如页面文章的标题、正文信息。 * 页面交互信息，如点击、滚动信息。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
