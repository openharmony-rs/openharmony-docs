# PositionRelativeToDoor（系统接口）

门内外识别接口返回结果中表示门内或门外位置的枚举。@enum { number } 门内外识别结果的枚举

**起始版本：** 23

**系统能力：** SystemCapability.MultimodalAwareness.DistanceMeasurement

**系统接口：** 此接口为系统接口。

```TypeScript
OUTDOOR = 0
```
