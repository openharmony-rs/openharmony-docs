# OperatingHandStatus

触控操作手状态信息。

**起始版本：** 15

**系统能力：** SystemCapability.MultimodalAwareness.Motion

## UNKNOWN_STATUS

```TypeScript
UNKNOWN_STATUS = 0
```

表示未识别。

**起始版本：** 15

**系统能力：** SystemCapability.MultimodalAwareness.Motion

## LEFT_HAND_OPERATED

```TypeScript
LEFT_HAND_OPERATED = 1
```

表示触控操作手是左手。

**起始版本：** 15

**系统能力：** SystemCapability.MultimodalAwareness.Motion

## RIGHT_HAND_OPERATED

```TypeScript
RIGHT_HAND_OPERATED = 2
```

表示触控操作手是右手。

**起始版本：** 15

**系统能力：** SystemCapability.MultimodalAwareness.Motion
