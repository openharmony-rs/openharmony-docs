# PhysicalOrientation（系统接口）

传感器检测到的物理方向枚举。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.MultimodalAwareness.Motion

**系统接口：** 此接口为系统接口。

## UPRIGHT

```TypeScript
UPRIGHT = 0
```

表示竖直。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.Motion

**系统接口：** 此接口为系统接口。
