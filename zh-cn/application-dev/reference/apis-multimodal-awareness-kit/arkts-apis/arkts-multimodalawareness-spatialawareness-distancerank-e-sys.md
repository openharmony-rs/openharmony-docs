# DistanceRank（系统接口）

测距结果的距离挡位，不同的挡位对应不同的距离范围。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.MultimodalAwareness.DistanceMeasurement

**系统接口：** 此接口为系统接口。

## RANK_ULTRA_SHORT_RANGE

```TypeScript
RANK_ULTRA_SHORT_RANGE = 'rankUltraShort'
```

表示超短距。单位:cm，范围:[0:5]

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
