## 导入模块


## height

```TypeScript
height: int
```

矩形区域的高度，单位为px，该参数应为整数，取值范围为：[1,2147483647]。

**类型：** int

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。
