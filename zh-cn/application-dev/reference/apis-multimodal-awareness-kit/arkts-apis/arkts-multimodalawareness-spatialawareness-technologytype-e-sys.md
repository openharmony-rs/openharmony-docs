# TechnologyType（系统接口）

提供输入信号的类型。接口根据输入信号类型，执行对应算法。@enum { number } 测距技术类型

**起始版本：** 23

**系统能力：** SystemCapability.MultimodalAwareness.DistanceMeasurement

**系统接口：** 此接口为系统接口。

## BLE_RSSI

```TypeScript
BLE_RSSI = 0
```

表示蓝牙强度。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.DistanceMeasurement

**系统接口：** 此接口为系统接口。
