# CollectStrategy（系统接口）

页面信息收集策略。

**起始版本：** 23

**系统能力：** SystemCapability.MultimodalAwareness.OnScreenAwareness

**系统接口：** 此接口为系统接口。

## ALLOW

```TypeScript
ALLOW = 1 << 0
```

应用支持采集。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。
