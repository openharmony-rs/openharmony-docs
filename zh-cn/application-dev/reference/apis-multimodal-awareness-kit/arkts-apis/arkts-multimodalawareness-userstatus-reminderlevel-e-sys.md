# ReminderLevel（系统接口）

表示提醒强度级别，触发提醒铃声时使用。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.MultimodalAwareness.UserStatus

**系统接口：** 此接口为系统接口。

## WEAK_REMINDER

```TypeScript
WEAK_REMINDER = 0
```

表示弱提醒级别。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.UserStatus

**系统接口：** 此接口为系统接口。

## NORMAL_REMINDER

```TypeScript
NORMAL_REMINDER = 1
```

表示正常提醒级别。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.UserStatus

**系统接口：** 此接口为系统接口。
