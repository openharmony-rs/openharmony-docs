# DeviceType（系统接口）

表示设备类型。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.MultimodalAwareness.UserStatus

**系统接口：** 此接口为系统接口。

## UNKNOWN_TYPE

```TypeScript
UNKNOWN_TYPE = 0
```

表示设备类型未知。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.UserStatus

**系统接口：** 此接口为系统接口。
