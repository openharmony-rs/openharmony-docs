# SpatialMotionInfo

空间运动响应信息的接口。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.MultimodalAwareness.CarAwareness

## 导入模块

```TypeScript
import { carAwareness } from '@kit.MultimodalAwarenessKit';
```

## event

```TypeScript
event: number
```

指示屏幕上的手移动。取值限定为整数。

**类型：** number

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.CarAwareness

## pointX

```TypeScript
pointX: number
```

指示手在屏幕上的X坐标。

**类型：** number

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.MultimodalAwareness.CarAwareness

## pointY

```TypeScript
pointY: number
```

指示手在屏幕上的Y坐标。

**类型：** number

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。
