# ActivityEvent

设备状态事件。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary

## ENTER

```TypeScript
ENTER = 1
```

进入事件，表示设备进入静止状态时触发。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary

## EXIT

```TypeScript
EXIT = 2
```

退出事件，表示设备退出静止状态时触发。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary

## ENTER_EXIT

```TypeScript
ENTER_EXIT = 3
```

进入和退出事件，表示设备进入和退出静止状态时均会触发。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary
