# ActivityState

设备状态返回值。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary

## ENTER

```TypeScript
ENTER = 1
```

进入状态，表示设备当前处于静止状态。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary

## EXIT

```TypeScript
EXIT = 2
```

退出状态，表示设备当前未处于静止状态。

**起始版本：** 9

**系统能力：** SystemCapability.Msdp.DeviceStatus.Stationary
