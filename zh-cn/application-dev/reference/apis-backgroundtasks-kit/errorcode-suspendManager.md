# suspendManager错误码

> **说明**：
>
> 以下仅介绍本模块特有错误码，通用错误码请参考[通用错误码说明文档](../errorcode-universal.md)。

## 31800005 参数错误

**错误信息**

Parameter error.

**错误描述**

传入的参数不合法，例如：observer未注册就调用注销接口、observer已注册再次调用注册接口、pidList中包含非正整数等。

**处理步骤**

检查传入参数是否合法，确保参数类型和取值范围符合接口要求。

## 31800006 获取冻结管理服务失败

**错误信息**

Failed to get suspend manager service.

**错误描述**

获取冻结管理服务失败。

**处理步骤**

系统内部服务异常，请稍后重试。若持续出现，请检查系统服务是否正常运行。
