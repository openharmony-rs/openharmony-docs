# PrismShapeType（系统接口）

枚举 SweepRefractionMask 的棱镜形状类型。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Graphics.Drawing

**系统接口：** 此接口为系统接口。

## ROUNDED_RECT

```TypeScript
ROUNDED_RECT = 0
```

圆角矩形棱镜形状。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Graphics.Drawing

**系统接口：** 此接口为系统接口。

## ELLIPSE

```TypeScript
ELLIPSE = 1
```

椭圆棱镜形状。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Graphics.Drawing

**系统接口：** 此接口为系统接口。
