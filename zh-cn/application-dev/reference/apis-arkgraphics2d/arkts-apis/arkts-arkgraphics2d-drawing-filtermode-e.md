**废弃版本：** -1

## FILTER_MODE_NEAREST

```TypeScript
FILTER_MODE_NEAREST = 0
```

邻近过滤模式，使用最近的像素点进行采样。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## FILTER_MODE_LINEAR

```TypeScript
FILTER_MODE_LINEAR = 1
```

线性过滤模式，使用周围像素点的加权平均值进行采样。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
