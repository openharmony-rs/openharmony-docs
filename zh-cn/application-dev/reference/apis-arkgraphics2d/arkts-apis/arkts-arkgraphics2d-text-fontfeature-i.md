# FontFeature

文本字体特征。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## name

```TypeScript
name: string
```

字体特征键值对中的关键字标识，如'liga'（标准连字）、'kern'（字距调整）等。

**类型：** string

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**原子化服务API：** 从API版本22开始，该接口支持在原子化服务API中使用。
