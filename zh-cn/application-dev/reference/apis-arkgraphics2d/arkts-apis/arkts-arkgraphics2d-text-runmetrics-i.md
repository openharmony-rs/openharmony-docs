# RunMetrics

描述文本行中连续文本块的布局信息和度量数据。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

```TypeScript
fontMetrics: drawing.FontMetrics
```

字体度量信息。

**类型：** drawing.FontMetrics

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**原子化服务API：** 从API版本22开始，该接口支持在原子化服务API中使用。
