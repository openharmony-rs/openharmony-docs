# Rect

矩形区域，通过左上角点和右下角点两个坐标点定义。

**起始版本：** 11

**系统能力：** SystemCapability.Graphics.Drawing

## 导入模块

```TypeScript
import { common2D } from '@kit.ArkGraphics2D';
```

## bottom

```TypeScript
bottom: number
```

矩形区域的右下角纵坐标，浮点数。单位为物理像素px。

**类型：** number

**起始版本：** 11

**原子化服务API：** 从API版本22开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Graphics.Drawing
