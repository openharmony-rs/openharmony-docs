# RectStyle

矩形框样式。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.Graphics.Drawing

```TypeScript

```

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。
