# SideBySideTransparentVideoLayoutMode

```TypeScript
enum SideBySideTransparentVideoLayoutMode
```

拼接模式的透明视频布局枚举定义;用于指明透明视频的alpha数据在图像中的位置，便于播放器正确合成透明效果的视频；

**起始版本：** 26.1.0

**系统能力：** SystemCapability.Multimedia.Media.Core

## SIDE_BY_SIDE_LAYOUT_HORIZONTAL

```TypeScript
SIDE_BY_SIDE_LAYOUT_HORIZONTAL = 0
```

指示透明视频为左右布局，左边数据为alpha数据

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。
