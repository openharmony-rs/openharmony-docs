# @ohos.multimedia.videoProcessing(提供视频画质处理能力。)

提供VideoProcessor类型，包括AIHDR相关功能。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.VideoProcessingEngine

## 导入模块

```TypeScript
import { videoProcessing } from '@kit.MediaKit';
```
