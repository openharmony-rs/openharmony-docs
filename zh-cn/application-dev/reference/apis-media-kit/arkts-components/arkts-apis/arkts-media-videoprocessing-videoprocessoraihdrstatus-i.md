# VideoProcessorAiHdrStatus

提供AIHDR功能状态。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Multimedia.VideoProcessingEngine

## 导入模块

```TypeScript
import { videoProcessing } from '@kit.MediaKit';
```

## enabled

```TypeScript
enabled?: boolean
```

AIHDR是否启用。

**类型：** boolean

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.VideoProcessingEngine
