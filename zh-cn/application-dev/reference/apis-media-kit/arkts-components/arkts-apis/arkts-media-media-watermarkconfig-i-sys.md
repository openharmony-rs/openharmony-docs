# WatermarkConfig（系统接口）

设置给AVRecorder的水印相关配置，该位置以画面的左上角为开始点。

**起始版本：** 13

**系统能力：** SystemCapability.Multimedia.Media.Core

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { media } from '@kit.MediaKit';
```

## left

```TypeScript
left: number
```

显示位置，距离图像左部的像素偏移量。

**类型：** number

**起始版本：** 13

**系统能力：** SystemCapability.Multimedia.Media.Core

**系统接口：** 此接口为系统接口。

## top

```TypeScript
top: number
```

显示位置，距离图像顶部的像素偏移量。

**类型：** number

**起始版本：** 13

**系统能力：** SystemCapability.Multimedia.Media.Core

**系统接口：** 此接口为系统接口。
