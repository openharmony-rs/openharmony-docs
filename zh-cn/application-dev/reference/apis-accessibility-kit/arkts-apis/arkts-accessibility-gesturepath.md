# @ohos.accessibility.GesturePath(手势路径)

GesturePath表示手势路径信息。
 本模块用于创建手势路径信息，供辅助功能注入手势使用。


## 导入模块

```TypeScript
import { GesturePath } from '@kit.AccessibilityKit';
```
