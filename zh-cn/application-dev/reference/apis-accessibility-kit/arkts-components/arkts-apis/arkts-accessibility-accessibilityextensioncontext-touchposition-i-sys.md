# TouchPosition（系统接口）

触摸点击位置。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.BarrierFree.Accessibility.Core

**系统接口：** 此接口为系统接口。

## x

```TypeScript
x: number
```

点击位置x坐标，单位为像素（px）。

**类型：** number

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.BarrierFree.Accessibility.Core

**系统接口：** 此接口为系统接口。
