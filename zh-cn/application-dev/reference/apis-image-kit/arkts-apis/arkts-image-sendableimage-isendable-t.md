# ISendable

```TypeScript
type ISendable = lang.ISendable
```

ISendable是所有Sendable类型（除null和undefined）的父类型。自身没有任何必须的方法和属性。

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**废弃版本：** -1
