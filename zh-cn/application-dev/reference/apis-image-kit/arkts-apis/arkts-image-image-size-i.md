## height

```TypeScript
height: number
```

图像或区域的高度。单位：像素（px）。取值范围是正整数。

**类型：** number

**起始版本：** 6

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**卡片能力：** 从API版本12开始，该接口支持在ArkTS卡片中使用。
