**废弃版本：** -1

## desiredPixelFormat

```TypeScript
desiredPixelFormat?: PixelMapFormat
```

用于合成图像的像素格式，支持RGBA_1010102、YCBCR_P010和YCRCB_P010格式。

**类型：** [PixelMapFormat](arkts-image-image-pixelmapformat-e.md)

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
