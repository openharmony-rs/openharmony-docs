# @ohos.multimedia.image

本模块提供图片的解码、编码、编辑、元数据处理和图片接收等能力。 本模块包含以下基础类： - [ImageSource]\_\_\_JSDOC\_LINK\_DESC\_USD\_8\_\_\_类，提供获取[图片信息]\_\_\_JSDOC\_LINK\_DESC\_USD\_9\_\_\_、将图片解码为PixelMap或Picture、读取和修改 [图片属性]\_\_\_JSDOC\_LINK\_DESC\_USD\_10\_\_\_的能力。\_\_\_MD\_LINK\_DESC\_USD\_0\_\_\_ 包括png、jpeg、bmp、gif、webp、dng、heic\_\_\_HTML\_TAG\_DESC\_USD\_38\_\_\_12+\_\_\_HTML\_TAG\_DESC\_USD\_39\_\_\_、wbmp\_\_\_HTML\_TAG\_DESC\_USD\_40\_\_\_23+\_\_\_HTML\_TAG\_DESC\_USD\_41\_\_\_、heifs\_\_\_HTML\_TAG\_DESC\_USD\_42\_\_\_23+\_\_\_HTML\_TAG\_DESC\_USD\_43\_\_\_、tiff\_\_\_HTML\_TAG\_DESC\_USD\_44\_\_\_23+\_\_\_HTML\_TAG\_DESC\_USD\_45\_\_\_。 - [PixelMap]\_\_\_JSDOC\_LINK\_DESC\_USD\_12\_\_\_类，位图对象，包含像素数据以及[图片信息]\_\_\_JSDOC\_LINK\_DESC\_USD\_13\_\_\_。可用于读取或写入像素数据，进行裁剪、缩放、平移、旋转、镜像等操作，并可直接传 给[Image组件]\_\_\_JSDOC\_LINK\_DESC\_USD\_14\_\_\_用于显示。还提供了获取和设置图片色域、HDR元数据的方法。 -
