# 常量

## MAX_ALLOWABLE_REUSE_DURATION

```TypeScript
const MAX_ALLOWABLE_REUSE_DURATION: int
```

永久锁定时长，单位为毫秒。取值为0x7fffffffff，代表认证永久锁定，不代表具体锁定时长。 取值范围为全体整数。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。
