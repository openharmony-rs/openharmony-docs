# errnoToString

## errnoToString

```TypeScript
function errnoToString(errno: int): string
```

Get the string name of the system errno.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

<!--Device-util-function errnoToString(errno: int): string--><!--Device-util-function errnoToString(errno: int): string-End-->

**系统能力：** SystemCapability.Utils.Lang

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| errno | int | 是 | The error code generated by an error in the system |

**返回值：**

| 类型 | 说明 |
| --- | --- |
| string | Return the string name of a system errno |
