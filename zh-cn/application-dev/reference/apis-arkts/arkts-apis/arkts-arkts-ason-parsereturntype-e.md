# ParseReturnType

定义解析结果的返回类型。

**起始版本：** 12

**系统能力：** SystemCapability.Utils.Lang

## OBJECT

```TypeScript
OBJECT = 0
```

返回 SendableObject 对象。

**起始版本：** 12

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Utils.Lang

## MAP

```TypeScript
MAP = 1
```

返回 SendableMap 对象。

**起始版本：** 13

**原子化服务API：** 从API版本13开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Utils.Lang
