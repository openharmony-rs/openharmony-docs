# @ohos.url

URL是统一资源定位符，本模块提供了常用的工具函数，实现了解析URL字符串、构造URL对象以及对URL查询参数的解析和操作等功能。 模块主要包含以下核心类： - [URL]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_：用于解析和构造完整URL。 - [URLParams]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_：用于操作URL查询参数。 - [URLSearchParams]\_\_\_JSDOC\_LINK\_DESC\_USD\_2\_\_\_：从API version 9开始废弃，建议使用[URLParams]\_\_\_JSDOC\_LINK\_DESC\_USD\_3\_\_\_替代。 > **说明：** > > - 本模块同时支持ArkTS-Dyn、ArkTS-Sta。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。
