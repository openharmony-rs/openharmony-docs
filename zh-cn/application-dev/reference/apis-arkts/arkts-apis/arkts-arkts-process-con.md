# 常量

## pid

```TypeScript
const pid: number
```

进程的 ID（PID）。

**起始版本：** 7

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Utils.Lang
