# 常量（系统接口）

## egid

```TypeScript
const egid: number
```

返回进程的有效组 ID（数值形式）。

**类型：** number

**起始版本：** 7

**系统能力：** SystemCapability.Utils.Lang

**系统接口：** 此接口为系统接口。

**测试接口：** 此接口仅在自动化测试脚本中使用。
