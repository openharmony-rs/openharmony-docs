# ShortMessageClass

短信类型。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.SmsMms

## UNKNOWN

```TypeScript
UNKNOWN = 0
```

未知类型。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.SmsMms

## INSTANT_MESSAGE

```TypeScript
INSTANT_MESSAGE = 1
```

即时消息，收到后立即显示。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.SmsMms

## OPTIONAL_MESSAGE

```TypeScript
OPTIONAL_MESSAGE = 2
```

存储在设备或SIM卡上的短信。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.SmsMms

## SIM_MESSAGE

```TypeScript
SIM_MESSAGE = 3
```

包含SIM卡信息的短信，需要存储在SIM卡中。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.SmsMms

## FORWARD_MESSAGE

```TypeScript
FORWARD_MESSAGE = 4
```

要转发到另一台设备的短信。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.SmsMms
