# DialOptions

拨打电话的可选参数。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CallManager

## 导入模块

```TypeScript
```

## extras

```TypeScript
extras?: boolean
```

根据extras的值判断是否为视频通话，默认为语音通话。  
- true：视频通话。  
- false：语音通话。

**类型：** boolean

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CallManager
