# DialOptions

拨打电话的可选参数。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## extras

```TypeScript
extras?: boolean
```

根据extras的值判断是否为视频通话，默认为语音通话。 - true：视频通话。 - false：语音通话。

**类型：** boolean

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
