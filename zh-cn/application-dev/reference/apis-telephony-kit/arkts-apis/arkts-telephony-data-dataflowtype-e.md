# DataFlowType

描述蜂窝数据流类型。

**起始版本：** 7

**系统能力：** SystemCapability.Telephony.CellularData

## DATA_FLOW_TYPE_NONE

```TypeScript
DATA_FLOW_TYPE_NONE = 0
```

表示没有上行或下行数据。

**起始版本：** 7

**系统能力：** SystemCapability.Telephony.CellularData

## DATA_FLOW_TYPE_DOWN

```TypeScript
DATA_FLOW_TYPE_DOWN = 1
```

表示只有下行数据。

**起始版本：** 7

**系统能力：** SystemCapability.Telephony.CellularData

## DATA_FLOW_TYPE_UP

```TypeScript
DATA_FLOW_TYPE_UP = 2
```

表示只有上行数据。

**起始版本：** 7

**系统能力：** SystemCapability.Telephony.CellularData

## DATA_FLOW_TYPE_UP_DOWN

```TypeScript
DATA_FLOW_TYPE_UP_DOWN = 3
```

表示有上下行数据。

**起始版本：** 7

**系统能力：** SystemCapability.Telephony.CellularData

## DATA_FLOW_TYPE_DORMANT

```TypeScript
DATA_FLOW_TYPE_DORMANT = 4
```

表示没有上下行数据，底层链路处于休眠状态。

**起始版本：** 7

**系统能力：** SystemCapability.Telephony.CellularData
