# CallTransferSettingType（系统接口）

设置呼叫转移类型。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## CALL_TRANSFER_DISABLE

```TypeScript
CALL_TRANSFER_DISABLE = 0
```

禁用呼叫转移。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## CALL_TRANSFER_ENABLE

```TypeScript
CALL_TRANSFER_ENABLE = 1
```

启用呼叫转移。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## CALL_TRANSFER_REGISTRATION

```TypeScript
CALL_TRANSFER_REGISTRATION = 3
```

登记呼叫转移。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## CALL_TRANSFER_ERASURE

```TypeScript
CALL_TRANSFER_ERASURE = 4
```

消除呼叫转移。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。
