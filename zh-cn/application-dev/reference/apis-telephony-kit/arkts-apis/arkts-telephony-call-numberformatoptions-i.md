## countryCode

```TypeScript
countryCode?: string
```

国家码，支持所有国家的国家码，如：CN（中国）。默认为：CN。

**类型：** string

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。
