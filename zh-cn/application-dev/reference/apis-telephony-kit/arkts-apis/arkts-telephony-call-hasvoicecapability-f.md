# hasVoiceCapability

## hasVoiceCapability

```TypeScript
function hasVoiceCapability(): boolean
```

检查当前设备是否具备语音通话能力。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.Telephony.CallManager

**返回值：**

| 类型 | 说明 |
| --- | --- |
| boolean | 返回true表示设备具备语音通话能力，返回false表示设备不具备语音通话能力。 |
