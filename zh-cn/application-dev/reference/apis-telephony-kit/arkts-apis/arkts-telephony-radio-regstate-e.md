# RegState

网络注册状态。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CoreService

## REG_STATE_NO_SERVICE

```TypeScript
REG_STATE_NO_SERVICE = 0
```

设备不能使用任何服务，包括数据业务、短信、通话等。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CoreService

## REG_STATE_IN_SERVICE

```TypeScript
REG_STATE_IN_SERVICE = 1
```

设备可以正常使用服务，包括数据业务、短信、通话等。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CoreService

## REG_STATE_EMERGENCY_CALL_ONLY

```TypeScript
REG_STATE_EMERGENCY_CALL_ONLY = 2
```

设备只能使用紧急呼叫业务。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CoreService

## REG_STATE_POWER_OFF

```TypeScript
REG_STATE_POWER_OFF = 3
```

蜂窝无线电已关闭，modem下电，无法和网侧进行通信。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CoreService
