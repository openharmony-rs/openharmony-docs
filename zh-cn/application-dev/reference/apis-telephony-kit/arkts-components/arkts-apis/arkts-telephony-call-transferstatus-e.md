# TransferStatus

转移状态。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Telephony.CallManager

## TRANSFER_DISABLE

```TypeScript
TRANSFER_DISABLE = 0
```

禁用转移。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Telephony.CallManager

## TRANSFER_ENABLE

```TypeScript
TRANSFER_ENABLE = 1
```

启用转移。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Telephony.CallManager
