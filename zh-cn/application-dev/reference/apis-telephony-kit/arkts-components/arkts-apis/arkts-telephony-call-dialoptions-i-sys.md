# DialOptions

拨打电话的可选参数。

**起始版本：** 6

**系统能力：** SystemCapability.Telephony.CallManager

## 导入模块

```TypeScript
import { call } from '@kit.TelephonyKit';
```

## accountId

```TypeScript
accountId?: number
```

帐户Id。

- 0：卡槽1。  
- 1：卡槽2。

。此接口为系统接口。

**类型：** number

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## dialScene

```TypeScript
dialScene?: DialScene
```

拨号场景。此接口为系统接口。

**类型：** [DialScene](arkts-telephony-call-dialscene-e-sys.md)

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

dialType?: DialType
