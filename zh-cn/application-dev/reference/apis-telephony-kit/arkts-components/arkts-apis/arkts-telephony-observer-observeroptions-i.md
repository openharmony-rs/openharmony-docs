# ObserverOptions

电话相关事件订阅参数可选项。

**起始版本：** 11

**系统能力：** SystemCapability.Telephony.StateRegistry

## 导入模块

```TypeScript
import { observer } from '@kit.TelephonyKit';
```

## slotId

```TypeScript
slotId: number
```

卡槽ID。

- 0：卡槽1。  
- 1：卡槽2。

**类型：** number

**起始版本：** 11

**系统能力：** SystemCapability.Telephony.StateRegistry
