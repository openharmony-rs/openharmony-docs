# RestrictionStatus（系统接口）

限制状态。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## RESTRICTION_DISABLE

```TypeScript
RESTRICTION_DISABLE = 0
```

禁用限制。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## RESTRICTION_ENABLE

```TypeScript
RESTRICTION_ENABLE = 1
```

启用限制。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。
