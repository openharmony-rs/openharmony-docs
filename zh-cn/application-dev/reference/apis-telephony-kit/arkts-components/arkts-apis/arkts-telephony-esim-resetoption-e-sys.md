# ResetOption（系统接口）

重置状态。

**起始版本：** 18

**系统能力：** SystemCapability.Telephony.CoreService.Esim

**系统接口：** 此接口为系统接口。

## DELETE_OPERATIONAL_PROFILES

```TypeScript
DELETE_OPERATIONAL_PROFILES = 1
```

删除所有操作配置文件。

**起始版本：** 18

**系统能力：** SystemCapability.Telephony.CoreService.Esim

**系统接口：** 此接口为系统接口。

```TypeScript

```

**系统接口：** 此接口为系统接口。
