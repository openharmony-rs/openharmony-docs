# CallRestrictionMode（系统接口）

呼叫限制模式。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## RESTRICTION_MODE_DEACTIVATION

```TypeScript
RESTRICTION_MODE_DEACTIVATION = 0
```

限制模式停用。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## RESTRICTION_MODE_ACTIVATION

```TypeScript
RESTRICTION_MODE_ACTIVATION = 1
```

限制模式激活。

**起始版本：** 8

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。
