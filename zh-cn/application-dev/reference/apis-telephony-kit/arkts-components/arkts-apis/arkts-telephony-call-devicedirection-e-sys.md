# DeviceDirection（系统接口）

视频通话画面方向类型。

**起始版本：** 11

**系统能力：** SystemCapability.Telephony.CallManager

**系统接口：** 此接口为系统接口。

## DEVICE_DIRECTION_0

```TypeScript
DEVICE_DIRECTION_0 = 0
```

视频画面0度方向。

**起始版本：** 11

**系统能力：** SystemCapability.Telephony.CallManager
