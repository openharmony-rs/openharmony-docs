## A

### Air Mouse Mode; 空鼠模式

手写笔的隔空操作模式：通过在空中转动手写笔控制屏幕上虚拟光标的移动，并借助笔身按键实现上下翻页，适用于演示PPT、隔空操作等场景。进入该模式后系统自动使用悬浮光标、点击光标或激光笔光标，应用无法通过常规光标样式接口直接设置，区别于手写笔在屏幕上书写的常规触控输入。

### Alphabetic Keyboard; 全键盘

配备完整字母键区的键盘（如QWERTY布局），可输入字母、数字及组合快捷键。用于通过键盘类型查询判断设备是否具备完整文字输入能力，区别于仅有数字键区的小键盘。

### 按键前置监听

在按键事件进入常规分发流程之前对其进行监听拦截的机制，目前仅支持左/右Meta键、电源键和音量键，仅系统应用可用。用于系统层优先响应特定系统功能键，区别于普通的按键事件监听。

### Application Hotkey; 应用快捷键

由应用自定义并注册的全局快捷键，在应用运行期间响应对应的组合按键输入。区别于系统快捷键：若与系统或其他应用已注册的快捷键冲突，订阅时会返回错误码。

### Axis; 轴

输入设备上报的连续数值维度，如横坐标轴（x）、纵坐标轴（y）、压力轴、方向轴等，每根轴具有最大值、最小值、分辨率等范围属性。用于刻画触摸屏、触控板、操纵杆等设备的连续输入状态，区别于按键这类离散输入信号。

### Axis Action; 轴事件动作

轴事件在交互过程中的生命周期状态，分为取消、开始、更新和结束四类。应用据此区分一个连续手势（如滚动、捏合）当前所处阶段并作出相应处理。

### Axis Event; 轴事件

由鼠标滚轮滚动、触控板手势、游戏手柄摇杆移动等轴类连续输入产生的事件，以轴类型（垂直/水平滚动轴、捏合轴、旋转轴）和轴值描述输入量，一个有效序列由开始事件、零次或多次更新事件、结束（或取消）事件按序构成，且同一时间只允许一个进行中的序列。区别于按键等离散事件，常用于页面滚动、缩放等连续交互。

### Axis Event Type; 轴事件类型

按手势来源对轴事件所做的分类，分为捏合事件（含捏合轴和旋转轴两种轴类型）和滚轴事件（含垂直、水平两种滚动轴，其中鼠标滚轮事件仅含垂直滚动轴）。应用据此区分轴事件承载的手势语义。

### Axis Type; 轴类型

输入设备在不同交互场景下物理行为特征的分类定义，包括垂直滚动轴、水平滚动轴、捏合轴和旋转轴。系统通过轴类型区分和传递不同的手势交互信息。

## B

### Bus Type; 总线类型

输入设备接入系统所使用的硬件通道类别（如USB、蓝牙），以设备上报为准。用于在设备信息中标识物理连接方式，是外接设备管理与绑定的依据之一。

## C

### Cursor; 光标

屏幕上跟随鼠标、触控板等指针设备移动的图形指示器，标示当前指向位置及操作语义，也称鼠标光标、鼠标指针。系统提供显示/隐藏、样式、大小、颜色、移动速度等管理能力。

### Cursor Anchor; 光标焦点

自定义光标图像中作为实际作用点的像素坐标，鼠标事件上报的坐标对应该点而非图像左上角。用于保证视觉热点位置（如箭头尖端）与实际点击、指向位置一致。

### Cursor Info; 光标信息

描述鼠标光标呈现状态的属性集合，包括显示/隐藏状态、光标样式、光标大小档位（1~7档，数值越大光标越大）以及以32位ARGB整数表示的光标颜色。既可查询当前光标的信息，也可随某个鼠标事件查询事件发生时刻的光标状态。

### Custom Cursor; 自定义光标

应用使用自有像素图（尺寸上限256×256像素）替换系统预置光标的机制，可指定光标焦点坐标及是否跟随系统设置调整大小，仅对本应用进程内的窗口生效。窗口布局变化、热区切换、页面跳转等场景可能导致光标回退为系统样式，需重新设置；区别于从系统预置样式集合中选取的光标样式。

## D

### Device Descriptor; 设备描述符

在设备组网中标识一台设备的字符串，键鼠穿越用它指定目标设备。区别于数值型的输入设备ID：目标设备未组网或描述符为空时，穿越操作会失败并报错。

### Digital Keypad; 小键盘

仅包含数字键和少量功能键的键区设备或键盘子区域，如遥控器、计算器键盘。系统中作为一种键盘类型被识别，区别于带完整字母键区的全键盘。

### Display Coordinate System; 屏幕坐标系

以指定屏幕左上角为原点的相对坐标系，单位为像素，用于表示鼠标、触屏、轴等输入事件在屏幕上的位置。区别于以主屏左上角为原点、坐标跨屏统一的全局坐标系，多屏场景下两者的坐标值不同。

### Display Group; 显示器组

多个显示器组成的逻辑显示单元，输入设备绑定到组内某一显示器后即可在该组范围内操作。用于多屏场景下组织屏幕与输入的对应关系。

### Double-tap and Drag; 双击拖拽

触控板上快速双击后手指保持接触并移动即可拖动内容的操作方式，效果相当于按住鼠标左键拖拽。可通过系统开关启停，用于在无需物理按压的情况下完成拖动操作。

## E

### Event Consumption; 事件消费

按键事件被订阅方处理后即终止向后分发、并屏蔽系统默认响应（如音量调节）的机制。用于组合键订阅和音量键、媒体键等单键订阅场景，取消订阅后系统默认行为恢复。

### Event Injection; 事件注入

以编程方式构造按键、鼠标、触屏、轴等输入事件并送入系统输入通道、模拟真实用户输入的能力，主要用于自动化测试等场景。注入须遵循事件状态约束（按键先按下后抬起、轴事件序列先开始后更新再结束、同一触点不能重复按下等），并受权限管控：系统侧需ohos.permission.INJECT_INPUT_EVENT，开放侧需ohos.permission.CONTROL_DEVICE权限或先获得用户注入授权，注入产生的触屏事件会被标记为注入事件。

### Event Interception; 输入事件拦截

应用在系统分发输入事件前截获并自行处理的机制，支持按键、鼠标、触屏和轴事件。按键事件拦截仅在应用获焦时生效，鼠标、触屏和轴事件拦截仅在命中应用窗口时生效，同一应用重复添加仅首次生效；区别于只观察不阻断的事件监听。

### Event Redispatch; 事件重分发

将被按键事件钩子拦截的事件按原有优先级顺序重新交回系统分发链路的机制，须在拦截后3秒内发起，且按下与抬起（或取消）事件需保持配对关系。用于钩子处理完毕后不吞掉按键、让事件继续正常派发。

## F

### Final Key; 被修饰键

组合快捷键中除修饰键以外、决定组合含义的那个按键，一个快捷键中仅允许一个，例如Ctrl+Alt+A中的A，系统接口中称最终按键。与修饰键集合共同唯一确定一个快捷键，快捷键订阅中由该按键按下触发回调。

### Fingerprint Gesture; 指纹手势

由侧边指纹器件识别上报的手势类事件，包含按下、抬起、滑动、第二次按下、双触等类型，并携带相对指纹器件长轴/短轴的偏移量。将指纹器件从身份认证部件扩展为一种触控输入通道，区别于用于身份认证的指纹识别。

### Function Key; 功能键

键盘上承担特定状态或功能切换的按键，如CapsLock大小写锁定键。系统支持查询和设置其使能状态以控制该键是否生效，区别于普通字符键。

### Function Key State; 功能键状态

键盘上具有锁定开关语义的功能键（当前支持CapsLock）处于打开还是关闭的状态，可按功能键值直接查询。用于在不依赖按键事件的情况下获知大小写锁定等功能的当前生效情况。

## G

### Gamepad; 游戏手柄

以摇杆、方向键和多个动作按键组合进行操控的游戏输入设备，通常经USB或蓝牙接入。在多屏输入绑定场景中与鼠标、触控板、键盘同属受支持的外接设备。

### Gesture Event; 手势事件

系统对底层触摸或触控板数据完成识别后上报的高层语义事件，直接给出捏合、旋转、多指滑动等手势结果，按开始、更新、结束（或取消）的状态流转上报。应用无需自行计算原始触点轨迹即可响应手势，区别于原始的触摸事件。

### Global Coordinate System; 全局坐标系

以主屏左上角为原点、跨多块屏幕统一取值的坐标系，单位为像素，多屏场景下坐标全局唯一，鼠标事件的全局坐标（globalX/globalY）基于该坐标系表示。基于全局坐标的事件注入用于跨屏精确定位，区别于以指定屏幕左上角为原点的屏幕坐标系。

### Global Shortcut; 全局快捷键

在系统任意界面按下即可生效的按键或组合键，又称热键（Hotkey），不依赖特定焦点窗口，由系统统一管理分发，应用通过全局快捷键接口订阅后即使不在前台也能响应。按定义者分为系统快捷键与应用快捷键，订阅前需避开已被系统或其他应用占用的组合；特殊场景（如工厂模式）下可整体屏蔽所有系统快捷键。

## H

### Hot-plug; 热插拔

输入设备在系统运行期间接入（热插）或移除（热拔）的行为，系统通过热插拔事件实时通知应用，回调以设备ID标识具体设备。应用据此感知外设连接状态变化并动态调整交互方式，设备重新接入后通常需重新查询其设备信息。

### Hover Scroll; 悬停滚动

鼠标悬停（未按键）状态下滚动滚轮即可使内容滚动的行为，可通过系统开关控制启停，默认开启。用于控制滚轮滚动是否需要在悬停时即时生效。

## I

### Infrared Emitter; 红外发射器

设备内置的、可发射特定频率和电平红外信号的硬件模块。用于将设备当作遥控器控制家电等外部设备，使用前可查询设备是否配备以及支持的红外频率范围。

### Infrared Signal Pattern; 红外电平信号

以微秒为单位、高电平与低电平交替的持续时间序列，如[100,200,300,400]表示100μs高电平、200μs低电平、300μs高电平、400μs低电平。与红外频率配合描述待发射的红外波形，用于编码红外遥控指令。

### Injected Event; 注入事件

由软件模拟注入而非真实硬件操作产生的输入事件，可通过事件中的标识区分来源。供监听方识别事件真实性，常用于自动化测试与模拟触控。

### Injection Authorization; 注入授权

用户通过弹窗授予应用执行事件注入的许可，具有未授权、授权中、已授权三种状态，应用可申请、查询并在用毕后主动撤销。供未持有CONTROL_DEVICE权限的应用合法使用事件注入；授权同一时刻互斥，其他应用已获授权时申请失败。

### Input Device; 输入设备

向系统提供输入能力的硬件统称，包括键盘、鼠标、触摸屏、触控板、手写笔、轨迹球、操纵杆、游戏手柄等。每台设备以设备ID、设备类型等属性标识，应用可进行设备信息查询、输入能力获取、热插拔监听等管理操作。

### Input Device Binding; 输入设备绑定

多屏场景下将输入设备与指定屏幕建立固定对应关系的能力：系统接口支持将外接USB和蓝牙的鼠标、触控板、键盘、游戏手柄绑定到显示器组；C接口当前支持手写笔与指定屏幕绑定。绑定后该设备的输入作用于对应屏幕，用于多屏场景下固定输入设备的作用范围。

### Input Device Capabilities; 输入设备能力

输入设备所支持的输入类别信息，例如该设备是触摸屏、触控板还是键盘。用于在使用设备前判断其输入形态并据此适配处理逻辑。

### Input Device Enablement; 输入设备使能

开启或关闭指定输入设备响应能力的状态控制。关闭后设备虽仍接入系统但其输入不再响应（如关闭触摸屏后点击不生效），用于系统按需屏蔽某类输入。

### Input Device ID; 输入设备ID

系统为每个已接入输入设备分配的唯一数字标识，用于查询设备信息、绑定屏幕等操作。该标识对应逻辑设备实例，同一物理设备反复插拔或系统重启后可能变化，不能当作硬件序列号持久使用。

### Input Event; 输入事件

设备上报的基本输入事件，携带事件ID、输入设备ID、上报时间戳、目标屏幕ID与目标窗口ID等公共属性，是按键、鼠标、触摸、轴等各类具体输入事件的公共基类，后者在其基础上扩展各自特有属性。应用可据此定位输入来源与分发目标。

### Input Idle Interval; 输入空闲时长

距离上一次系统输入事件的时间间隔，计算时包含设备休眠时间，单位为微秒。用于息屏、锁屏等基于用户活跃度的空闲判断。

### Input Kit

OpenHarmony面向输入场景的开发套件，聚合输入设备管理、按键/鼠标/触摸/手势等输入事件、键值、鼠标光标管理、全局快捷键、意图事件、红外管理及输入事件注入等能力，ArkTS接口通过@kit.InputKit统一导入，C接口以libohinput.so动态库形式提供，底层能力由多模输入（MultimodalInput）子系统提供。

### Input Monitoring; 输入监听

注册回调以在全局范围内观察系统中触屏、鼠标、触控板手势、按键、指纹等输入事件的能力，仅感知事件而不阻断其正常分发。其中鼠标事件监听仅允许在录屏场景使用，滚轮滚动归入轴事件监听；区别于仅作用于应用自身窗口或组件的UI事件监听。

### Input Service; 输入服务

系统中集中管理输入设备并接收、分发输入事件的系统服务。其运行状态影响输入相关接口的可用性，服务异常或重启可能导致设备ID变化。

### Input Source Type; 输入源类型

按产生输入的设备类别对输入事件来源的分类，包括鼠标、触摸屏、触控板三类。用于区分事件来自何种设备并据此适配交互处理，例如同为多点触控输入时区分触摸屏与触控板。

### Intention Code; 意图编码

将输入设备的原始事件映射为归一化交互意图的编码，例如键盘空格键映射为"选中"意图。应用面向上/下/左/右、返回、翻页、放大/缩小等意图编程，无需关心具体按键与设备差异，一套逻辑可兼容多种输入方式。

## J

### Joystick; 操纵杆

通过杆体在多个轴向上偏转输入方向和幅度信号的指点设备（又称摇杆），常用于游戏操控。作为一类输入源类型被系统识别，其轴信息可用于查询偏转范围。

## K

### Key Auto-repeat; 按键自动重复

按住按键不放时系统连续上报重复按键事件的行为，又称自动重复按键。订阅快捷键时可配置是否上报此类重复事件（如仅首次按下触发或每次重复均触发）；物理键盘侧由按键重复时延与重复速率共同控制其节奏。

### Key Code; 键值

系统为按键设备上每个按键分配的整数编码，又称键码，字母、数字、功能键、多媒体键、游戏手柄按键等均有唯一取值。是构造按键事件、查询按键支持情况、定义与匹配快捷键时指定按键的统一方式，屏蔽了不同设备按键布局的差异，区别于字符编码。

### Key Combination; 组合键

多个按键按约定组合按下的按键输入形式，如Ctrl+C。在快捷键场景由修饰键和被修饰键构成，区别于单个按键直接触发的输入。

### Key Event; 按键事件

按键按下、抬起或取消产生的输入事件，包含键值、事件类型、按下时间以及当前处于按下状态的按键列表等信息。供应用订阅监听并响应用户的按键输入。

### Key Event Hook; 按键事件钩子

在按键事件分发前对其进行拦截的钩子函数，一个进程仅支持设置一个，后添加者优先级更高，拦截后可选择将事件重分发。区别于应用获焦时才生效的按键事件拦截，钩子面向待分发的所有按键事件。

### Key State; 按键状态

指定键值按键当前的状态，包括是否按下以及按键开关是否使能（如大写锁定类按键的开与关）。可按需主动查询，适用于输入事件状态管理等场景，区别于描述某一次按键动作的按键事件。

### Keyboard; 键盘

以按键阵列输入字符与控制指令的输入设备。系统按形态将其分为全键盘、小键盘、手写笔、遥控器等键盘类型，并支持设置按键重复时延与重复速率。

### Keyboard Mouse Crossing; 键鼠穿越

两台或多台设备组网协同后共享一套键盘鼠标、实现键鼠输入跨设备操作的能力，又称键鼠协同、键鼠共享。一套物理键鼠可在组网设备间切换控制目标，以设备描述符指定目标设备，区别于各设备各自搭配输入设备的独立使用方式；对应的系统接口inputDeviceCooperate已停止维护。

### Keyboard Repeat Delay; 按键重复时延

按住按键不放时，从按键按下到系统开始自动重复产生该键值之间的延迟时间，默认500ms，调节范围[300ms, 1000ms]。与重复速率共同决定长按按键时的连续输入节奏。

### Keyboard Repeat Rate; 按键重复速率

长按按键时系统自动重复产生键值的频率，以ms/次为单位，默认50ms/次，取值范围[36, 100]。与重复时延共同控制连续输入的速度。

### Keyboard Type; 键盘类型

对键盘类输入设备形态的分类，包括全键盘、数字键盘、手写笔、遥控器等。用于识别设备的具体键盘形态并适配相应的按键布局与交互。

## L

### Local Input Device; 本地输入设备

直接连接在本机上的输入设备，通过设备信息中的本地标识加以区分。用于判断输入是否来自本机物理连接，区别于跨设备协同等远程输入。

### Lock Key; 锁定键

具有持续使能（锁定）状态的按键，如大写锁定（CapsLock）、数字锁定（NumLock）、滚动锁定（ScrollLock）。鼠标事件中记录的是其使能状态，区别于修饰键的瞬时按下状态。

## M

### Max Touch Points; 触屏报点数

设备触摸屏支持的最大同时报点数量，即多点触控可跟踪的最大触点数，取值范围0~10，-1表示未知。用于判断设备支持几个手指同时触控。

### Media Key; 多媒体键

用于控制媒体播放的按键，如播放/暂停、上一首、下一首、快进、快退。可作为单按键订阅对象被应用消费并屏蔽系统默认行为，区别于普通字符按键。

### Modifier Key; 修饰键

组合键中起修饰作用、改变其他按键含义的按键，包括Ctrl、Shift、Alt等（系统接口中称前置按键），须与被修饰键组合才构成完整快捷键。定义快捷键时可配置1~4个且无顺序要求；鼠标事件中亦记录事件发生时各修饰键是否处于按下状态，用于组合键逻辑判断。

### Mouse; 鼠标

通过移动、按键和滚轮进行指向与操作的输入设备，产生鼠标输入事件。作为独立外设以光标相对移动定位，区别于手指操作触控板的定位方式。

### Mouse Event; 鼠标事件

由鼠标、触控板等设备上报、描述移动、按键按下/抬起、轴变化等操作的输入事件，携带屏幕/窗口/全局坐标、位移偏移、按键、修饰键与锁定键状态等信息。区别于触摸事件和按键事件；鼠标滚轮滚动归入轴事件而非鼠标事件。

### Multi-finger Gesture; 多指手势

三指及以上的手指在触摸屏上协同完成的操作，如三指/四指滑动、三指轻点、多指捏合与张开，系统识别后以手势事件上报，常用于截屏、分屏等系统级功能的触发。区别于单指、双指手势，关键在于多指协同产生的是整体语义而非单点轨迹。

### Multimodal Input; 多模输入

OpenHarmony中统一管理键盘、鼠标、触摸屏、触控板、手写笔等多种输入设备及其事件的子系统（MultimodalInput），以系统服务进程形式运行，将不同设备的操作归一为标准输入事件并分发，负责输入事件的识别分发、输入设备管理，并提供全局快捷键、键鼠穿越、红外管理、输入事件注入等能力。Input Kit的输入能力由其提供。

## N

### Natural Scrolling; 自然滚动

控制滚动方向与操作方向对应关系的滚动行为设置：开启时内容移动方向与手指滑动（或滚轮滚动）方向一致，关闭时相反。触控板与鼠标滚轮可分别配置，默认均为一致，也称滚动方向设置。

## P

### Physical Keyboard; 物理键盘

以实体硬件形式连接的键盘设备。应用常通过查询键盘类型并结合热插拔监听判断物理键盘是否连接，从而在软键盘与实体键盘之间切换输入交互逻辑。

### Pinch; 捏合手势

多指在触摸屏或触控板上相对聚拢或张开以实现缩放的手势（触控板上为2指及以上，触摸屏上支持4~5指），事件以不小于0的捏合度表征缩放程度，触控板侧通过捏合轴上报其变化。用于图片、页面等内容的缩小与放大，区别于携带旋转角度的旋转手势。

### PixelMap; 像素图

以像素阵列描述图像的数据对象，支持图像的创建、读取、修改和渲染等操作。在输入场景中用作自定义鼠标光标的图像资源，尺寸上限为256×256像素，可随光标信息查询返回当前使用的像素图。

### Pointer Speed; 指针速度

指针设备物理位移映射为光标位移的灵敏度系数：鼠标取值范围[1, 20]默认10，触控板取值范围[1, 11]默认6，二者相互独立设置。也称鼠标移动速度、光标移动速度。

### Pointer Style; 光标样式

系统预置的鼠标光标呈现形态枚举，涵盖箭头、手形指针、文本选择、十字、移动、缩放、截图等，按窗口设置或获取，用于向用户提示当前操作语义（如可调整大小、可输入文本）。区别于使用自有像素图的自定义光标；与大小档位、颜色、显示状态共同构成光标信息。

### Primary Button; 鼠标主键

承担主要点击功能的鼠标按键，可配置为左键或右键，用于适配不同用手习惯（如左撇子将右键设为主键）。配置后系统相应交换左右键的功能语义。

## R

### Remote Control; 遥控器

以无线方式远距离操控设备的输入设备，通常仅含数字键与少量功能键。系统中归为键盘类型设备加以识别，区别于近场使用的标准键盘。

### Render Service; 渲染服务

负责窗口图形合成与上屏的系统服务进程。鼠标光标的最终绘制由渲染服务完成，因此输入模块设置的光标显示/隐藏状态并非其实际显示效果的充分条件。

### Right Click Type; 右键触发方式

触控板上触发右键菜单的交互方式，可选按压右键区域、按压左键区域、双指轻击或双指按压，以及它们的组合，默认为双指轻击/按压或按压右键区域。区别于鼠标通过物理右键触发右键菜单。

### Rotation Gesture; 旋转手势

两指及以上绕接触区域中心转动的手势，事件携带以度为单位的旋转角度，用于旋转图片、地图等可旋转内容。区别于表达缩放语义的捏合手势，二者常同时发生但语义不同。

## S

### Scroll Axis; 滚动轴

鼠标滚轮或触控板滚动对应的输入轴，分为垂直滚动轴和水平滚动轴，轴值表示滚动量的大小。滚动行为通过轴事件上报。

### Scroll Rows; 滚动行数

鼠标滚轮每滚动一次对应的内容滚动行数，取值范围1-100，默认3行。用于调节滚轮单次滚动的幅度。

### Single-hand Mode; 单手模式

大屏设备单手握持时，为让拇指触及对侧屏幕区域而对触控坐标进行修正映射的模式。触屏事件携带坐标修正值，系统据此把实际触控位置换算回用户期望的目标位置，区别于不做坐标修正的正常模式。

### Stylus; 手写笔

以笔尖在触摸屏上书写和精确操作的输入设备，可上报压力、倾斜角、接触区域等信息。系统中作为一种键盘类型被识别，区别于手指触摸。

### Swipe; 多指滑动

多个手指同时在触控板表面滑动的手势，用于触发翻页、切换等快捷操作。可通过系统开关启停，默认开启。

### Swipe Inward; 向内滑动

自屏幕边缘向屏幕内部方向的滑动手势，事件携带触发点坐标，常用于唤出侧边栏等边缘交互。区别于发生在屏幕内容区的普通滑动手势，其起始位置在屏幕边缘。

### System API; 系统接口

仅系统应用可调用、不对普通三方应用开放的接口，文档中以"系统接口"标注，非系统应用调用会返回202错误。区别于所有应用均可使用的公开接口。

### System Capability (SysCap); 系统能力

OpenHarmony用于标识设备是否支持某项能力集合的机制，接口以SystemCapability.MultimodalInput.Input.Core等形式声明所依赖的输入能力，供系统能力集裁剪与设备兼容性判断使用。

### System Preset Shortcut; 系统预置快捷键

系统预先定义、按下后直接拉起对应Ability的全局快捷键。系统应用可设置其拉起Ability的延迟时间（如长按3秒后再截屏），且仅支持按下触发，区别于应用按自身需求申请的自定义全局快捷键。

## T

### Tap; 轻触

手指轻触触控板表面即产生点击效果的手势，无需物理按压触控板。可通过系统开关启停，默认开启。

### Tilt; 倾斜角

手写笔等触控工具相对参考平面的倾斜程度，tiltX、tiltY分别表示相对YZ平面和XZ平面的角度，取值范围[-90, 90]，正值分别表示向右、向下倾斜。用于还原笔尖姿态以实现更精细的书写与绘制效果。

### Tool Type; 工具类型

对产生触屏事件的接触工具的分类，包括手指、手写笔、橡皮擦、画笔、铅笔、喷枪、鼠标、透镜等，未设置时默认为手指。用于书写绘制类场景区分手指与各类笔型输入并做相应适配。

### Touch Area; 触摸区域

手指或触控工具与触摸屏接触面的近似椭圆区域，以长轴、短轴刻画其大小；工具区域特指触控工具（如笔尖）形成的接触区域。用于精细笔迹绘制与手掌误触抑制等场景。

### Touch Event; 触摸事件

手指、手写笔等工具在触摸屏上按下、移动、抬起、取消产生的输入事件（又称触屏事件、触控事件），以触点为基本单元，可携带触点压力、工具类型、接触区域等属性；交互序列被异常打断（如按下后屏幕旋转、折叠）时以取消事件收尾。区别于鼠标事件。

### Touch Point; 触点

手指、手写笔等工具与触摸屏接触产生的一个接触点，包含触点ID（多点触控中从0起依次累加）、屏幕与窗口坐标、压力值、接触区域宽高、笔尖倾斜角及工具类型等信息。多点触控时每个手指对应一个独立触点，是构成触摸事件的基本单元。

### Touchpad; 触控板

通过手指在其表面触摸滑动来控制指针并执行手势输入的指点设备，也称触摸板，本身不显示内容。系统为其提供滚动、轻触、双指捏合、多指滑动、双击拖拽、右键触发方式等手势功能的开关与参数配置，区别于兼具显示功能的触摸屏。

### Touchscreen; 触摸屏

兼具显示与触摸输入能力的屏幕，手指或触控笔直接在屏幕上操作。作为一类输入源类型被系统识别，区别于外接的独立输入面板触控板。

### Trackball; 轨迹球

通过滚动球体控制光标移动的指点输入设备，无需移动设备本体即可完成指向操作。作为一类输入源类型被系统识别，常见于早期移动设备。

## V

### Virtual Input Device; 虚拟输入设备

由软件模拟而非物理硬件实现的输入设备，通过设备信息中的虚拟标识加以区分。常用于测试、远程注入或特殊输入场景。
