## A

### Air Mouse Mode; 空鼠模式

手写笔的隔空操作模式：通过在空中转动手写笔控制屏幕上虚拟光标的移动，并借助笔身按键实现上下翻页，适用于演示PPT、隔空操作等场景。进入该模式后系统自动使用悬浮光标、点击光标或激光笔光标，应用无法通过常规光标样式接口直接设置，区别于手写笔在屏幕上书写的常规触控输入。

### 按键前置监听

在按键事件进入常规分发流程之前对其进行监听拦截的机制，目前仅支持左/右Meta键、电源键和音量键，仅系统应用可用。用于系统层优先响应特定系统功能键，区别于普通的按键事件监听。

### Application Hotkey; 应用快捷键

由应用自定义并注册的全局快捷键，在应用运行期间响应对应的组合按键输入。区别于系统快捷键：若与系统或其他应用已注册的快捷键冲突，订阅时会返回错误码。

### Axis; 轴

输入设备上报的连续数值维度，如横坐标轴（x）、纵坐标轴（y）、压力轴、方向轴等，每根轴具有最大值、最小值、分辨率等范围属性。用于刻画触摸屏、触控板、操纵杆等设备的连续输入状态，区别于按键这类离散输入信号。

### Axis Action; 轴事件动作

轴事件在交互过程中的生命周期状态，分为取消、开始、更新和结束四类。应用据此区分一个连续手势（如滚动、捏合）当前所处阶段并作出相应处理。

### Axis Event; 轴事件

由鼠标滚轮滚动、触控板手势、游戏手柄摇杆移动等轴类连续输入产生的事件，以轴类型（垂直/水平滚动轴、捏合轴、旋转轴）和轴值描述输入量，一个有效序列由开始事件、零次或多次更新事件、结束（或取消）事件按序构成，且同一时间只允许一个进行中的序列。区别于按键等离散事件，常用于页面滚动、缩放等连续交互。

### Axis Event Type; 轴事件类型

按手势来源对轴事件所做的分类，分为捏合事件（含捏合轴和旋转轴两种轴类型）和滚轴事件（含垂直、水平两种滚动轴，其中鼠标滚轮事件仅含垂直滚动轴）。应用据此区分轴事件承载的手势语义。

### Axis Type; 轴类型

输入设备在不同交互场景下物理行为特征的分类定义，包括垂直滚动轴、水平滚动轴、捏合轴和旋转轴。系统通过轴类型区分和传递不同的手势交互信息。

## C

### Cursor; 光标

屏幕上跟随鼠标、触控板等指针设备移动的图形指示器，标示当前指向位置及操作语义，也称鼠标光标、鼠标指针。系统提供显示/隐藏、样式、大小、颜色、移动速度等管理能力。

## D

### Display Coordinate System; 屏幕坐标系

以指定屏幕左上角为原点的相对坐标系，单位为像素，用于表示鼠标、触屏、轴等输入事件在屏幕上的位置。区别于以主屏左上角为原点、坐标跨屏统一的全局坐标系，多屏场景下两者的坐标值不同。

## E

### Event Injection; 事件注入

以编程方式构造按键、鼠标、触屏、轴等输入事件并送入系统输入通道、模拟真实用户输入的能力，主要用于自动化测试等场景。注入须遵循事件状态约束（按键先按下后抬起、轴事件序列先开始后更新再结束、同一触点不能重复按下等），并受权限管控：系统侧需ohos.permission.INJECT_INPUT_EVENT，开放侧需ohos.permission.CONTROL_DEVICE权限或先获得用户注入授权，注入产生的触屏事件会被标记为注入事件。

### Event Interception; 输入事件拦截

应用在系统分发输入事件前截获并自行处理的机制，支持按键、鼠标、触屏和轴事件。按键事件拦截仅在应用获焦时生效，鼠标、触屏和轴事件拦截仅在命中应用窗口时生效，同一应用重复添加仅首次生效；区别于只观察不阻断的事件监听。

### Event Redispatch; 事件重分发

将被按键事件钩子拦截的事件按原有优先级顺序重新交回系统分发链路的机制，须在拦截后3秒内发起，且按下与抬起（或取消）事件需保持配对关系。用于钩子处理完毕后不吞掉按键、让事件继续正常派发。

## F

### Final Key; 被修饰键

组合快捷键中除修饰键以外、决定组合含义的那个按键，一个快捷键中仅允许一个，例如Ctrl+Alt+A中的A，系统接口中称最终按键。与修饰键集合共同唯一确定一个快捷键，快捷键订阅中由该按键按下触发回调。

### Fingerprint Gesture; 指纹手势

由侧边指纹器件识别上报的手势类事件，包含按下、抬起、滑动、第二次按下、双触等类型，并携带相对指纹器件长轴/短轴的偏移量。将指纹器件从身份认证部件扩展为一种触控输入通道，区别于用于身份认证的指纹识别。

### Function Key; 功能键

键盘上承担特定状态或功能切换的按键，如CapsLock大小写锁定键。系统支持查询和设置其使能状态以控制该键是否生效，区别于普通字符键。

### Function Key State; 功能键状态

键盘上具有锁定开关语义的功能键（当前支持CapsLock）处于打开还是关闭的状态，可按功能键值直接查询。用于在不依赖按键事件的情况下获知大小写锁定等功能的当前生效情况。

## G

### Gesture Event; 手势事件

系统对底层触摸或触控板数据完成识别后上报的高层语义事件，直接给出捏合、旋转、多指滑动等手势结果，按开始、更新、结束（或取消）的状态流转上报。应用无需自行计算原始触点轨迹即可响应手势，区别于原始的触摸事件。

### Global Coordinate System; 全局坐标系

以主屏左上角为原点、跨多块屏幕统一取值的坐标系，单位为像素，多屏场景下坐标全局唯一，鼠标事件的全局坐标（globalX/globalY）基于该坐标系表示。基于全局坐标的事件注入用于跨屏精确定位，区别于以指定屏幕左上角为原点的屏幕坐标系。

### Global Shortcut; 全局快捷键

在系统任意界面按下即可生效的按键或组合键，又称热键（Hotkey），不依赖特定焦点窗口，由系统统一管理分发，应用通过全局快捷键接口订阅后即使不在前台也能响应。按定义者分为系统快捷键与应用快捷键，订阅前需避开已被系统或其他应用占用的组合；特殊场景（如工厂模式）下可整体屏蔽所有系统快捷键。

## H

### Hover Scroll; 悬停滚动

鼠标悬停（未按键）状态下滚动滚轮即可使内容滚动的行为，可通过系统开关控制启停，默认开启。用于控制滚轮滚动是否需要在悬停时即时生效。

## I

### Infrared Emitter; 红外发射器

设备内置的、可发射特定频率和电平红外信号的硬件模块。用于将设备当作遥控器控制家电等外部设备，使用前可查询设备是否配备以及支持的红外频率范围。

### Infrared Signal Pattern; 红外电平信号

以微秒为单位、高电平与低电平交替的持续时间序列，如[100,200,300,400]表示100μs高电平、200μs低电平、300μs高电平、400μs低电平。与红外频率配合描述待发射的红外波形，用于编码红外遥控指令。

### Injected Event; 注入事件

由软件模拟注入而非真实硬件操作产生的输入事件，可通过事件中的标识区分来源。供监听方识别事件真实性，常用于自动化测试与模拟触控。

### Injection Authorization; 注入授权

用户通过弹窗授予应用执行事件注入的许可，具有未授权、授权中、已授权三种状态，应用可申请、查询并在用毕后主动撤销。供未持有CONTROL_DEVICE权限的应用合法使用事件注入；授权同一时刻互斥，其他应用已获授权时申请失败。

## M

### Modifier Key; 修饰键

组合键中起修饰作用、改变其他按键含义的按键，包括Ctrl、Shift、Alt等（系统接口中称前置按键），须与被修饰键组合才构成完整快捷键。定义快捷键时可配置1~4个且无顺序要求；鼠标事件中亦记录事件发生时各修饰键是否处于按下状态，用于组合键逻辑判断。
