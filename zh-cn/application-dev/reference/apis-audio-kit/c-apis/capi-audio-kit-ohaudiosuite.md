# OHAudioSuite

## 概述

提供音频编创相关C接口定义，包含多种专业级音频效果处理功能，服务于音频编辑和创作类应用场景。

**系统能力：** SystemCapability.Multimedia.Audio.SuiteEngine

**起始版本：** 22
