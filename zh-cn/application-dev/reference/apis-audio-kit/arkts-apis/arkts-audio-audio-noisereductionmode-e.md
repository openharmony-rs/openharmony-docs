# NoiseReductionMode

表示录音降噪模式的枚举。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Multimedia.Audio.Core

## FIDELITY

```TypeScript
FIDELITY = 0
```

保真模式，不进行降噪。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.Audio.Core

## PURE_VOCALS

```TypeScript
PURE_VOCALS = 1
```

纯人声模式，强降噪。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.Audio.Core

## STANDARD

```TypeScript
STANDARD = 2
```

标准模式，弱降噪。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Multimedia.Audio.Core
