# AudioDevcieSelectStrategy（系统接口）

表示设备选择策略的枚举。

**起始版本：** 21

**系统能力：** SystemCapability.Multimedia.Audio.Device

**系统接口：** 此接口为系统接口。

## SELECT_STRATEGY_DEFAULT

```TypeScript
SELECT_STRATEGY_DEFAULT = 0
```

默认设备选择策略。

**起始版本：** 21

**系统能力：** SystemCapability.Multimedia.Audio.Device

**系统接口：** 此接口为系统接口。

## SELECT_STRATEGY_INDEPENDENT

```TypeScript
SELECT_STRATEGY_INDEPENDENT = 1
```

独立设备选择策略。

**起始版本：** 21

**系统能力：** SystemCapability.Multimedia.Audio.Device

**系统接口：** 此接口为系统接口。
