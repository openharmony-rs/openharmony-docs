# ContentType

表示音频内容类型的枚举。

> **说明：**
> 
> 从API version 7开始支持，从API version 10开始废弃，建议使用[StreamUsage](arkts-audio-audio-streamusage-e.md)替代。

**起始版本：** 7

**废弃版本：** 10

**替代接口：** [StreamUsage](arkts-audio-audio-streamusage-e.md)

**系统能力：** SystemCapability.Multimedia.Audio.Core

## CONTENT_TYPE_UNKNOWN

```TypeScript
CONTENT_TYPE_UNKNOWN = 0
```

未知类型。

**起始版本：** 7

**废弃版本：** 10

**替代接口：** [STREAM_USAGE_UNKNOWN](arkts-audio-audio-streamusage-e.md#stream_usage_unknown)

**系统能力：** SystemCapability.Multimedia.Audio.Core
