# SystemVolumeFilter（系统接口）

描述系统音量过滤器。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.Multimedia.Audio.Volume

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { audio } from '@kit.AudioKit';
```

## uid

```TypeScript
uid: number
```

应用程序的UID。

**类型：** number

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。
