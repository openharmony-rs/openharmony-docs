# AsrVoiceMuteMode（系统接口）

枚举，自动语音识别（ASR）的静音模式。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。

## OUTPUT_MUTE

```TypeScript
OUTPUT_MUTE = 0
```

本地输出静音。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。

## INPUT_MUTE

```TypeScript
INPUT_MUTE = 1
```

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。
