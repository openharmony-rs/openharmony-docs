# VolumeFlag（系统接口）

Enumerates volume related operations. Flags should be powers of 2!

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## FLAG_SHOW_SYSTEM_UI

```TypeScript
FLAG_SHOW_SYSTEM_UI = 1
```

Show system volume bar.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
