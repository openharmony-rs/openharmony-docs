# InterruptActionType

表示中断事件返回类型的枚举。

> **说明：**
> 
> 从API version 7开始支持，从API version 9开始废弃，建议使用[InterruptType](arkts-audio-audio-interrupttype-e.md)替代。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [InterruptType](arkts-audio-audio-interrupttype-e.md)

**系统能力：** SystemCapability.Multimedia.Audio.Renderer

## TYPE_ACTIVATED

```TypeScript
TYPE_ACTIVATED = 0
```

表示触发焦点事件。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [INTERRUPT_TYPE_BEGIN](arkts-audio-audio-interrupttype-e.md#interrupt_type_begin)

**系统能力：** SystemCapability.Multimedia.Audio.Renderer

## TYPE_INTERRUPT

```TypeScript
TYPE_INTERRUPT = 1
```

表示音频打断事件。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [INTERRUPT_TYPE_END](arkts-audio-audio-interrupttype-e.md#interrupt_type_end)

**系统能力：** SystemCapability.Multimedia.Audio.Renderer
