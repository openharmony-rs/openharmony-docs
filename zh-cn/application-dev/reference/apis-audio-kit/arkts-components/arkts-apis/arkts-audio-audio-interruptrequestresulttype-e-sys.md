# InterruptRequestResultType（系统接口）

枚举，音频中断请求结果类型。

**起始版本：** 9

**系统能力：** SystemCapability.Multimedia.Audio.Interrupt

**系统接口：** 此接口为系统接口。

## INTERRUPT_REQUEST_GRANT

```TypeScript
INTERRUPT_REQUEST_GRANT = 0
```

请求音频中断成功。

**起始版本：** 9

**系统能力：** SystemCapability.Multimedia.Audio.Interrupt

**系统接口：** 此接口为系统接口。

## INTERRUPT_REQUEST_REJECT

```TypeScript
INTERRUPT_REQUEST_REJECT = 1
```

请求音频中断失败，可能具有较高优先级类型。

**起始版本：** 9

**系统能力：** SystemCapability.Multimedia.Audio.Interrupt

**系统接口：** 此接口为系统接口。
