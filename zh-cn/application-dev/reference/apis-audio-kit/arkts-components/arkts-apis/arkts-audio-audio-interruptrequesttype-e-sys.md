# InterruptRequestType（系统接口）

枚举，音频中断请求类型。

**起始版本：** 9

**系统能力：** SystemCapability.Multimedia.Audio.Interrupt

**系统接口：** 此接口为系统接口。

## INTERRUPT_REQUEST_TYPE_DEFAULT

```TypeScript
INTERRUPT_REQUEST_TYPE_DEFAULT = 0
```

默认类型，可中断音频请求。

**起始版本：** 9

**系统能力：** SystemCapability.Multimedia.Audio.Interrupt

**系统接口：** 此接口为系统接口。
