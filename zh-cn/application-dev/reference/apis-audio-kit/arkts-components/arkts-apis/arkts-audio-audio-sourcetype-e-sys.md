枚举，音源类型。

**起始版本：** 8

**系统能力：** SystemCapability.Multimedia.Audio.Core

## SOURCE_TYPE_WAKEUP

```TypeScript
SOURCE_TYPE_WAKEUP = 3
```

**系统接口：** 此接口为系统接口。
