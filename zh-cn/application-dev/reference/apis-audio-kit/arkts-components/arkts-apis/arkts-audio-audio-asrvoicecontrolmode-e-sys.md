# AsrVoiceControlMode（系统接口）

枚举，自动语音识别（ASR）的音频通路模式。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。

## AUDIO_2_VOICE_TX

```TypeScript
AUDIO_2_VOICE_TX = 0
```

仅媒体音频流生效。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。

## AUDIO_MIX_2_VOICE_TX

```TypeScript
AUDIO_MIX_2_VOICE_TX = 1
```

媒体音频流和MIC音频流均生效。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。

## AUDIO_2_VOICE_TX_EX

```TypeScript
AUDIO_2_VOICE_TX_EX = 2
```

仅媒体音频流生效，将媒体流上报给通话录音。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。

## AUDIO_MIX_2_VOICE_TX_EX

```TypeScript
AUDIO_MIX_2_VOICE_TX_EX = 3
```

媒体音频流和MIC音频流均生效，将媒体流上报给通话录音。

**起始版本：** 12

**系统能力：** SystemCapability.Multimedia.Audio.Capturer

**系统接口：** 此接口为系统接口。
