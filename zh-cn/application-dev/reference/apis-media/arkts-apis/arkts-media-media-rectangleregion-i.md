# RectangleRegion

```TypeScript
interface RectangleRegion
```

矩形区域的配置接口。矩形区域的位置从左上角开始，大小定义为矩形的长宽数据。

**起始版本：** 26.1.0

## height

```TypeScript
height: number
```

矩形区域的高度。单位为：像素。取值应为正整数。

**类型：** number

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。
