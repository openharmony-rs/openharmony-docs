# OnProxyConfigChangeCallback

```TypeScript
type OnProxyConfigChangeCallback = () => void
```

回调函数，在代理配置发生改变时被调用，回调成功表示代理设置成功。

**起始版本：** 15

**原子化服务API：** 从API版本19开始，该接口支持在原子化服务API中使用。
