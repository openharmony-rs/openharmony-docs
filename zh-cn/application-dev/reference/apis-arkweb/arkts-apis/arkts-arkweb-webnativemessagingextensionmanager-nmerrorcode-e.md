# NmErrorCode

Native Messaging的错误列表。

**起始版本：** 21

**系统能力：** SystemCapability.Web.Webview.Core

## PERMISSION_DENY

```TypeScript
PERMISSION_DENY = 17100203
```

由于缺少 ohos.permission.WEB_NATIVE_MESSAGING，权限被拒绝。

**起始版本：** 21

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Web.Webview.Core

## WANT_CONTENT_ERROR

```TypeScript
WANT_CONTENT_ERROR = 17100202
```

所需内容无效。

**起始版本：** 21

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Web.Webview.Core

## INNER_ERROR

```TypeScript
INNER_ERROR = 17100201
```

原生消息的内部错误。

**起始版本：** 21

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Web.Webview.Core
