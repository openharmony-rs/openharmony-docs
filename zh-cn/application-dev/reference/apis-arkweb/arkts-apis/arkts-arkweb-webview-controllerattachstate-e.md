# ControllerAttachState

WebviewController与Web组件的绑定状态。

**起始版本：** 20

**系统能力：** SystemCapability.Web.Webview.Core

## UNATTACHED

```TypeScript
UNATTACHED = 0
```

未绑定状态。

**起始版本：** 20

**系统能力：** SystemCapability.Web.Webview.Core

## ATTACHED

```TypeScript
ATTACHED = 1
```

已绑定状态。

**起始版本：** 20

**系统能力：** SystemCapability.Web.Webview.Core
