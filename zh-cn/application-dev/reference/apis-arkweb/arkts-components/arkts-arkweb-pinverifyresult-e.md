# PinVerifyResult

PIN码认证结果，用于标识PIN码验证的执行状态。

**起始版本：** 22

**系统能力：** SystemCapability.Web.Webview.Core

## PIN_VERIFICATION_SUCCESS

```TypeScript
PIN_VERIFICATION_SUCCESS = 0
```

成功。

**起始版本：** 22

**系统能力：** SystemCapability.Web.Webview.Core

## PIN_VERIFICATION_FAILED

```TypeScript
PIN_VERIFICATION_FAILED = 1
```

失败。

**起始版本：** 22

**系统能力：** SystemCapability.Web.Webview.Core
