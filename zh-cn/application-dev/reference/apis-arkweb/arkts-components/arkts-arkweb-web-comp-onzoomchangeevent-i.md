# OnZoomChangeEvent

```TypeScript
declare interface OnZoomChangeEvent
```

描述网页浏览器级缩放倍率变化的信息。

**起始版本：** 26.2.0

**系统能力：** SystemCapability.Web.Webview.Core

## newZoomFactor

```TypeScript
newZoomFactor: number
```

变化后的浏览器级缩放倍率。

**类型：** number

**起始版本：** 26.2.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Web.Webview.Core

## oldZoomFactor

```TypeScript
oldZoomFactor: number
```

变化前的浏览器级缩放倍率。

**类型：** number

**起始版本：** 26.2.0

**模型约束：** 此接口仅可在Stage模型下使用。
