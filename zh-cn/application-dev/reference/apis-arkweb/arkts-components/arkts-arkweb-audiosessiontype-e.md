# AudioSessionType

应用中 Web 音频类型，用于控制 Web 音频的音频流类型和行为，帮助开发者根据应用场景优化音频体验，如支持网页游戏声音与系统音乐同时播放。

**起始版本：** 20

**系统能力：** SystemCapability.Web.Webview.Core

## AMBIENT

```TypeScript
AMBIENT = 3
```

适用于网页游戏场景，支持Web游戏声音与系统音乐同时播放。对应系统音频流类型STREAM_USAGE_GAME。

**起始版本：** 20

**系统能力：** SystemCapability.Web.Webview.Core
