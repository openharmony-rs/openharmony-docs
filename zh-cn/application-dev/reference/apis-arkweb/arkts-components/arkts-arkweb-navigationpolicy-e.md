# NavigationPolicy

WebView中新窗口的打开方式，支持弹窗、新窗口、前台和后台标签页等多种方式。

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core

## NEW_POPUP

```TypeScript
NEW_POPUP = 0
```

在新弹窗中打开。

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core

## NEW_WINDOW

```TypeScript
NEW_WINDOW = 1
```

在新窗口中打开。

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core

## NEW_BACKGROUND_TAB

```TypeScript
NEW_BACKGROUND_TAB = 2
```

在新标签页中以后台方式打开。

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core

## NEW_FOREGROUND_TAB

```TypeScript
NEW_FOREGROUND_TAB = 3
```

在新标签页中以前台方式打开。

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core
