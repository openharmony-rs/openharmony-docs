# CameraCaptureStateChangeInfo

提供摄像头触发回调时的状态变化信息，包括改变前的状态和新状态。适用于需要监控摄像头状态变化的场景，提升摄像头管理的可见性和用户体验。

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core

