# OnInterceptRequestEvent

定义Web组件加载URL之前触发的回调信息，包括请求详情。适用于需要拦截或修改网络请求的场景，提升请求控制的灵活性和安全性。

**起始版本：** 12

**系统能力：** SystemCapability.Web.Webview.Core
