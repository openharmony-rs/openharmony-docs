# AcceptableFileType

提供文件选择器推荐的文件类型信息，包括MIME类型和类型数组。

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core

## 导入模块

```TypeScript
```

## acceptableType

```TypeScript
acceptableType: Array<string>
```

文件类型数组，包含若干可供选择的文件类型。

**类型：** Array&lt;string&gt;

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core

## mimeType

```TypeScript
mimeType: string
```

文件MIME类型。

**类型：** string

**起始版本：** 23

**系统能力：** SystemCapability.Web.Webview.Core
