# WebviewController

```TypeScript
declare type WebviewController = import('../api/@ohos.web.webview').default.WebviewController
```

提供Web控制器的方法。通过WebviewController可以控制Web组件各种行为。一个WebviewController对象只能控制一个Web组件，且必须在Web组件和WebviewController绑定后，才能调用WebviewController上的方法（静态方法除外）。

**类型：** import('../api/@ohos.web.webview').default.WebviewController

**起始版本：** 9

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。
