## clearDnsCache

```TypeScript
function clearDnsCache(netId: number): void
```

清除指定网络的DNS缓存。使用异步回调返回结果。

**起始版本：** 26.1.0

**需要权限：** ohos.permission.ENTERPRISE_MANAGE_NETWORK

**模型约束：** 此接口仅可在Stage模型下使用。
