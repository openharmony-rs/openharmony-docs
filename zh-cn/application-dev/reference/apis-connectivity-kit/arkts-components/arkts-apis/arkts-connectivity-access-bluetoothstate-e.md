# BluetoothState

枚举，蓝牙开关状态。

**起始版本：** 10

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## STATE_OFF

```TypeScript
STATE_OFF = 0
```

表示蓝牙已关闭。

**起始版本：** 10

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core
