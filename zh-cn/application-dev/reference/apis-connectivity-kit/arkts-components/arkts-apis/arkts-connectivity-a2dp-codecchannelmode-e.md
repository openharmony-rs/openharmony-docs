# CodecChannelMode

枚举，蓝牙媒体音频编解码器的声道模式，表示音频播放时独立的空间信号路径数量。声道模式影响声音的立体感和空间定位‌。

**起始版本：** 11

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CODEC_CHANNEL_MODE_NONE

```TypeScript
CODEC_CHANNEL_MODE_NONE = 0
```

声道未知。

**起始版本：** 11

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CODEC_CHANNEL_MODE_MONO

```TypeScript
CODEC_CHANNEL_MODE_MONO = 1
```

单声道。

**起始版本：** 11

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CODEC_CHANNEL_MODE_STEREO

CODEC_CHANNEL_MODE_STEREO = 2
