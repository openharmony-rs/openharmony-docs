# BluetoothTransport

```TypeScript
type BluetoothTransport = connection.BluetoothTransport
```

表示远端设备的传输类型。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API（仅ArkTS-Dyn）：** 从API版本26.0.0开始，该接口支持在原子化服务中使用。
