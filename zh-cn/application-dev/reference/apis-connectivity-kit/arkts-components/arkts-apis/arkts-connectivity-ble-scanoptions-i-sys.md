# ScanOptions

BLE扫描的配置参数。

**起始版本：** 10

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## 导入模块

```TypeScript
import { ble } from '@kit.ConnectivityKit';
```

## scanEnhanceMode

```TypeScript
scanEnhanceMode?: ScanEnhanceMode
```

配置扫描增强模式。

**类型：** [ScanEnhanceMode](arkts-connectivity-ble-scanenhancemode-i-sys.md)

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。
