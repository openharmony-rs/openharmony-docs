# CodecFrameLength

枚举，蓝牙媒体音频编解码器的帧长，表示一帧音频数据播放的时长，单位为ms。帧长影响音频传输的延迟和效率。

**起始版本：** 19

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CODEC_FRAME_LENGTH_5MS

```TypeScript
CODEC_FRAME_LENGTH_5MS = 0
```

5ms帧长。

**起始版本：** 19

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CODEC_FRAME_LENGTH_10MS

```TypeScript
CODEC_FRAME_LENGTH_10MS = 1
```

10ms帧长。

**起始版本：** 19

**系统能力：** SystemCapability.Communication.Bluetooth.Core
