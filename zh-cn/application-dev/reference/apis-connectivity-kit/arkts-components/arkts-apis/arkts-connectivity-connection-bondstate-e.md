# BondState

枚举，配对状态。

**起始版本：** 10

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## BOND_STATE_INVALID

```TypeScript
BOND_STATE_INVALID = 0
```

未配对状态。

**起始版本：** 10

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core
