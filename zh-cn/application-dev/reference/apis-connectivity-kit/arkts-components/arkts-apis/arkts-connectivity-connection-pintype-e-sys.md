# PinType（系统接口）

枚举，蓝牙配对类型。

**起始版本：** 10

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。

## PIN_TYPE_ENTER_PIN_CODE

```TypeScript
PIN_TYPE_ENTER_PIN_CODE = 0
```

用户需要输入对端设备上显示的PIN码。&lt;br/

**起始版本：** 10

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。
