# WifiCategory

表示热点支持的最高Wi-Fi类别。可以用于识别和区分不同Wi-Fi技术标准的热点。

**起始版本：** 12

**系统能力：** SystemCapability.Communication.WiFi.STA

## DEFAULT

```TypeScript
DEFAULT = 1
```

Default。Wifi6以下的wifi类别。

**起始版本：** 12

**系统能力：** SystemCapability.Communication.WiFi.STA
