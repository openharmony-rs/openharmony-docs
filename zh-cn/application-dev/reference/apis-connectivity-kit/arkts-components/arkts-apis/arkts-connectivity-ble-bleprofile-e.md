# BleProfile

枚举，指定当前设备的Profile协议类型。

**起始版本：** 21

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## GATT

```TypeScript
GATT = 1
```

当前设备在GATT链路中同时作为client端和server端。

**起始版本：** 21

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## GATT_CLIENT

```TypeScript
GATT_CLIENT = 2
```

当前设备在GATT链路中作为client端。

**起始版本：** 21

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## GATT_SERVER

```TypeScript
GATT_SERVER = 3
```

当前设备在GATT链路中作为server端。

**起始版本：** 21

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core
