# P2pConnectState

```TypeScript
enum P2pConnectState
```

表示P2P连接状态的枚举。

> **说明：** 
> 
> 从API version 8开始支持，从API version 9开始废弃。

**废弃版本：** 9

**替代接口：** [P2pConnectState](arkts-connectivity-wifimanager-p2pconnectstate-e.md)

**系统能力：** SystemCapability.Communication.WiFi.P2P
