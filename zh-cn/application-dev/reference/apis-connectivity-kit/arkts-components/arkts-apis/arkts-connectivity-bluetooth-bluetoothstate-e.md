# BluetoothState

枚举，蓝牙开关状态。

从API version 7开始支持，从API version 9开始废弃。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [BluetoothState](arkts-connectivity-bluetoothmanager-bluetoothstate-e.md)

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## STATE_OFF

```TypeScript
STATE_OFF = 0
```

表示蓝牙已关闭。

**起始版本：** 7

**废弃版本：** 9

**替代接口：** [STATE_OFF](arkts-connectivity-bluetoothmanager-bluetoothstate-e.md#state_off)

**系统能力：** SystemCapability.Communication.Bluetooth.Core
