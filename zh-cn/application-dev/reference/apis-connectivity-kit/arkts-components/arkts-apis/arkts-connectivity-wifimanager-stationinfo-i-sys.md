# StationInfo（系统接口）

接入的设备信息。包含连接到Wi-Fi网络的设备详细信息。

**起始版本：** 9

**系统能力：** SystemCapability.Communication.WiFi.AP.Core

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { wifiManager } from '@kit.ConnectivityKit';
```
