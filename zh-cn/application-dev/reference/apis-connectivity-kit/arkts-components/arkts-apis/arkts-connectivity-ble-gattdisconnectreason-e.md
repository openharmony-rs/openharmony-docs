# GattDisconnectReason

枚举，指定GATT链路断开的原因。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CONN_TIMEOUT

```TypeScript
CONN_TIMEOUT = 1
```

连接超时。

**起始版本：** 20

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core
