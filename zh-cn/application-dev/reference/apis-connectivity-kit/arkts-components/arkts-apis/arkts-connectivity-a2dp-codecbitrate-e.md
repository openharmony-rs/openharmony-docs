# CodecBitRate

枚举，蓝牙媒体音频编解码器的码率，表示单位时间内音频数据的传输量，单位为kbps。码率影响音频音质和传输带宽。

**起始版本：** 19

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CODEC_BIT_RATE_96000

```TypeScript
CODEC_BIT_RATE_96000 = 0
```

96kbps

**起始版本：** 19

**系统能力：** SystemCapability.Communication.Bluetooth.Core
