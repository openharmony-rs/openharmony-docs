# BluetoothRawAddressType

枚举，蓝牙协议定义的蓝牙设备地址类型。关于地址类型的详细介绍请参见蓝牙设备地址类型。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## PUBLIC

```TypeScript
PUBLIC = 0
```

公共设备地址类型，该类型地址由IEEE组织分配并保证全球唯一性，永久不变。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## RANDOM

```TypeScript
RANDOM = 1
```

随机设备地址类型，该类型地址随机生成，包括静态随机地址和私有随机地址等子类型，可能定期变化。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.Bluetooth.Core
