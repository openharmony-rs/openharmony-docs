# ReportType

枚举，报告类型。

**起始版本：** 23

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## REPORT_TYPE_INPUT

```TypeScript
REPORT_TYPE_INPUT = 1
```

输入报告，表示由本端向HID主机发送的数据。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## REPORT_TYPE_OUTPUT

```TypeScript
REPORT_TYPE_OUTPUT = 2
```

输出报告，表示HID主机向本端发送的数据。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## REPORT_TYPE_FEATURE

```TypeScript
REPORT_TYPE_FEATURE = 3
```

特征报告，表示双向传输的配置数据。

**起始版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core
