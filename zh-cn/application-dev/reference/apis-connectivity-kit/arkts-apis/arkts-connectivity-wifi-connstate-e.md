# ConnState

```TypeScript
export enum ConnState
```

表示Wi-Fi连接状态的枚举。

> **说明：** 
> 
> 从API version 6开始支持，从API version 9开始废弃。

**起始版本：** 6

**废弃版本：** 9

**替代接口：** [ConnState](arkts-connectivity-wifimanager-connstate-e.md)

**系统能力：** SystemCapability.Communication.WiFi.STA
