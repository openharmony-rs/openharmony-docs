# NfcState

定义不同的NFC状态值。

**起始版本：** 7

**系统能力：** SystemCapability.Communication.NFC.Core

## STATE_OFF

```TypeScript
STATE_OFF = 1
```

NFC已关闭状态。

**起始版本：** 7

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Communication.NFC.Core

## STATE_TURNING_ON

```TypeScript
STATE_TURNING_ON = 2
```

NFC正在打开状态。

**起始版本：** 7

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Communication.NFC.Core
