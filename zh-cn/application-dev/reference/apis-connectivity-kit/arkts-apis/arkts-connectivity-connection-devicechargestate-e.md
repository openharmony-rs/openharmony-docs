# DeviceChargeState

枚举，表示设备当前的充电状态。

**起始版本：** 12

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## DEVICE_NORMAL_CHARGE_NOT_CHARGED

```TypeScript
DEVICE_NORMAL_CHARGE_NOT_CHARGED = 0
```

不支持超级快充能力的设备当前处于未充电状态。

**起始版本：** 12

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core
