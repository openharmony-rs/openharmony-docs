```TypeScript
function uninit(): boolean
```

**替代接口：** [uninitialize](arkts-connectivity-connectedtag-uninitialize-f.md)

**系统能力：** SystemCapability.Communication.ConnectedTag

**返回值：**

| 类型 | 说明 |
| --- | --- |
| boolean | true：卸载操作成功。  |
