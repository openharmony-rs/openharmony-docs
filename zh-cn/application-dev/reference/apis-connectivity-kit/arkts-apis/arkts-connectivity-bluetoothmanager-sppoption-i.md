# SppOption

描述spp的配置参数。

从API version 9开始支持，从API version 10开始废弃。

**起始版本：** 9

**废弃版本：** 10

**替代接口：** [SppOptions](arkts-connectivity-socket-sppoptions-i.md)

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## 导入模块

```TypeScript
import { bluetoothManager } from '@kit.ConnectivityKit';
```

## secure

```TypeScript
secure: boolean
```

是否是安全通道。

**类型：** boolean

**起始版本：** 9

**废弃版本：** 10

**替代接口：** [secure](arkts-connectivity-socket-sppoptions-i.md#secure)

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## type

```TypeScript
type: SppType
```

Spp链路类型。

**类型：** [SppType](arkts-connectivity-bluetoothmanager-spptype-e.md)

**起始版本：** 9

**废弃版本：** 10

**替代接口：** [type](arkts-connectivity-socket-sppoptions-i.md#type)

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## uuid

```TypeScript
uuid: string
```

套接字链路类型的服务UUID。

**类型：** string

**起始版本：** 9

**废弃版本：** 10

**替代接口：** [uuid](arkts-connectivity-socket-sppoptions-i.md#uuid)

**系统能力：** SystemCapability.Communication.Bluetooth.Core
