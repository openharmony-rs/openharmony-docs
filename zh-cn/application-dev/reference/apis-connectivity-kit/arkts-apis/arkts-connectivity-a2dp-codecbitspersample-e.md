# CodecBitsPerSample

枚举，蓝牙媒体音频编解码器的位深，表示蓝牙音频信号在数字表示中使用的位数，单位为bit。位深决定每个采样点可以表示的动态范围和精度。

**起始版本：** 11

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## CODEC_BITS_PER_SAMPLE_NONE

```TypeScript
CODEC_BITS_PER_SAMPLE_NONE = 0
```

位深未知。

**系统能力：** SystemCapability.Communication.Bluetooth.Core
