# MajorMinorClass

枚举，主要次要蓝牙设备类别。

从API version 9开始支持，从API version 10开始废弃。

**起始版本：** 9

**废弃版本：** 10

**替代接口：** [MajorMinorClass](arkts-connectivity-constant-majorminorclass-e.md)

**系统能力：** SystemCapability.Communication.Bluetooth.Core
