# @ohos.bluetooth.wearDetection(蓝牙佩戴检测模块)

佩戴检测模块提供了获取蓝牙音频设备(如蓝牙耳机)是否支持佩戴检测、是否开启佩戴检测的方法。

**起始版本：** 11

**系统能力：** SystemCapability.Communication.Bluetooth.Core

## 导入模块

```TypeScript
import { wearDetection } from '@kit.ConnectivityKit';
```
