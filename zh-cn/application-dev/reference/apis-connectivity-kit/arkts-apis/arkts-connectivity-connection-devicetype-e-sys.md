# DeviceType（系统接口）

枚举，蓝牙远程设备的自定义类型。

**起始版本：** 12

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。

## DEVICE_TYPE_DEFAULT

```TypeScript
DEVICE_TYPE_DEFAULT = 0
```

默认设备类型，与原类型一致。&lt;br/

**起始版本：** 12

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。
