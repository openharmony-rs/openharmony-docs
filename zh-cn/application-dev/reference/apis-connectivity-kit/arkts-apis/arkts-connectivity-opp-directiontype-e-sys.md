# DirectionType（系统接口）

枚举，文件传输方向。

**起始版本：** 16

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。

## OUTBOUND

```TypeScript
OUTBOUND = 0
```

表示本文件是发送方向。

**起始版本：** 16

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。

## INBOUND

```TypeScript
INBOUND = 1
```

表示本文件是接收方向。

**起始版本：** 16

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。
