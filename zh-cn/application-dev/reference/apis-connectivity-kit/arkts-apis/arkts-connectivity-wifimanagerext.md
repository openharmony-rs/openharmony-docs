# @ohos.wifiManagerExt(WLAN扩展接口)

该模块主要提供Wi-Fi扩展接口，供非通用类型产品使用。

**起始版本：** 9

**系统能力：** SystemCapability.Communication.WiFi.AP.Extension

## 导入模块

```TypeScript
import { wifiManagerExt } from '@kit.ConnectivityKit';
```
