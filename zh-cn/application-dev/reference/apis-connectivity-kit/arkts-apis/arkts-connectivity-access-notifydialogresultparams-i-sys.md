# NotifyDialogResultParams（系统接口）

用户操作对话框的行为。

**起始版本：** 20

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。

## 导入模块

```TypeScript
import { access } from '@kit.ConnectivityKit';
```

## dialogResult

```TypeScript
dialogResult: boolean
```

表示用户操作对话框的行为。true表示用户同意该操作，false表示拒绝该操作。

**类型：** boolean

**起始版本：** 20

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。

## dialogType

```TypeScript
dialogType: DialogType
```

表示对话框的类型。

**类型：** [DialogType](arkts-connectivity-access-dialogtype-e-sys.md)

**起始版本：** 20

**系统能力：** SystemCapability.Communication.Bluetooth.Core

**系统接口：** 此接口为系统接口。
