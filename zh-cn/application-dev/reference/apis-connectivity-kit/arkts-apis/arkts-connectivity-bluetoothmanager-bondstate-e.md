# BondState

枚举，配对状态。

从API version 9开始支持，从API version 10开始废弃。

**起始版本：** 9

**废弃版本：** 10

**替代接口：** [BondState](arkts-connectivity-connection-bondstate-e.md)

**系统能力：** SystemCapability.Communication.Bluetooth.Core
