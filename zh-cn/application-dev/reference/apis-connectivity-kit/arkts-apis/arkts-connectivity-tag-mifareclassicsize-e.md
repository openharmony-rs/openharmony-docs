# MifareClassicSize

MIFARE Classic标签存储大小的定义。

**起始版本：** 9

**系统能力：** SystemCapability.Communication.NFC.Tag

## MC_SIZE_MINI

```TypeScript
MC_SIZE_MINI = 320
```

每个标签5个扇区，每个扇区4个块。

**起始版本：** 9

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Communication.NFC.Tag
