# StopCode

枚举停止代码， 用于ON_STOP函数。

**起始版本：** 26.1.0

**系统能力：** SystemCapability.ResourceSchedule.WorkScheduler

## SUCCESS

```TypeScript
SUCCESS = 0
```

执行成功码。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ResourceSchedule.WorkScheduler
