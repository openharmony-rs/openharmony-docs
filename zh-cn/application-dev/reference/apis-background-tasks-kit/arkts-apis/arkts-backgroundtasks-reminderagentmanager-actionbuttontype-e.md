**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## ACTION_BUTTON_TYPE_CLOSE

```TypeScript
ACTION_BUTTON_TYPE_CLOSE = 0
```

表示关闭提醒的按钮。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## ACTION_BUTTON_TYPE_SNOOZE

```TypeScript
ACTION_BUTTON_TYPE_SNOOZE = 1
```

表示延时提醒的按钮，提醒次数和间隔通过[ReminderRequest](arkts-backgroundtasks-reminderagentmanager-reminderrequest-i.md#ReminderRequest)中snoozeTimes和timeInterval设置。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
