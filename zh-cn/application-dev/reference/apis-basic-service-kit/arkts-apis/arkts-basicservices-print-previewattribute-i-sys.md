# PreviewAttribute（系统接口）

定义打印预览属性的接口。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**起始版本：** 23

**废弃版本：** -1

result?: int
