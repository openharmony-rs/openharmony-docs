# @ohos.deviceInfo

本模块提供终端设备信息查询，开发者不可配置。 > **说明：** > > 本模块首批接口从API version 6开始支持。后续版本的新增接口，采用上角标单独标记接口的起始版本。 > 部分参数返回值为default的，会在正式发布的版本中配置。 > 本模块接口返回设备常量信息，建议应用只调用一次，不需要频繁调用。

**起始版本：** 24

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为24。
