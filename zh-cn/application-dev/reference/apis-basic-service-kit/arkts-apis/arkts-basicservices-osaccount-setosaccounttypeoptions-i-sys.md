# SetOsAccountTypeOptions（系统接口）

设置系统账号类型的选项。

**起始版本：** 24

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为24。

## token

```TypeScript
token?: Uint8Array
```

表示从认证管理接口获取的token，默认为空。

**类型：** Uint8Array

**起始版本：** 24

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为24。
