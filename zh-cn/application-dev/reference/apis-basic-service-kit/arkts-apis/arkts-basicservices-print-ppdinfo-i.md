# PpdInfo

定义打印机所使用驱动的PPD文件信息的接口。

**起始版本：** 24

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为24。

**废弃版本：** -1

**系统能力：** SystemCapability.Print.PrintFramework

## manufacturer

```TypeScript
manufacturer: string
```

表示当前PPD文件内的打印机厂商名称。

**类型：** string

**起始版本：** 24

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为24。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
