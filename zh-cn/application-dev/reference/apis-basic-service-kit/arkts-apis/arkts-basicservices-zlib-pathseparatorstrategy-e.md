# PathSeparatorStrategy

PathSeparatorStrategy作为[Options]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_的一个属性，用于指定解压时目标压缩包内文件路径中分隔符的处理策略。

**ArkTS模式：** ArkTS-Dyn起始版本为21；ArkTS-Sta起始版本为23。

