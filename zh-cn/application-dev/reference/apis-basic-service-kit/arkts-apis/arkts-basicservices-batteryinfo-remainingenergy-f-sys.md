# remainingEnergy（系统接口）

## remainingEnergy

```TypeScript
function remainingEnergy(): int
```

获取当前设备电池的剩余容量，单位毫安时。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。
