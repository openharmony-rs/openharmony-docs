# SelectionType（系统接口）

定义划词方式枚举值。 | 名称 | 值 | 说明 | | ------------ | -- | ------------------ | | MOUSE_MOVE | 1 | 鼠标或触控板滑动划词。 | | DOUBLE_CLICK | 2 | 鼠标或触控板双击划词。 | | TRIPLE_CLICK | 3 | 鼠标或触控板三击划词。 |

**起始版本：** 24

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为24。

**废弃版本：** -1
