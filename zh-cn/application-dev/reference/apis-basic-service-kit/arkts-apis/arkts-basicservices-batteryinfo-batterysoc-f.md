# batterySOC

## batterySOC

```TypeScript
function batterySOC(): int
```

表示当前设备剩余电池电量百分比，取值范围是[0，100]。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

| 类型 | 说明 |
