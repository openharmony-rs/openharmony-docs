# PrintMargin

定义打印页边距的接口。

**起始版本：** 24

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。

<!--Device-print-interface PrintMargin--><!--Device-print-interface PrintMargin-End-->

**系统能力：** SystemCapability.Print.PrintFramework

## bottom

```TypeScript
bottom?: int
```

表示页面下边距。默认值为0。单位：毫米。

**类型：** int

**起始版本：** 24

**ArkTS模式：** ArkTS-Dyn起始版本为10；ArkTS-Sta起始版本为23。
