# CoordinatesOptions

设置坐标选项对象，用于指定坐标系的变换方向。

**起始版本：** 8

**系统能力：** SystemCapability.Sensors.Sensor

## 导入模块

```TypeScript
import { sensor } from '@kit.SensorServiceKit';
```

## x

```TypeScript
x: number
```

x坐标方向，用于指定旋转矩阵变换在x轴的方向。

**类型：** number

**起始版本：** 8

**系统能力：** SystemCapability.Sensors.Sensor

## y

```TypeScript
y: number
```

y坐标方向，用于指定旋转矩阵变换在y轴的方向。

**类型：** number

**起始版本：** 8

**系统能力：** SystemCapability.Sensors.Sensor
