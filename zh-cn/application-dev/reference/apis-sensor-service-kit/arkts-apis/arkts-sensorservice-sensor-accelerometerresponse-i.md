# AccelerometerResponse

**继承/实现关系：** AccelerometerResponse extends [Response](arkts-sensorservice-sensor-response-i.md)

**起始版本：** 8

**系统能力：** SystemCapability.Sensors.Sensor


## x

```TypeScript

```

施加在设备x轴方向的加速度。单位：m/s²；取值为实际上报物理量。
