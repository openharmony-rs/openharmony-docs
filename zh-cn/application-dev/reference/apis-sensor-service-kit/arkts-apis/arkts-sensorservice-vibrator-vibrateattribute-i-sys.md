# VibrateAttribute

马达振动属性。用于 [startVibration](arkts-sensorservice-vibrator-startvibration-f.md#startVibration) 接口的attribute参数，指定马达ID、设备ID和振动使用场景。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
