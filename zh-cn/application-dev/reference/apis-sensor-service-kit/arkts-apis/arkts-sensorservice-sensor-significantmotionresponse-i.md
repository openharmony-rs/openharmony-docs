## scalar

```TypeScript
scalar: number
```

表示剧烈运动程度。取值范围：1（检测到有效运动），表示设备在三个物理轴（x、y和z）上存在大幅度运动时上报为1。

**类型：** number

**起始版本：** 8

**系统能力：** SystemCapability.Sensors.Sensor
