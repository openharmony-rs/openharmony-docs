# AccelerometerResponse

感应到加速度数据变化后的回调函数的响应对象，包含设备在x、y、z三轴方向上的加速度数据。

**起始版本：** 3

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为3。

**废弃版本：** 8

**替代接口：** [AccelerometerResponse](arkts-sensorservice-sensor-accelerometerresponse-i.md#AccelerometerResponse)

**需要权限：** ohos.permission.ACCELEROMETER

## x

```TypeScript
x: number
```

施加在设备x轴的加速度。单位：m/s²。取值范围：取值为实际上报物理量，由硬件传感器决定。

**类型：** number

**起始版本：** 3

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为3。

**废弃版本：** 8

**替代接口：** [x](arkts-sensorservice-sensor-accelerometerresponse-i.md#x)

**需要权限：** ohos.permission.ACCELEROMETER

**模型约束：** 此接口仅可在FA模型下使用。

## z

```TypeScript

```
