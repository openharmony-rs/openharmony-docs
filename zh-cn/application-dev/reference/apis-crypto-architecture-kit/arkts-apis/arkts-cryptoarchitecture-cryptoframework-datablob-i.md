# DataBlob

二进制数据的封装接口，核心字段data为Uint8Array类型。 > **说明：** > > Uint8Array类型数据表示8位无符号整数的数组。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

数据。
