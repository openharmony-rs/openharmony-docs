# CmsRecipientInfo

CMS封装数据的接收者信息。 > **说明：** > > 至少需要设置一个接收者。

**起始版本：** 22

**ArkTS模式：** ArkTS-Dyn起始版本为22；ArkTS-Sta起始版本为23。
