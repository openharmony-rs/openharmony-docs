# CertificateDialogProperty

表示证书管理对话框的属性。

**起始版本：** 18

**ArkTS模式：** ArkTS-Dyn起始版本为18；ArkTS-Sta起始版本为23。

## showInstallButton

```TypeScript
showInstallButton: boolean
```

表示是否显示安装证书的按钮，true为显示，false为不显示。

**类型：** boolean

**起始版本：** 18

**ArkTS模式：** ArkTS-Dyn起始版本为18；ArkTS-Sta起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
