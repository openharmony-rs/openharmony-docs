# ExtensionOidType

证书扩展OID类型的枚举。

**起始版本：** 10

**系统能力：** SystemCapability.Security.Cert

## EXTENSION_OID_TYPE_ALL

```TypeScript
EXTENSION_OID_TYPE_ALL = 0
```

所有OID。

**起始版本：** 10

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Security.Cert

## EXTENSION_OID_TYPE_CRITICAL

```TypeScript
EXTENSION_OID_TYPE_CRITICAL = 1
```

critical为true的OID。

**起始版本：** 10

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Security.Cert

## EXTENSION_OID_TYPE_UNCRITICAL

```TypeScript
EXTENSION_OID_TYPE_UNCRITICAL = 2
```

critical为false的OID。

**起始版本：** 10

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Security.Cert
