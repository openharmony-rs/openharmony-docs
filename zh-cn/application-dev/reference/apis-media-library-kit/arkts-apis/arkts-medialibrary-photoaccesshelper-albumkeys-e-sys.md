## ALBUM_LPATH

```TypeScript
ALBUM_LPATH = 'lpath'
```

相册的虚拟路径。 支持的相册及对应的lpath值： - 相机应用相册：'/DCIM/Camera' - 截图应用相册：'/Pictures/Screenshots' - 屏幕录制应用相册：'/Pictures/Screenrecords' - 用户创建的相册：'/Pictures/Users/{用户自定义相册名称}'

**起始版本：** 23
