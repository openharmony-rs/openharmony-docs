# PhotoSource

枚举，图片或者视频数据的来源类型。

**起始版本：** 20

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## ALL

```TypeScript
ALL = 0
```

所有来源的图片、视频。

**起始版本：** 20

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## CAMERA

```TypeScript
CAMERA = 1
```

仅相机拍摄的图片、视频。

**起始版本：** 20

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## SCREENSHOT

```TypeScript
SCREENSHOT = 2
```

截屏图片或者录屏视频。

**起始版本：** 20

**原子化服务API：** 从API版本20开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core
