# ResourceType

枚举，写入资源的类型。

**起始版本：** 11

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## IMAGE_RESOURCE

```TypeScript
IMAGE_RESOURCE = 1
```

表示图片资源。

**起始版本：** 11

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## VIDEO_RESOURCE

```TypeScript
VIDEO_RESOURCE = 2
```

表示视频资源。

**起始版本：** 11

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core
