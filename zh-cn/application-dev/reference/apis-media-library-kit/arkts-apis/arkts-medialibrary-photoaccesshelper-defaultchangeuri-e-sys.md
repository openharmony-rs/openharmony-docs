# DefaultChangeUri

枚举，DefaultChangeUri子类型。

**起始版本：** 10

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## DEFAULT_HIDDEN_ALBUM_URI

```TypeScript
DEFAULT_HIDDEN_ALBUM_URI = 'file://media/HiddenAlbum'
```

隐藏相册-相册视图中相册的Uri，即系统中包含隐藏文件的相册（不包含系统预置隐藏相册和回收站相册）的Uri， 仅用于隐藏相册-相册视图场景的通知。

**起始版本：** 11

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。
