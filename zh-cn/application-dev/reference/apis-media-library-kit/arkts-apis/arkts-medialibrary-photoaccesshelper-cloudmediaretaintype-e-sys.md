# CloudMediaRetainType（系统接口）

枚举，表示云端媒体资产的删除方式。

**起始版本：** 14

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。

## RETAIN_FORCE

```TypeScript
RETAIN_FORCE = 0
```

删除原文件在云空间的本地元数据和缩略图。

**起始版本：** 14

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。

## HDC_RETAIN_FORCE

```TypeScript
HDC_RETAIN_FORCE = 1
```

删除原文件在家庭存储设备的本地元数据和缩略图。

**起始版本：** 22

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。
