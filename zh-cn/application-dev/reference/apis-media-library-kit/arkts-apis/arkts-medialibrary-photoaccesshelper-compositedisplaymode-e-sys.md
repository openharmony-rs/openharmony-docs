# CompositeDisplayMode（系统接口）

枚举，表示复合图显示模式。

**起始版本：** 23

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。

## DEFAULT

```TypeScript
DEFAULT = 0
```

复合图显示模式为原图。

**起始版本：** 23

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。

## CLOUD_ENHANCEMENT

```TypeScript
CLOUD_ENHANCEMENT = 1
```

复合图显示模式为云增强。

**起始版本：** 23

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。
