# PickerOrientation

```TypeScript
export declare enum PickerOrientation
```

Picker宫格页面滑动预览的方向。

从API版本20开始，该能力支持配置；在API版本12-19，该能力设置不生效，默认为竖直方向。

**起始版本：** 12
