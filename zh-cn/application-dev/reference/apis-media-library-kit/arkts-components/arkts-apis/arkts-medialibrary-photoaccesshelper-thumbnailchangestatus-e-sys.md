# ThumbnailChangeStatus（系统接口）

枚举，表示缩略图（包括图片/视频）更新的状态。

**起始版本：** 20

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。

## THUMBNAIL_NOT_EXISTS

```TypeScript
THUMBNAIL_NOT_EXISTS = 0
```

缩略图不存在。

**起始版本：** 20

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。
