# AlbumType

枚举，相册类型，表示是用户相册还是系统预置相册。

**起始版本：** 12

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## USER

```TypeScript
USER = 0
```

用户相册。

**起始版本：** 12

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

## SYSTEM

```TypeScript
SYSTEM = 1024
```

系统预置相册。

**起始版本：** 12

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core
