# HiddenPhotosDisplayMode（系统接口）

枚举，系统中隐藏文件显示模式。

**起始版本：** 11

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。

## ASSETS_MODE

```TypeScript
ASSETS_MODE = 0
```

按系统预置的隐藏相册显示隐藏文件，即显示系统中所有的隐藏文件。

**起始版本：** 11

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。

## ALBUMS_MODE

```TypeScript
ALBUMS_MODE = 1
```

按相册显示隐藏文件（即显示系统中所有包含隐藏文件的相册，除系统预置的隐藏相册本身和回收站相册以外）。

**起始版本：** 11

**系统能力：** SystemCapability.FileManagement.PhotoAccessHelper.Core

**系统接口：** 此接口为系统接口。
