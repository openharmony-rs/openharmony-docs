## displayId

```TypeScript
displayId?: int
```

坐标点所属的屏幕ID，取值范围：大于等于0的整数。默认值为设备默认屏幕ID。 从API version 20开始，该接口支持在原子化服务中使用。

**类型：** int

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。
