# @ohos.application.testRunner

TestRunner模块提供了框架测试的能力。包括准备单元测试环境、运行测试用例。
 如果您想实现自己的单元测试框架，您必须继承这个类并覆盖它的所有方法。
 > **说明：**
 >
 > 本模块接口仅可在[单元测试框架](../../../application-test/unittest-guidelines.md)中使用。
