# 属性

## BY

```TypeScript
declare const BY: By
```

用于便捷构造[By](arkts-test-uitest-by-c.md)对象的静态构造器，使用示例：BY.text('txt').enabled(true)。

**类型：** [By](arkts-test-uitest-by-c.md)

**起始版本：** 8

**废弃版本：** 9

**替代接口：** ON

**系统能力：** SystemCapability.Test.UiTest

## ON

```TypeScript
declare const ON: On
```

用于便捷构造[On](arkts-test-uitest-on-c.md)对象的静态构造器，使用示例：ON.text('txt').enabled(true)。

**类型：** [On](arkts-test-uitest-on-c.md)

**起始版本：** 9

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Test.UiTest
