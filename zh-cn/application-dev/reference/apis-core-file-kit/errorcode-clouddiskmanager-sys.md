> **说明：**
>
> 以下仅介绍本模块特有错误码，通用错误码请参考[通用错误码说明文档](../errorcode-universal.md)。

## 34400001 输入参数无效

**错误信息**

Invalid argument.

**错误描述**

输入参数无效。

**可能原因**

文件路径为空、不是绝对路径、包含非法路径段（如“..”或“.”），或枚举参数取值不在允许范围内。

**处理步骤**

检查并修正入参后重试。

## 34400003 IPC通信失败

**错误信息**

IPC communication failed

**错误描述**

IPC通信失败。

**可能原因**

调用服务不存在。

**处理步骤**

检查服务是否启动。

## 34400008 同步根路径未注册

**错误信息**

The sync root path is not registered.

**错误描述**

同步根路径未注册，或已注册的同步根信息查询失败。

**可能原因**

目标路径不在任何已注册的同步根目录范围内，或系统查询已注册同步根信息失败。

**处理步骤**

确认目标路径位于三方云盘应用已注册的同步根目录范围内后重试。

## 34400010 同步根路径不存在

**错误信息**

The sync root path does not exist.

**错误描述**

同步根路径不存在，或路径解析时目标文件、挂载路径缺失。

**可能原因**

同步根目录已被删除或未挂载，或目标文件在路径解析时不存在。

**处理步骤**

确认同步根路径存在且目标文件路径有效后重试。

## 34400014 系统内部错误

**错误信息**

Temporary failure, Retry is recommended (e.g., network issues).

**错误描述**

内部错误。

**可能原因**

网络通信异常，数据写入数据库失败。

**处理步骤**

由当前应用进行重试。

## 34400015 当前设备不允许使用云盘功能

**错误信息**

Cloud disk is not allowed on this device.

**错误描述**

当前设备不允许使用云盘功能。

**可能原因**

当前设备不允许使用云盘功能。

**处理步骤**

三方云盘应用弹框提示用户“当前设备不允许使用云盘功能”。

## 34400017 目标路径不是占位符文件

**错误信息**

The target path is not a placeholder file.

**错误描述**

目标路径不是占位符文件。

**可能原因**

对普通文件（未标记为占位符的文件）调用水合或脱水接口。

**处理步骤**

确认目标文件为三方云盘应用创建的占位符文件后再调用。

## 34400019 水合任务已在进行中

**错误信息**

Hydration in progress.

**错误描述**

目标文件已存在进行中的水合任务。

**可能原因**

同一文件的水合任务尚未完成或未取消时再次发起水合，或水合进行中调用脱水接口。

**处理步骤**

等待水合完成，或先将水合任务取消（调用hydratePlaceholder时callbackType取CANCEL_FETCH_DATA）后再操作。

## 34400020 磁盘可用空间不足

**错误信息**

The available disk space is insufficient.

**错误描述**

磁盘可用空间不足，或磁盘配额已用尽。

**可能原因**

执行脱水时本地磁盘可用空间不足，或应用的磁盘配额已用尽。

**处理步骤**

清理本地存储空间或提升磁盘配额后重试。

## 34400021 回调表未注册

**错误信息**

The callback table is not registered.

**错误描述**

云盘应用回调表未注册，或水合进度回调未注册。

**可能原因**

目标路径不在任何已注册的同步根目录范围内，或目标路径所属同步根对应的三方云盘应用未注册回调表；或调用off('hydrateProgress')取消订阅时，当前实例尚未通过on('hydrateProgress')注册回调。

**处理步骤**

确认目标路径位于已注册的同步根目录范围内，且对应的三方云盘应用已完成回调表注册；取消订阅前请先完成订阅。

## 34400022 回调表已注册

**错误信息**

The callback table has been registered.

**错误描述**

回调已注册。

**可能原因**

同一CloudDiskSystemAccessor实例已通过on('hydrateProgress')注册回调，未取消订阅前再次调用on('hydrateProgress')。

**处理步骤**

先调用off('hydrateProgress')取消订阅后再重新订阅。

## 34400023 路径父目录不是目录

**错误信息**

The parent directory of the target path is not a directory.

**错误描述**

目标路径中本应为目录的路径段不是目录。

**可能原因**

目标路径的某个路径段实际为普通文件，导致路径解析失败。

**处理步骤**

检查并修正目标路径后重试。

## 34400024 目标路径不存在

**错误信息**

The target path does not exist.

**错误描述**

访问解析后的路径时目标路径不存在。

**可能原因**

目标文件或其路径中的某个路径段已被删除或移动。

**处理步骤**

确认目标文件存在后重试。

## 34400025 文件名或路径过长

**错误信息**

The file name or path is too long.

**错误描述**

文件名或路径超出系统允许的最大长度。

**可能原因**

传入的文件路径或其中的文件名超出系统限制。

**处理步骤**

缩短文件名或路径后重试。

## 34400028 占位符文件未完全水合

**错误信息**

The placeholder file is not fully hydrated.

**错误描述**

占位符文件未完全水合。

**可能原因**

对处于未水合或部分水合状态的占位符文件调用脱水接口。

**处理步骤**

先调用hydratePlaceholder完成水合后再执行脱水。

## 34400029 云盘应用拒绝脱水

**错误信息**

The application denied placeholder dehydration.

**错误描述**

三方云盘应用拒绝了脱水授权。

**可能原因**

脱水前系统向三方云盘应用发起脱水授权请求，云盘应用返回不允许脱水（如文件正在被云端使用）。

**处理步骤**

尊重云盘应用的授权结果，暂不执行脱水操作。

## 34400031 占位符文件已完全水合

**错误信息**

The placeholder file is already fully hydrated.

**错误描述**

占位符文件已完全水合，无需再次水合。

**可能原因**

对已完全水合的占位符文件再次发起水合。

**处理步骤**

无需处理，文件内容已在本地。

## 34400032 无进行中的水合任务

**错误信息**

No hydration task is in progress for the target file.

**错误描述**

目标文件不存在进行中的水合任务。

**可能原因**

调用hydratePlaceholder取消水合（callbackType取CANCEL_FETCH_DATA）时，目标文件不存在进行中的水合任务。

**处理步骤**

无需处理。

## 34400033 占位符状态无效

**错误信息**

The stored placeholder state is invalid.

**错误描述**

占位符文件存储的状态或属性无效。

**可能原因**

占位符文件的状态值不在有效范围内，或其记录的属性信息损坏。

**处理步骤**

请重试；若持续出现该错误，请三方云盘应用重建该占位符文件。

## 34400034 活跃水合任务数量达到上限

**错误信息**

The number of active placeholder hydration tasks has reached the limit.

**错误描述**

活跃水合任务数量达到上限。

**可能原因**

单个云盘应用的活跃水合任务数达到5个，或全局活跃水合任务数达到10个。

**处理步骤**

等待部分水合任务完成或取消部分任务后再重试。
