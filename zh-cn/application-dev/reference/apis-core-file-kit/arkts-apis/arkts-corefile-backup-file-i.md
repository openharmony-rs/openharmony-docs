# File（系统接口）

文件对象，包含文件元数据、文件数据和清单文件信息。 用于客户端与备份服务进行IPC。

**继承/实现关系：** File extends [FileMeta](arkts-corefile-backup-filemeta-i-sys.md#FileMeta（系统接口）), [FileData](arkts-corefile-backup-filedata-i-sys.md#FileData（系统接口）), [FileManifestData](arkts-corefile-backup-filemanifestdata-i-sys.md#FileManifestData（系统接口）)

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
