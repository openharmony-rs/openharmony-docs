# IncrementalBackupData（系统接口）

一次增量备份对象，包含最后一次增量备份时间和增量清单。

**继承/实现关系：** IncrementalBackupData extends [IncrementalBackupTime](arkts-corefile-backup-incrementalbackuptime-i-sys.md#IncrementalBackupTime（系统接口）), [FileManifestData](arkts-corefile-backup-filemanifestdata-i-sys.md#FileManifestData（系统接口）), [BackupParams](arkts-corefile-backup-backupparams-i-sys.md#BackupParams（系统接口）), [BackupPriority](arkts-corefile-backup-backuppriority-i-sys.md#BackupPriority（系统接口）)

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
