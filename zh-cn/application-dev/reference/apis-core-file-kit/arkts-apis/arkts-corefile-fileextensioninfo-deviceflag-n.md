# DeviceFlag

组成RootInfo中的deviceFlags字段，通过与运算判断是否具备某种能力。

**起始版本：** 9

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为9。

**废弃版本：** 23

**模型约束：** 此接口仅可在Stage模型下使用。

**系统接口：** 此接口为系统接口。
