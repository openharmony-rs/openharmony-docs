# openSync

## openSync

```TypeScript
declare function openSync(path: string, mode?: number): File
```

以同步方法打开文件或目录。支持使用URI打开文件。

**起始版本：** 9

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为9。

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。
