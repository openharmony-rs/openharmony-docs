# AudioSelectOptions

音频选择选项。

**起始版本：** 9

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为9。

**废弃版本：** -1

## maxSelectNumber

```TypeScript
maxSelectNumber?: int
```

选择文件最大个数，默认值为1，上限为500个，有效值范围1-500。

**类型：** int

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
