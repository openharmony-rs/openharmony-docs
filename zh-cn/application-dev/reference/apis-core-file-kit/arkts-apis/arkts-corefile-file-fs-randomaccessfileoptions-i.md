# RandomAccessFileOptions

可选项类型，支持 createRandomAccessFile 接口使用。

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**废弃版本：** -1

## end

```TypeScript
end?: number
```

表示期望读取结束的位置，单位为Byte。可选，默认文件末尾。

**类型：** number

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**废弃版本：** -1

## start

```TypeScript
start?: number
```

表示期望读取文件的位置，单位为Byte。可选，默认从当前位置开始读。

**类型：** number

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**废弃版本：** -1
