# PerceptionCycle（系统接口）

```TypeScript
export enum PerceptionCycle
```

定义感知扫描的保活周期级别。级别越高，保活周期越短。

**起始版本：** 26.0.1

**系统能力：** SystemCapability.Communication.SoftBus.Core

**系统接口：** 此接口为系统接口。

