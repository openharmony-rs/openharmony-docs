# HardwareDescriptor（系统接口）

表示分布式硬件的描述信息。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.DistributedHardware.DistributedHardwareFWK

**系统接口：** 此接口为系统接口。

## srcNetworkId

```TypeScript
srcNetworkId?: string
```

表示源端设备，缺省时表示所有源端设备。

**类型：** string

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**需要权限：** ohos.permission.ACCESS_DISTRIBUTED_HARDWARE
