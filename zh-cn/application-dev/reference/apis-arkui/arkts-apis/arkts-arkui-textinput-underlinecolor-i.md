# UnderlineColor

Defines the underline color width property.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

## disable

```TypeScript
disable?: ResourceColor | undefined
```

禁用时下划线颜色。不填写、undefined、null、无效值时恢复默认。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。

## error

```TypeScript
error?: ResourceColor | undefined
```
