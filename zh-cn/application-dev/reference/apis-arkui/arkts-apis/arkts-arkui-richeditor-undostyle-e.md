# UndoStyle

撤销还原是否保留原样式选项。

**起始版本：** 24

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为24。

**废弃版本：** -1

## CLEAR_STYLE

```TypeScript
CLEAR_STYLE = 0
```

**起始版本：** 24

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为24。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
