# SwipeDirection

定义滑动手势的触发方向。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## None

```TypeScript
None
```

任何方向均不可触发。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

## Horizontal

```TypeScript
Horizontal
```

水平方向，手指滑动方向与x轴夹角小于45度时触发。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。
