# ScaleOption

缩放参数。

**起始版本：** 7

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## 导入模块

```TypeScript
import { matrix4 } from '@kit.ArkUI';
```

## centerX

```TypeScript
centerX?: number
```

变换中心点x轴坐标。单位：px默认值：组件中心点x轴坐标。取值范围 (-∞, +∞)

**类型：** number

**起始版本：** 7

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## x

```TypeScript
x?: number
```

x轴的缩放倍数。x&gt;1时以x轴方向放大，0&lt;x&lt;1时以x轴方向缩小，x&lt;0时沿x轴反向并缩放。默认值：1取值范围 (-∞, +∞)

**类型：** number

**起始版本：** 7

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
