# component/gridRow

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| [BreakPoints](gridrow-breakpoints-i.md) | 设置栅格容器组件的断点。 |
| [GridRowColumnOption](gridrow-gridrowcolumnoption-i.md) | 栅格在不同宽度设备类型下，栅格列数。 |
| [GridRowOptions](gridrow-gridrowoptions-i.md) | 设置栅格行布局容器的布局选项。 |
| [GridRowSizeOption](gridrow-gridrowsizeoption-i.md) | 栅格在不同宽度设备类型下，gutter的大小。 |
| [GutterOption](gridrow-gutteroption-i.md) | 栅格布局间距类型，用于描述栅格子组件不同方向的间距。 |

### 枚举
