## 汇总

### 类

| 名称 | 说明 |
| --- | --- |

| 名称 | 说明 |
| --- | --- |
| [FullscreenInfo](video-fullscreeninfo-i.md) | 用于描述当前视频是否进入全屏播放状态。 |
| [PlaybackInfo](video-playbackinfo-i.md) | 用于描述当前视频播放的进度。 |
| [PosterOptions](video-posteroptions-i.md) | 用于描述当前视频是否配置首帧送显。 |
| [PreparedInfo](video-preparedinfo-i.md) | 用于描述当前视频的时长。 |
| [VideoAttribute](video-videoattribute-i.md) | 用于播放视频文件并控制其播放状态的组件。 |
| [VideoOptions](video-videooptions-i.md) | 定义Video的具体配置参数。 |
