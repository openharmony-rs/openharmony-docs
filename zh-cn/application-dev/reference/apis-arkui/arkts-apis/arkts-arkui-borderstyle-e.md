# BorderStyle

```TypeScript
declare enum BorderStyle
```

定义元素的边框线条样式。

**起始版本：** 7

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## Dotted

```TypeScript
Dotted
```

显示为一系列圆点，圆点半径为borderWidth的一半。

**起始版本：** 7

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
