# ParallelOption

使用ParallelizeUI并行化创建UI时的可选参数。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。


## enable

```TypeScript
enable?: boolean
```

是否开启UI创建并行化。 true：开启并行化创建；false：不开启并行化创建。 默认值：true 取值为undefined时，按默认值true处理。

**类型：** boolean

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
