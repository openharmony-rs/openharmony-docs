# EditableTextChangeValue

文本变化的详细信息，包括预上屏。

**起始版本：** 15

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为15。

**废弃版本：** -1


**类型：** string

**起始版本：** 15
