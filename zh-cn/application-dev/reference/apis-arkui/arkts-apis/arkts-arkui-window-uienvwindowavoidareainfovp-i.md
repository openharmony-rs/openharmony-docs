# UIEnvWindowAvoidAreaInfoVP

窗口不同类型避让区域信息组成的[环境变量](../../../ui/arkts-env-system-property.md)数据类型，每种类型避让区域单位为vp。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.Window.SessionManager

```TypeScript

```
