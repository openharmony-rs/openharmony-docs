# StackOptions

设置堆叠容器的子组件对齐方式。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## alignContent

```TypeScript
alignContent?: Alignment
```

设置子组件在容器内的对齐方式。 默认值：Alignment.Center，非法值：按默认值处理。

**类型：** [Alignment](arkts-arkui-alignment-e.md)

**默认值：** Alignment.Center

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
