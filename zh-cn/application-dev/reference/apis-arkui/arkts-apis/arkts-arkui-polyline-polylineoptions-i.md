# PolylineOptions

用于描述Polyline组件绘制属性。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

## height

```TypeScript
height?: Length
```

高度，取值范围≥0。&lt;br/&gt;默认值：0&lt;br/&gt;默认单位：vp&lt;br/&gt;异常值undefined、null、NaN和Infinity按照默认值处理。

**类型：** [Length](arkts-arkui-length-t.md)

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
