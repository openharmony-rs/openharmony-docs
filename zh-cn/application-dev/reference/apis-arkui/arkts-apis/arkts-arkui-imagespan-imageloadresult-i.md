# ImageLoadResult

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## loadingStatus

```TypeScript
loadingStatus: double
```

图片加载成功的状态值。 **说明：** 返回的状态值为0时，表示图片数据加载成功。返回的状态值为1时，表示图片解码成功。

**类型：** double

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。
