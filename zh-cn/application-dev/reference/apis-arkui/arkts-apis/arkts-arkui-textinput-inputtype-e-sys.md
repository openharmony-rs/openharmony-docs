## SCREEN_LOCK_PASSWORD

```TypeScript
SCREEN_LOCK_PASSWORD = 9
```

锁屏应用密码输入模式。支持输入数字、字母、下划线、空格、特殊字符。密码显示小眼睛图标并且默认会将文字变成圆点，特定设备上输入文字直接显示为圆点。 密码输入模式不支持下划线样式。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
