# Nullable

```TypeScript
declare type Nullable<T> = T | undefined
```

在使用该类型时，其值可以使泛型参数T所指定的类型，也可以是undefined。

**起始版本：** 12

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为12。

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。
