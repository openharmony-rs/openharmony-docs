**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

## radius

```TypeScript
radius: double
```

模糊效果半径。取值范围为[0, +∞)，默认值为0，值越大前景模糊效果越明显，为0时不模糊。

**类型：** double

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
