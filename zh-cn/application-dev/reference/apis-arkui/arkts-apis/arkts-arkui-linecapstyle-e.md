# LineCapStyle

```TypeScript
declare enum LineCapStyle
```

线条端点样式。

**起始版本：** 7

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## Butt

```TypeScript
Butt
```

线条两端为平行线，不额外扩展。

**起始版本：** 7

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## Round

```TypeScript
Round
```

在线条两端延伸半个圆，直径等于线宽。

**起始版本：** 7

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## Square

```TypeScript
Square
```

在线条两端延伸一个矩形，宽度等于线宽的一半，高度等于线宽。

**起始版本：** 7

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
