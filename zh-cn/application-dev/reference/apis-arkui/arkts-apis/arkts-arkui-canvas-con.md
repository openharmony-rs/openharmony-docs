# 常量

## Canvas

```TypeScript
declare const Canvas: CanvasInterface
```

提供画布组件，用于自定义绘制图形。 > **说明：** > > 该组件从API version 8开始支持。后续版本的新增接口，采用上角标单独标记接口的起始版本。

### 子组件 不支持。

**起始版本：** 8

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为8。

**废弃版本：** -1

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。
