# TitleBarType

标题栏类型的可选项，默认值为ROUND_ICON。

**起始版本：** 18

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## SQUARED_ICON

```TypeScript
SQUARED_ICON = 1
```

方形图标样式。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## ROUND_ICON

```TypeScript
ROUND_ICON = 2
```

圆形图标样式。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
