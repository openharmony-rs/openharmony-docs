# MixMode

背景色混合模式的可选项。

**起始版本：** 18

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## AVERAGE

```TypeScript
AVERAGE = 1
```

两种颜色各占一半。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## CROSS

```TypeScript
CROSS = 2
```

一种颜色从另一种颜色中穿过。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## TOWARDS

```TypeScript
TOWARDS = 3
```

一种颜色渐变为另一种颜色。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
