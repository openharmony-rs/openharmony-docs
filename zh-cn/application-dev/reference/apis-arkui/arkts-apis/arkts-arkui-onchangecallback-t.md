# OnChangeCallback

```TypeScript
declare type OnChangeCallback = (value: boolean) => void
```

操作复选框/开关/单选按钮时的回调函数。

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
