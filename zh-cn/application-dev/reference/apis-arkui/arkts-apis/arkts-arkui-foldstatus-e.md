# FoldStatus

```TypeScript
declare enum FoldStatus
```

定义设备的折叠状态。

**起始版本：** 11

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## FOLD_STATUS_UNKNOWN

```TypeScript
FOLD_STATUS_UNKNOWN = 0
```

表示设备当前折叠状态未知。

**起始版本：** 11

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
