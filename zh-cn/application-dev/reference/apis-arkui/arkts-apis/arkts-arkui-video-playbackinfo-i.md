# PlaybackInfo

用于描述当前视频播放的进度。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## time

```TypeScript
time: int
```

当前视频播放的进度。 单位：秒，取值范围：[0,+∞)

**类型：** int

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
