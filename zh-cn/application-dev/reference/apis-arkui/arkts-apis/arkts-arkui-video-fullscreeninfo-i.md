# FullscreenInfo

用于描述当前视频是否进入全屏播放状态。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## fullscreen

```TypeScript
fullscreen: boolean
```

当前视频是否进入全屏播放状态。 true：进入全屏播放状态；false：未进入全屏播放状态。 默认值：false

**类型：** boolean

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
