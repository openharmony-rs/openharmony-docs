# StatusBarProperty

状态栏的属性。在获取状态栏属性信息时返回。

**起始版本：** 18

**ArkTS模式：** ArkTS-Dyn起始版本为18；ArkTS-Sta起始版本为23。

**系统能力：** SystemCapability.Window.SessionManager

## contentColor

```TypeScript
contentColor: string
```

状态栏文字颜色，固定为ARGB格式，如：\_\_\_INLINE\_CODE\_DESC\_USD\_0\_\_\_。

**类型：** string

**起始版本：** 18

**ArkTS模式：** ArkTS-Dyn起始版本为18；ArkTS-Sta起始版本为23。

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。
