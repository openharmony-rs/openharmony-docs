# StatusBarProperty

状态栏的属性。在获取状态栏属性信息时返回。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

## contentColor

```TypeScript
contentColor: string
```

状态栏文字颜色，固定为ARGB格式，如：`#E5FFFFFF`。

**类型：** string

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1

**原子化服务API：** 从API版本23开始，该接口支持在原子化服务API中使用。
