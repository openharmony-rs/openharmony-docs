# PixelUnit

像素单位枚举。

物理像素单位和虚拟像素单位换算可使用px2vp和vp2px。

**起始版本：** 22

**系统能力：** SystemCapability.Window.SessionManager

## PX

```TypeScript
PX = 0
```

物理像素单位（px）。

**起始版本：** 22

**系统能力：** SystemCapability.Window.SessionManager

## VP

```TypeScript
VP = 1
```

虚拟像素单位（vp）。

**起始版本：** 22

**系统能力：** SystemCapability.Window.SessionManager
