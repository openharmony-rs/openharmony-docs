# DarkMode

深浅色模式枚举，用于配置系统的深色或浅色模式。

| 名称 | 值 | 说明 |  
| -- | -- | -- |  
| [ALWAYS_DARK](arkts-arkui-uiappearance-darkmode-e.md) | 0 | 系统始终为深色。 |
| [ALWAYS_LIGHT](arkts-arkui-uiappearance-darkmode-e.md) | 1 | 系统始终为浅色。 |

**起始版本：** 20

**系统能力：** SystemCapability.ArkUI.UiAppearance

## ALWAYS_DARK

```TypeScript
ALWAYS_DARK = 0
```

系统始终为深色。

**起始版本：** 20

**系统能力：** SystemCapability.ArkUI.UiAppearance

## ALWAYS_LIGHT

```TypeScript
ALWAYS_LIGHT = 1
```

系统始终为浅色。

**起始版本：** 20

**系统能力：** SystemCapability.ArkUI.UiAppearance
