# IconStyle

设置关闭按钮的色调样式，默认为亮色调。  
| 名称 | 值 | 说明 | | - | - | - | | DARK | 0 | 设置关闭按钮为暗色调。 | | LIGHT | 1 | 设置关闭按钮为亮色调。默认值。 |

**起始版本：** 12

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## DARK

```TypeScript
DARK = 0
```

设置关闭按钮为暗色调。

**起始版本：** 12

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## LIGHT

```TypeScript
LIGHT = 1
```

设置关闭按钮为亮色调。默认值。

**起始版本：** 12

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
