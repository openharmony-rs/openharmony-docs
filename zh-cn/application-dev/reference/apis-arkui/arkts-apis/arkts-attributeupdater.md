# AttributeUpdater

## 汇总

### 类

| 名称 | 说明 |
| --- | --- |
| [AttributeUpdater](arkts-arkui-attributeupdater-c.md) | 将属性直接设置给组件，无需标记为状态变量即可直接触发UI更新。适用于需要在不定义状态变量的情况下动态更新组件属性的场景，如动态修改组件构造参数、避免为一次性属性更新定义状态变量等。 |
