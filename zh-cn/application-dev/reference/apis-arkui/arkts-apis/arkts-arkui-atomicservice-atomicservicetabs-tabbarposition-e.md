# TabBarPosition

设置页签栏位置，默认值为TabBarPosition.BOTTOM。

**起始版本：** 12

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## LEFT

```TypeScript
LEFT = 0
```

设置TabBar位于屏幕左侧

**起始版本：** 12

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## BOTTOM

```TypeScript
BOTTOM = 1
```

设置TabBar位于屏幕底部

**起始版本：** 12

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
