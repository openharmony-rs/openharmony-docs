# MaxLinesMode

TextArea组件在文本超长时显示效果。默认值为CLIP，按最大行截断显示。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

