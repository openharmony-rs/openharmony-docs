# SelectionContainerTextJoinStyle

文本聚合拼接方式。 | 名称 | 值 | 说明 | | ---- | -- | ---- | | NEWLINE | 0 | 不同文本节点之间使用换行符\_\_\_INLINE\_CODE\_DESC\_USD\_0\_\_\_拼接。 | | DIRECT | 1 | 不同文本节点之间直接拼接，不添加分隔符。 |

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。
