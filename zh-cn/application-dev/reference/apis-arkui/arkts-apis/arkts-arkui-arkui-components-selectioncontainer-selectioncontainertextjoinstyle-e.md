# SelectionContainerTextJoinStyle

文本聚合拼接方式。

**起始版本：** 26.0.0

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## NEWLINE

```TypeScript
NEWLINE = 0
```

不同文本节点之间使用换行符`\n`拼接。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.0.0开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## DIRECT

```TypeScript
DIRECT = 1
```

不同文本节点之间直接拼接，不添加分隔符。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.0.0开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
