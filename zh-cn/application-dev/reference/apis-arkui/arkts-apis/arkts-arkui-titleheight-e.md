# TitleHeight

```TypeScript
declare enum TitleHeight
```

设置标题栏的推荐高度。

**起始版本：** 9

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## MainOnly

```TypeScript
MainOnly
```

只有主标题时，标题栏的推荐高度（56vp）。

**起始版本：** 9

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## MainWithSub

```TypeScript
MainWithSub
```

同时有主标题和副标题时，标题栏的推荐高度（82vp）。

**起始版本：** 9

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
