# PopoverOptions

跟手弹出框参数，用于设置弹出框内容、位置属性等。 继承自CustomPopupOptions。 > **说明：** > > radius默认值为32vp。

**继承/实现关系：** PopoverOptions extends CustomPopupOptions

**起始版本：** 14

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为14。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本14开始，该接口支持在原子化服务API中使用。
