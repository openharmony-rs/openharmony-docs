## FADE_IN

```TypeScript
FADE_IN = 1
```

表示窗口动画类型为淡入。淡入动画在窗口显示过程中生效。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为23。

**废弃版本：** -1
