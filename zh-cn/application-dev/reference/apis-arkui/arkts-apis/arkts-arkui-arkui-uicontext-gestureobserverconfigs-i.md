# GestureObserverConfigs

该参数用于指定需要监听的手势回调阶段（传入空数组将无效），仅当手势触发指定阶段时才会发送通知。

**起始版本：** 20

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
