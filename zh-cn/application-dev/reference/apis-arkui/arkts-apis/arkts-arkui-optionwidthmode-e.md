# OptionWidthMode

```TypeScript
declare enum OptionWidthMode
```

下拉菜单的宽度模式。

**起始版本：** 11

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## FIT_CONTENT

```TypeScript
FIT_CONTENT = 'fit_content'
```

设置该值时，下拉菜单宽度默认为2栅格。

**起始版本：** 11

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## FIT_TRIGGER

```TypeScript
FIT_TRIGGER = 'fit_trigger'
```

设置下拉菜单继承下拉按钮宽度。

**起始版本：** 11

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
