# SnapshotRegionType

```TypeScript
type SnapshotRegionType = SnapshotRegion | LocalizedSnapshotRegion
```

表示组件截图区域。

**起始版本：** 15

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本15开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
