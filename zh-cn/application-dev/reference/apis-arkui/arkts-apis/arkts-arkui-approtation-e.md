# AppRotation

```TypeScript
declare enum AppRotation
```

**起始版本：** 12

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## ROTATION_0

```TypeScript
ROTATION_0 = 0
```

**起始版本：** 12

**模型约束：** 此接口仅可在Stage模型下使用。
