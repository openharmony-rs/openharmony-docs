# Size（系统接口）

表示截取图像的大小。

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。

<!--Device-screenshot-interface Size--><!--Device-screenshot-interface Size-End-->

**系统能力：** SystemCapability.WindowManager.WindowManager.Core

**系统接口：** 此接口为系统接口。

## height

```TypeScript
height: long
```

表示截取图像的高度，单位为px，该参数应为整数。

**类型：** long

**起始版本：** 7

**ArkTS模式：** ArkTS-Dyn起始版本为7；ArkTS-Sta起始版本为23。
