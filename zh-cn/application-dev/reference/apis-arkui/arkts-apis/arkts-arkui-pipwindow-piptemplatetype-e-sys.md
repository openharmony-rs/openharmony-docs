# PiPTemplateType

画中画模板类型枚举。

**起始版本：** 11

**系统能力：** SystemCapability.Window.SessionManager

## VIDEO_DRIVE

```TypeScript
VIDEO_DRIVE = 4
```

表示车载影像画中画模板类型，系统依此加载车载影像模板。

**起始版本：** 26.0.0

**原子化服务API：** 从API版本26.0.0开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.Window.SessionManager

**系统接口：** 此接口为系统接口。

## VIDEO_NAVIGATION

```TypeScript
VIDEO_NAVIGATION = 5
```

表示车载导航画中画模版类型，系统依此加载车载导航模板。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.Window.SessionManager

**系统接口：** 此接口为系统接口。
