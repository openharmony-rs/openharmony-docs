# RadiusItem

```TypeScript
export type RadiusItem = [
    Length,
    Length
]
```

设置圆角的宽度和高度。第一个参数是圆角的宽度，第二个参数是圆角的高度。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
