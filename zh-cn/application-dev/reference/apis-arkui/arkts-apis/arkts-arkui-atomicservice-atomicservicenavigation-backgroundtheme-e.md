# BackgroundTheme

导航栏背景底色的可选项。

**起始版本：** 18

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## DARK

```TypeScript
DARK = 1
```

背景底色为黑色。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## LIGHT

```TypeScript
LIGHT = 2
```

背景底色为白色。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## DEFAULT

```TypeScript
DEFAULT = 3
```

背景底色为灰白色。颜色值`#F1F3F5` 。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务API中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
