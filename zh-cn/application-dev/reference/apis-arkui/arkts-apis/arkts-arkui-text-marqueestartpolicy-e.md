# MarqueeStartPolicy

Marquee的滚动方式，可选择默认持续滚动或条件触发滚动。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## DEFAULT

```TypeScript
DEFAULT = 0
```

默认持续滚动。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
