# ChipSize

```TypeScript
export declare enum ChipSize
```

ChipSize定义Chip组件可指定的尺寸类型，如普通类型和小尺寸型。

**起始版本：** 11

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## NORMAL

```TypeScript
NORMAL = "NORMAL"
```
