# console

提供控制台。

**起始版本：** 3

**系统能力：** SystemCapability.ArkUI.ArkUI.Lite

## debug

```TypeScript
static debug(message: string): void
```

打印调试信息。

**起始版本：** 3

**模型约束：** 此接口仅可在FA模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Lite

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| message | string | 是 | 要打印的文本信息。 @static |
