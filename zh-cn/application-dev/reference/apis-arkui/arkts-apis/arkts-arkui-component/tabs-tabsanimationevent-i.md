# TabsAnimationEvent

Tabs组件动画相关信息集合。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

<!--Device-unnamed-export declare interface TabsAnimationEvent--><!--Device-unnamed-export declare interface TabsAnimationEvent-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## currentOffset

```TypeScript
currentOffset: double
```

Tabs当前显示元素在主轴方向上，相对于Tabs起始位置的位移。 单位为： vp。

**类型：** double

**默认值：** 0.0 vp

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## targetOffset

```TypeScript
targetOffset: double
```

Tabs动画目标元素在主轴方向上，相对于Tabs起始位置的位移。 单位为： vp。

**类型：** double

**默认值：** 0.0 vp

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-TabsAnimationEvent-targetOffset: double--><!--Device-TabsAnimationEvent-targetOffset: double-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## velocity

```TypeScript
velocity: double
```

Tabs离手动画开始时的离手速度。，默认值为0。 单位为： vp/s。

**类型：** double

**默认值：** 0.0 vp/s

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
