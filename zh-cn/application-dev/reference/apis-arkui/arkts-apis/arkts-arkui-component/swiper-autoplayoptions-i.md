## stopWhenTouched

```TypeScript
stopWhenTouched: boolean
```

在按下事件中配置子组件是否立即停止播放。 true表示停止播放；false表示自动播放不中断。 默认值：true

**类型：** boolean

**默认值：** true

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
