# LocalizedBarrierDirection

定义支持镜像模式的屏障线的方向。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## START

```TypeScript
START = 0
```

屏障在其所有referencedId的最左/右侧，LTR模式时为最左侧，RTL模式时为最右侧。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
