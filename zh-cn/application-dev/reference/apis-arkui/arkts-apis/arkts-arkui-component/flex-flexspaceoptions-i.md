# FlexSpaceOptions

设置Flex容器的子组件在主轴或交叉轴的间距。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## cross

```TypeScript
cross?: LengthMetrics
```

**类型：** LengthMetrics

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
