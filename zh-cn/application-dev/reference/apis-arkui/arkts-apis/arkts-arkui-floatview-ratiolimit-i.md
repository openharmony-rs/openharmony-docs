# RatioLimit

标准悬浮窗的宽高比限制范围。宽高比比值由窗口矩形区域的宽除以高获得。

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为26.0.0。

**废弃版本：** -1
