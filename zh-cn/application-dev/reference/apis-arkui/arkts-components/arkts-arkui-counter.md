# Counter

计数器组件，提供增加或减少的计数操作。适用于商品数量选择、参数调整等需要频繁修改数值的场景，帮助用户快速直观地调整数值。 > **说明：** > > - 该组件从API版本26.0.0开始支持WithTheme。

## 子组件 可以包含子组件。

## Counter

```TypeScript
Counter()
```

创建计数器组件。

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为7。

**废弃版本：** -1

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

**卡片能力：** 从API版本9开始，该接口支持在ArkTS卡片中使用。
