# Worker（系统接口）

```TypeScript
declare type Worker = import('../api/@ohos.worker').default.Worker
```

用于运行Abc的Worker线程对象。需通过worker.ThreadWorker创建。

**起始版本：** 26.0.0

**模型约束：** 此接口仅可在Stage模型下使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**系统接口：** 此接口为系统接口。

**类型：** import('../api/@ohos.worker').default.Worker
