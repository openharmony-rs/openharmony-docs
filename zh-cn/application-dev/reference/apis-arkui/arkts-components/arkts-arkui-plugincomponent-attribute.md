# PluginComponent属性/事件

定义插件组件的属性方法。 组件的宽高必须显式设置为非零有效值。 [手势事件]\_\_\_JSDOC\_LINK\_DESC\_USD\_0\_\_\_可以分发到提供方页面内部进行处理。 除[通用事件]\_\_\_JSDOC\_LINK\_DESC\_USD\_1\_\_\_外，还支持以下事件。

**继承/实现关系：** PluginComponentAttribute extends [CommonMethod<PluginComponentAttribute>](CommonMethod<PluginComponentAttribute>)

**起始版本：** 9

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为9。
