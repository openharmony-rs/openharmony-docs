# FormComponent(系统接口) (System API)

Defines FormComponent Component.

## FormComponent

```TypeScript
FormComponent(value: FormInfo)
```

Set a new value of form info.

**起始版本：** 7

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**系统接口：** 此接口为系统接口。

**参数:**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| value | FormInfo | 是 | [since 9 - 11] |

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| ErrorInformation | 卡片错误信息。 |
| FormCallbackInfo | 卡片查询或者卸载时获取formId的参数。 |
| FormInfo | 卡片信息。 |
| FormSize | 卡片大小信息。 |

### 枚举

| 名称 | 说明 |
| --- | --- |
| FormColorMode | 卡片色彩模式枚举。 |
| FormDimension | 卡片尺寸枚举 |
| FormRenderingMode | 卡片渲染模式枚举 |
| FormShape | 定义卡片形状枚举。 |
