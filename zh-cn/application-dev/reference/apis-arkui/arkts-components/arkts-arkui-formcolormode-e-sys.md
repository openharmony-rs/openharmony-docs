# FormColorMode（系统接口）

**起始版本：** 23

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**系统接口：** 此接口为系统接口。

## MODE_AUTO

```TypeScript
MODE_AUTO = -1
```
