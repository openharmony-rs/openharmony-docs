# AbilityComponent (System API)

独立显示Ability的容器。

## AbilityComponent

```TypeScript
AbilityComponent(value: { want: import('../api/@ohos.app.ability.Want').default })
```

创建AbilityComponent。当AbilityComponent被使用时调用。

**起始版本：** 9

**废弃版本：** 10

**替代接口：** UIExtensionComponentInterface

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**系统接口：** 此接口为系统接口。

**参数:**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| value | { want: import('../api/@ohos.app.ability.Want').default } | 是 |  |
