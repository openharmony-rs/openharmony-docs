# SafeAreaInsetAlignment（系统接口）

```TypeScript
declare enum SafeAreaInsetAlignment
```

沿边方向的内容对齐方式。上、下边沿水平方向对齐；起始边、结束边沿垂直方向对齐。

**起始版本：** 26.1.0

## END

```TypeScript
END = 2
```

对齐到沿边方向的终点。上、下边在从左到右布局时靠右，在从右到左布局时靠左；起始边、结束边靠下。

**起始版本：** 26.1.0

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.1.0开始，该接口支持在原子化服务中使用。
