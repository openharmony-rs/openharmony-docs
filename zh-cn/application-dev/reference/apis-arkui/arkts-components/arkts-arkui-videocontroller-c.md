# VideoController

一个VideoController对象可以控制一个或多个Video。

## 导入对象 ```ts let controller: VideoController = new VideoController(); ```

**起始版本：** 7

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为7。
