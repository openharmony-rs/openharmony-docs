# ContainerSpan

Text组件的子组件，用于统一管理多个Span、ImageSpan的背景色及圆角弧度，适用于需要为文本片段和图片组合设置统一背 景样式的场景。

## 子组件 可以包含Span、ImageSpan 子组件。

## ContainerSpan

```TypeScript
ContainerSpan()
```

定义ContainerSpan组件构造函数。

**起始版本：** 11

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本12开始，该接口支持在原子化服务API中使用。
