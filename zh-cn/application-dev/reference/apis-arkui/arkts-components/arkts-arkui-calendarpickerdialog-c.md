# CalendarPickerDialog

点击日期弹出日历选择器弹窗，可在弹窗内选择日期。

**起始版本：** 10

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为10。

## show

```TypeScript
static show(options?: CalendarDialogOptions): void
```

显示日历选择器弹窗，供用户选择日期。

**起始版本：** 10

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为10。

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务API中使用。

| 参数名 | 类型 | 必填 | 说明 |
