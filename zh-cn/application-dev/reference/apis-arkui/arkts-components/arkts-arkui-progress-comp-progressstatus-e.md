# ProgressStatus

```TypeScript
declare enum ProgressStatus
```

进度条的当前状态。

**起始版本：** 10

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## LOADING

```TypeScript
LOADING
```

加载中状态。开启检查更新动效，此时设置进度值不生效。

**起始版本：** 10

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
