## SCREEN_LOCK_PASSWORD

```TypeScript
SCREEN_LOCK_PASSWORD = 9
```

锁屏应用密码输入模式。支持输入数字、字母、下划线、空格、特殊字符。密码显示小眼睛图标并且默认会将文字变成圆点，从API version 12开始，Wearable设备上输入文字直接显示为圆点。密码输入模式不支持下划线样式。 **系统接口：** 此接口为系统接口。

**起始版本：** 11

**模型约束：** 此接口仅可在Stage模型下使用。
