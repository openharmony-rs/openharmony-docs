# TabBarDisplayMode

```TypeScript
declare enum TabBarDisplayMode
```

枚举不同Tabs容器大小下标签栏的实际显示方式。此枚举用于[barDisplayModeBreakpoint](arkts-arkui-tabs-comp-attribute.md#bardisplaymodebreakpoint)中指定不同断点大小的显示模式。只有当**TabBarStyle**设置为**侧栏自适应表**或**侧栏**。

**起始版本：** 26.0.1

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## BOTTOM_TABBAR

```TypeScript
BOTTOM_TABBAR = 0
```

底部显示标签栏。

**起始版本：** 26.0.1

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本26.0.1开始，该接口支持在原子化服务中使用。
