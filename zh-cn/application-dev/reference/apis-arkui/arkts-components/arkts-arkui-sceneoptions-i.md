**系统能力：** SystemCapability.ArkUi.Graphics3D


## modelType

```TypeScript
modelType?: ModelType
```

3D渲染时的场景类型

**类型：** [ModelType](arkts-arkui-modeltype-e.md)

**系统能力：** SystemCapability.ArkUi.Graphics3D
