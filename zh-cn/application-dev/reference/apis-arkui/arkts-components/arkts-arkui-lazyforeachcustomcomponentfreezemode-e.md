# LazyForEachCustomComponentFreezeMode

选择是否使能自定义组件冻结。 > **说明：** > > 该配置仅在LazyForEach下直接使用自定义组件时添加，其他情况不适用。

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Dyn，起始版本为26.0.0。

**废弃版本：** -1
