# ShadowType

阴影类型。

**起始版本：** 10

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## COLOR

```TypeScript
COLOR = 0
```

颜色阴影，基于指定颜色值绘制阴影效果。

**起始版本：** 10

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## BLUR

```TypeScript
BLUR = 1
```

模糊阴影，基于组件内容模糊绘制阴影效果。

**起始版本：** 10

**模型约束：** 此接口仅可在Stage模型下使用。

**原子化服务API：** 从API版本11开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full
