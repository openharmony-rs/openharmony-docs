# OnSelectCallback

```TypeScript
declare type OnSelectCallback =  (index: number) => void
```

定义[onSelect](arkts-arkui-arcalphabetindexer-comp-attribute.md#onselect)中使用的回调类型。

**起始版本：** 18

**原子化服务API：** 从API版本18开始，该接口支持在原子化服务中使用。

**系统能力：** SystemCapability.ArkUI.ArkUI.Circle

**参数：**

| 参数名 | 类型 | 必填 | 说明 |
| --- | --- | --- | --- |
| index | number | 是 | 选中项序号。 |
