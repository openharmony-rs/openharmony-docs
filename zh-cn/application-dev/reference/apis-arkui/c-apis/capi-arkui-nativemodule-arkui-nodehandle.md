# ArkUI_NodeHandle

```c
typedef struct ArkUI_NodeHandle ArkUI_NodeHandle
```

## 概述

定义 ArkUI Native 组件实例对象指针，用于在 ArkUI Native 接口中标识和传递组件实例，例如创建、挂载、移除或销毁组件节点。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

**起始版本：** 12

**相关模块：** [ArkUI_NativeModule](capi-arkui-nativemodule.md)

**所在头文件：** [common_type.h](capi-common-type-h.md)
