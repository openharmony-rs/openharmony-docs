# CanvasDirection

```TypeScript
export type CanvasDirection = 'inherit' | 'ltr' | 'rtl'
```

定义当前文本方向的类型。 'inherit': 继承canvas组件通用属性已设定的文本方向，若canvas组件未设置direction属性，则跟随系统文字方向。 'ltr': 从左往右。 'rtl': 从右往左。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
