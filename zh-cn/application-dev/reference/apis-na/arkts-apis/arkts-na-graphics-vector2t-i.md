# Vector2T

用于表示T类型的包含x和y两个值的向量。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## x

```TypeScript
x: T
```

向量x轴方向的值。 取值范围：(-∞, +∞)。

**类型：** T

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
