# progress

## 汇总

### 接口

| 名称 | 说明 |
| --- | --- |
| [CapsuleStyleOptions](arkts-na-progress-capsulestyleoptions-i.md) | 胶囊样式选项。 继承自[ScanEffectOptions](arkts-na-progress-scaneffectoptions-i.md#ScanEffectOptions)和[CommonProgressStyleOptions](arkts-na-progress-commonprogressstyleoptions-i.md#CommonProgressStyleOptions)。 |
| [CommonProgressStyleOptions](arkts-na-progress-commonprogressstyleoptions-i.md) | 进度条通用样式选项。 |
| [EclipseStyleOptions](arkts-na-progress-eclipsestyleoptions-i.md) | 圆形样式选项。圆形样式的显示类似月圆月缺的进度展示效果，从月牙逐渐变化至满月。 继承自[CommonProgressStyleOptions](arkts-na-progress-commonprogressstyleoptions-i.md#CommonProgressStyleOptions)。 |
| [LinearStyleOptions](arkts-na-progress-linearstyleoptions-i.md) | 线性样式选项。 继承自[ScanEffectOptions](arkts-na-progress-scaneffectoptions-i.md#ScanEffectOptions)和[CommonProgressStyleOptions](arkts-na-progress-commonprogressstyleoptions-i.md#CommonProgressStyleOptions)。 |
| [ProgressConfiguration](arkts-na-progress-progressconfiguration-i.md) | 进度条配置。继承自CommonConfiguration。 |
| [ProgressOptions](arkts-na-progress-progressoptions-i.md) | 进度条选项。 |
| [ProgressStyleOptions](arkts-na-progress-progressstyleoptions-i.md) | 进度条样式选项。 继承自[CommonProgressStyleOptions](arkts-na-progress-commonprogressstyleoptions-i.md#CommonProgressStyleOptions)。 |
| [RingStyleOptions](arkts-na-progress-ringstyleoptions-i.md) | 环形无刻度样式选项。 继承自[ScanEffectOptions](arkts-na-progress-scaneffectoptions-i.md#ScanEffectOptions)和[CommonProgressStyleOptions](arkts-na-progress-commonprogressstyleoptions-i.md#CommonProgressStyleOptions)。 |
| [ScaleRingStyleOptions](arkts-na-progress-scaleringstyleoptions-i.md) | 环形有刻度样式选项。 继承自[CommonProgressStyleOptions](arkts-na-progress-commonprogressstyleoptions-i.md#CommonProgressStyleOptions)。 |
| [ScanEffectOptions](arkts-na-progress-scaneffectoptions-i.md) | 扫光效果选项。 |
