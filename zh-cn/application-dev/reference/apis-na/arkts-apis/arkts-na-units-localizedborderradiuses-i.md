# LocalizedBorderRadiuses

圆角类型，用于描述组件边框圆角半径。 引用该对象时，至少传入一个参数。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1
