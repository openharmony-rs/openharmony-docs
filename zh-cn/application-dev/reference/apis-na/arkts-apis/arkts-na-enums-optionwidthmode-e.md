# OptionWidthMode

Decide whether the width of select menu fit the trigger or content

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## FIT_CONTENT

```TypeScript
FIT_CONTENT = 'fit_content'
```

The menu width fit the content.
