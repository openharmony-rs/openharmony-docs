# LocalizedEdgeColors

边框颜色，用于描述组件边框四条边的颜色。 引入该对象时，至少传入一个参数。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
