# SwiperAnimationMode

Declare the animation mode of SwiperController's changeIndex method.

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## NO_ANIMATION

```TypeScript
NO_ANIMATION = 0
```

无动效翻页至指定页面。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-SwiperAnimationMode-NO_ANIMATION = 0--><!--Device-SwiperAnimationMode-NO_ANIMATION = 0-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## DEFAULT_ANIMATION

```TypeScript
DEFAULT_ANIMATION = 1
```

有动效翻页至指定页面。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-SwiperAnimationMode-DEFAULT_ANIMATION = 1--><!--Device-SwiperAnimationMode-DEFAULT_ANIMATION = 1-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## FAST_ANIMATION

```TypeScript
FAST_ANIMATION = 2
```

先无动效翻页至指定页面附近，再有动效翻页至指定页面。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
