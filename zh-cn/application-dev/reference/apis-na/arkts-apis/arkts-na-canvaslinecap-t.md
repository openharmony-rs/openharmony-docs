# CanvasLineCap

```TypeScript
export type CanvasLineCap = 'butt' | 'round' | 'square'
```

定义绘制每条线段端点的类型。 'butt': 线条两端为平行线，不额外扩展。 'round': 在线条两端延伸半个圆，直径等于线宽。 'square': 在线条两端延伸一个矩形，宽度等于线宽的一半，高度等于线宽。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
