# ReadonlyEnvKey

只读系统环境变量Key类，用于@Env装饰器的字符串参数格式`'ReadonlyEnvKey.&lt;keyName&gt;'`中的key声明。

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**废弃版本：** -1
