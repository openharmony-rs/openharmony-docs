# DirectionalEdgesT

边缘宽度类型，用于描述组件边缘不同方向的宽度。支持全球化。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。
