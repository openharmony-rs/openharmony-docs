# OnInputmethodAttachedCallback

```TypeScript
export type OnInputmethodAttachedCallback = () => void
```

The callback will be triggered when inputmethod is attached.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
