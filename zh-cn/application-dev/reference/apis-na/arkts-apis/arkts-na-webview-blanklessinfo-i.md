## similarity

```TypeScript
similarity: double
```

Obtains the similarity of snapshots generated by the blankless loading solution based on the last several snapshots. The value ranges from 0 to 1.0. The value 1.0 indicates that the snapshots are the same. A value closer to 1 indicates higher similarity. This value has a certain lag, meaning that the similarity of the current loading will only be reflected in the next loading. It is recommended that the frame interpolation functionality be disabled when the similarity is 0.

**类型：** double

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。
