# EdgeColors

type EdgeColors = { top: ResourceColor; right: ResourceColor; bottom: ResourceColor; left: ResourceColor; } 边框颜色，用于描述组件边框四条边的颜色。 引入该对象时，至少传入一个参数。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1
