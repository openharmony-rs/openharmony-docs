# ButtonStyle

设置侧边栏控制按钮的样式。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

<!--Device-unnamed-export declare interface ButtonStyle--><!--Device-unnamed-export declare interface ButtonStyle-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## height

```TypeScript
height?: double
```

设置侧边栏控制按钮的高度。 默认值： API version 9及之前版本：32vp 从API version 10开始：24vp 单位：vp 取值范围：[0, +∞) 异常值时取默认值。

**类型：** double

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-ButtonStyle-height?: double--><!--Device-ButtonStyle-height?: double-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## icons

```TypeScript
icons?: ButtonIconOptions
```

设置侧边栏控制按钮的图标。 资源获取错误以及未设置该属性时，使用默认图标。

**类型：** [ButtonIconOptions](arkts-na-sidebar-buttoniconoptions-i.md)

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-ButtonStyle-icons?: ButtonIconOptions--><!--Device-ButtonStyle-icons?: ButtonIconOptions-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full


**类型：** double

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
