# ScrollType

Enum type supplied to [setScrollable](arkts-na-webview-webviewcontroller-c.md#setScrollable) for indicating the type of scroll.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

## EVENT

```TypeScript
EVENT = 0
```

Indicates scrolling the web page through scroll event, include touch screen, touch pad, and mouse wheel.

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。
