## size

## timeToLive

```TypeScript
timeToLive: int
```

Set the lifetime in seconds in the BackForwardCache. The value should be an integer.Unit: seconds. Default is 600.

**类型：** int

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1
