# FinishCallbackType

动画中定义onFinish回调的类型。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

## REMOVED

```TypeScript
REMOVED = 0
```

当整个动画结束并立即删除时，将触发回调。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。

## LOGICALLY

```TypeScript
LOGICALLY = 1
```

当动画在逻辑上处于下降状态，但可能仍处于其长尾状态时，将触发回调。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
