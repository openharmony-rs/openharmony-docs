## velocity

```TypeScript
velocity?: double
```

设置滚动到容器边缘的固定速度。如果设置小于等于0的值，参数不生效。

**类型：** double

**默认值：** 0vp/s

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
