# TypedFrameNode

TypedFrameNode继承自[FrameNode](arkts-na-framenode-framenodeoptions-i.md)，用于声明具体类型的FrameNode。 > **说明：** > > commonAttribute仅在CustomFrameNode上生效，TypedFrameNode上commonAttribute行为未定义。建议使用 > attribute接口而非 > commonAttribute接口进行通用属性设置，如node.attribute.backgroundColor(Color.Pink)。

**继承/实现关系：** TypedFrameNode extends [FrameNode](../../apis-arkui/arkts-apis/arkts-arkui-framenode-c.md)

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
