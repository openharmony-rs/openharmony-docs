# CustomDarkColors

```TypeScript
export declare type CustomDarkColors = Partial<Colors>
```

自定义深色主题颜色资源类型。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
