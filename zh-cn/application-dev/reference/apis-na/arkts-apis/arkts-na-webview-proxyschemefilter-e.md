# ProxySchemeFilter

Enum type supplied to [insertProxyRule](../../apis-arkweb/arkts-apis/arkts-arkweb-webview-proxyconfig-c.md#insertproxyrule) for indicating the scheme filter for proxy.

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## MATCH_ALL_SCHEMES

```TypeScript
MATCH_ALL_SCHEMES = 0
```
