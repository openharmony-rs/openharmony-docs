# PromptActionQuadrupleButtons

```TypeScript
export type PromptActionQuadrupleButtons = [
        Button,
        Button | undefined,
        Button | undefined,
        Button | undefined
    ]
```

菜单中的菜单项按钮，仅支持4个按钮。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
