# WebKeyboardAppearanceMode

Enum type supplied to keyboardAppearance for setting the web keyboard appearance mode.

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。
