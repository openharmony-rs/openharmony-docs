## wordBreak

```TypeScript
wordBreak?: WordBreak
```

弹窗message内容的文本截断方式。 默认值：WordBreak.BREAK_ALL

**类型：** [WordBreak](../../apis-arkui/arkts-apis/arkts-arkui-wordbreak-e.md)

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
