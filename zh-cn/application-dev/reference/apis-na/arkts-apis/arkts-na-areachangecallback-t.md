# AreaChangeCallback

```TypeScript
export declare type AreaChangeCallback = (oldValue: Area, newValue: Area) => void
```

Defines the options for the AreaChangeEvent.

**起始版本：** 26.0.0

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
