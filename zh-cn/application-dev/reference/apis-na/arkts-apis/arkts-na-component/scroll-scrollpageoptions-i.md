# ScrollPageOptions

翻页模式的参数选项。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

<!--Device-unnamed-export declare interface ScrollPageOptions--><!--Device-unnamed-export declare interface ScrollPageOptions-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## animation

```TypeScript
animation?: boolean
```

是否开启翻页动画效果。true有动画，false无动画。

**类型：** boolean

**默认值：** false

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

<!--Device-ScrollPageOptions-animation?: boolean--><!--Device-ScrollPageOptions-animation?: boolean-End-->

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## next

```TypeScript
next: boolean
```

是否向下翻页。true表示向下翻页，false表示向上翻页。

**类型：** boolean

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
