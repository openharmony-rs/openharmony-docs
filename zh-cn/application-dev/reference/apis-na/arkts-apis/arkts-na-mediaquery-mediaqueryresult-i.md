**废弃版本：** -1

## matches

```TypeScript
readonly matches: boolean
```

是否符合匹配条件。true表示满足查询条件，false表示不满足查询条件。 此属性为只读属性。

**类型：** boolean

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
