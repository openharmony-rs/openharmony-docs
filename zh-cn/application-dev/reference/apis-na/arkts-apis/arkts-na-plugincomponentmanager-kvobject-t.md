# KVObject

```TypeScript
export type KVObject = Record<string, int | long | double | string | boolean | Array<KVObject> | KVObject>
```

以键值对形式存储信息，符合JSON格式。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
