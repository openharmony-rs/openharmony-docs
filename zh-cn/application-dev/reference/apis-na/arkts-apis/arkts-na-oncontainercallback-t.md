# OnContainerCallback

```TypeScript
declare type OnContainerCallback = () => void
```

容器回调函数类型，用于定义绑定在树节点上的子组件回调。

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
