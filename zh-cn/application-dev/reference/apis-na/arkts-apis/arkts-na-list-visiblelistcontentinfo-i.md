# VisibleListContentInfo

定义List可见内容区子组件的详细信息。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

## index

```TypeScript
index: int
```

表示ListItem或ListItemGroup在List中的索引值。 取值限定为整数。

**类型：** int

**起始版本：** 23

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
