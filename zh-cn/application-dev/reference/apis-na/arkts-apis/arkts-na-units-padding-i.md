# Padding

type Padding = { top: Length; right: Length; bottom: Length; left: Length; } 内边距类型，用于描述组件不同方向的内边距。 引入该对象时，至少传入一个参数。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1


**模型约束：** 此接口仅可在Stage模型下使用。
