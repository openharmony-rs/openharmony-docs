# SystemBarStyle

```TypeScript
export type SystemBarStyle = window.SystemBarStyle
```

状态栏的属性。在设置页面级状态栏属性时使用。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
