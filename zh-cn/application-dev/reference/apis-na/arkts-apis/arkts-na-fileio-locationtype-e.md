# LocationType

枚举，文件位置，表示该文件是否在本地或者云端存在。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**系统能力：** SystemCapability.FileManagement.File.FileIO

## LOCAL

```TypeScript
LOCAL = 1 << 0
```
