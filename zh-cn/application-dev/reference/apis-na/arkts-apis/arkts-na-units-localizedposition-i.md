# LocalizedPosition

位置类型，用于表示一个坐标点。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## start

```TypeScript
start?: LengthMetrics
```

LTR模式时x轴相对左边坐标，RTL模式x轴相对右边坐标。

**类型：** [LengthMetrics](arkts-na-lengthmetrics-t.md)

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
