# StackLayoutAlgorithmOptions

设置堆叠布局算法的对齐方式。

**起始版本：** 24

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为24。

## alignContent

```TypeScript
alignContent?: LocalizedAlignment
```

设置子组件在堆叠布局算法中对齐格式。 非法值：按默认值处理。

**类型：** [LocalizedAlignment](arkts-na-enums-localizedalignment-e.md)

**默认值：** LocalizedAlignment.Center

**起始版本：** 24

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为24。
