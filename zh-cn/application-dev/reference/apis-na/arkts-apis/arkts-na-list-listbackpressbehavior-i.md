## closeSwipeAction

```TypeScript
closeSwipeAction?: boolean
```

系统返回键生效时，是否收起已展开的ListItem的划出组件。

**类型：** boolean

**默认值：** true

**起始版本：** 26.0.0

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为26.0.0。

**模型约束：** 此接口仅可在Stage模型下使用。
