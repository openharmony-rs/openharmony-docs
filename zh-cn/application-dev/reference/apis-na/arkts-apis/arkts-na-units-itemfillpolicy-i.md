# ItemFillPolicy

定义一个适用于WaterFlow、Grid、 List、Swiper和 [LazyVWaterFlowLayout](../../../reference/apis-arkui/arkui-ts/ts-container-lazyvwaterflowlayout.md)组件的响应式布局策略。 LazyVWaterFlowLayout组件从API版本26.0.0开始支持。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## fillType

```TypeScript
fillType?: ResponsiveFillType
```

为不同的响应式断点指定列数。默认值为BREAKPOINT_DEFAULT。

**类型：** [ResponsiveFillType](arkts-na-responsivefilltype-t.md)

**默认值：** ResponsiveFillType.BREAKPOINT_DEFAULT

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
