| [ActionSheetOptions](actionsheet-actionsheetoptions-i.md) | 列表选择弹窗的样式。 |
| [DismissDialogAction](actionsheet-dismissdialogaction-i.md) | Dialog关闭的信息。 |
| [SheetInfo](actionsheet-sheetinfo-i.md) | 弹窗中的选项内容，每一项支持设置文本、图标以及选中的回调。 |
