# unlink

## unlink

```TypeScript
function unlink(path: string): Promise<void>
```

删除单个文件，仅适用于文件，不可用于删除目录。使用Promise异步回调。

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

| --- | --- |

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1
