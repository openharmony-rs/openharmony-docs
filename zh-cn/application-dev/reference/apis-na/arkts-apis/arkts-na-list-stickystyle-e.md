# StickyStyle

ListItemGroup吸顶或吸底效果枚举。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

## None

```TypeScript
None = 0
```

ListItemGroup的header不吸顶，footer不吸底。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
