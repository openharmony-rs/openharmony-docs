# DatePicker

## DatePicker

```TypeScript
@ComponentBuilder
export declare function DatePicker(
    options?: DatePickerOptions
): DatePickerAttribute
```

定义日期选择器组件。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。

| 类型 | 说明 |
