# PixelStretchEffectOptions

Set the edge blur effect distance of the corresponding defense line of the component When the component expand out, no re-layout is triggered

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**系统能力：** SystemCapability.ArkUI.ArkUI.Full

## bottom

```TypeScript
bottom?: Length
```

bottom property. value range (-∞, ∞) If value > 0, expand outward elements. Else first shrink by value and then expand outward pixels.

**类型：** [Length](../../apis-arkui/arkts-apis/arkts-arkui-length-t.md)

**默认值：** 0

**起始版本：** 23

**ArkTS模式：** 仅支持ArkTS-Sta，起始版本为23。

**废弃版本：** -1

**模型约束：** 此接口仅可在Stage模型下使用。
