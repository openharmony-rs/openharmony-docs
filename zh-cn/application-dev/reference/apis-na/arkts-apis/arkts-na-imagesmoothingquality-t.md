# ImageSmoothingQuality

```TypeScript
export type ImageSmoothingQuality = 'high' | 'low' | 'medium'
```

定义图片平滑度类型。 'high': 高画质。 'low': 低画质。 'medium': 中画质。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
