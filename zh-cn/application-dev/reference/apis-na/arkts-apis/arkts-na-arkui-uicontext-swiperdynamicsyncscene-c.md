# SwiperDynamicSyncScene

提供Swiper组件动态帧率场景的相关配置，适用于为动画过渡和手势跟手等不同交互场景设置差异化帧率范围，以兼顾流畅度和功耗，继承自[DynamicSyncScene](arkts-na-arkui-uicontext-dynamicsyncscene-c.md)。

**继承/实现关系：** SwiperDynamicSyncScene extends [DynamicSyncScene](arkts-na-arkui-uicontext-dynamicsyncscene-c.md)

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。
