# GetterCallback

```TypeScript
export declare type GetterCallback<T> = () => T
```

获取绑定值的回调方法。

**起始版本：** 23

**ArkTS模式：** 同时支持ArkTS-Dyn、ArkTS-Sta，起始版本为23。

**模型约束：** 此接口仅可在Stage模型下使用。
