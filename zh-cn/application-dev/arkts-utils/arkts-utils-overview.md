# ArkTS基础类库概述
<!--Kit: ArkTS-->
<!--Subsystem: CommonLibrary-->

<!--Tester: @kirl75; @zsw_zhushiwei-->

ArkTS基础类库是一个功能齐全的API集合，设计了一系列关键且实用的功能模块。

ArkTS基础类库主要提供了[XML概述](xml-overview.md)、[Buffer与FastBuffer](buffer.md)、[多种容器类库](container-overview.md)、[URL字符串解析](../reference/apis-arkts/js-apis-url.md)和[任意精度数学库Decimal](../reference/apis-arkts/js-apis-arkts-decimal.md)等能力，简化开发工作，提升开发效率。
